# 标准答案卡

标准答案卡保存经人工审核的答案原文。每张卡片归属一个固定知识空间，并绑定一至十份不同文档的固定发布版本。搜索相关性只帮助查找，不能证明答案适用于当前业务情形；使用前请核对标准问题、适用范围和依据。

## 三类状态

| 维度 | 含义 |
| --- | --- |
| 内容和审核 | 保存产生不可变草稿修订；送审为 IN_REVIEW，结果为 APPROVED、REJECTED 或 WITHDRAWN |
| 当前展示 | 来源、权限及日期均合格时可展示；来源变化、未生效、过期等原因可暂停展示，历史批准仍保留 |
| 周期复审 | UNASSIGNED 未指定，NEEDS_REASSIGN 需改派，DUE_SOON 三十天内复审，OVERDUE 复审逾期，OK 正常 |

周期复审逾期本身不下线仍有效的答案。责任人失格本身也不阻止其他合格读者读取有效卡片，但必须重新指定人员。

## 当前权限

| 操作 | 功能权限 | 资源条件 |
| --- | --- | --- |
| 浏览、搜索、固定详情 | 有效登录并已完成必需改密 | 卡片空间 view、全部来源可读，且满足当前展示条件 |
| 创建、保存、送审 | answer:card:write | 卡片空间 view/edit、所操作修订全部来源可读 |
| 批准、驳回 | answer:card:review | 卡片空间 view/review、全部来源可读，且非分支贡献者或送审者 |
| 撤回 | answer:card:write | 当前仍合格的本轮送审者 |
| 历史和暂停正文 | write 或 review 对应资格 | 按每个修订核对空间和全部来源，允许有可信发布证据的旧来源版本 |
| 配置责任人 | 空间 manage 或 space:manage-all | 只返回卡片ID、流程及复审信息；归档期间只读 |
| 确认仍准确 | answer:card:write | 当前合格责任人，当前发布版可展示，且无活动草稿 |

角色名称、空间管理权和来源文档例外均不能替代卡片维护或审核资格。来源的文档 view 例外只用于读取来源本身，不扩大卡片空间范围。任一来源失权、升密、删除或归档都阻止整份派生答案返回，不能通过隐藏一个引用继续展示正文。

## 草稿与人工审核

1. 维护者在具有 view/edit 的空间创建草稿。问题必填；答案、范围及来源可暂缺。
2. 通过受控来源候选，明确选择本人可读的当前发布文档。每次保存追加修订，不覆盖历史。
3. 空间管理员从合格候选中指定一名责任人及周期；不需要身份目录读取权限。
4. 内容完整且存在其他合格审核人时，手动送审精确修订。空间 AUTO 策略不能免除卡片审核。
5. 审核期间草稿冻结。全部分支贡献者和送审者均不得批准或驳回；换送审者不解除原贡献者限制。
6. 批准后原子切换发布修订并关闭草稿分支。驳回需原因，撤回仅送审者可执行；这两种结果保留原分支，可编辑后再次送审。

已发布卡片可另开新版草稿。只要旧发布版仍满足当前展示规则，读者继续使用旧发布版。新草稿文字不会进入普通卡片搜索结果。

## 固定依据与日期更正

来源绑定文档ID、版本ID及适用期修订号，日期快照由服务端取得。缺少日期声明行时修订为0，日期为未声明。私人候选、仅完成索引或仅允许兼容访问的版本不能作为依据。

来源发布新版或更正适用日期会使旧卡片停止普通展示。即使日期随后改回，修订号已经推进，仍须重审。维护者先撤回仍在审核的旧稿，查看可访问的原绑定及当前声明，再明确选择新事实、保存新修订并重新送审。系统不自动替换来源。标题、标签和分类变化本身不触发重审。

卡片和全部来源按 Asia/Shanghai 日历计算，生效日和截止日均包含当天，日期范围为1900-01-01至2999-12-31。未声明表示未知，不能改称长期有效。审核允许未来共同适用区间；已无当前或未来交集的组合不能送审或批准。正常到达已审核的生效日可以自动展示，截止日次日暂停。

## 责任人周期复审

周期为3、6、12或24个月。到期日以最近确认日计算，无确认时使用首次指定日，月末按日历截取。提前30天提示，到期日次日才逾期。例如2026-11-30首次指定、周期三个月，到期为2027-02-28。改派不重置基准，改周期沿用原基准。

确认“仍准确”记录当前责任人、业务日期和固定发布修订，推进复审版本。发布、保存和改派都不自动确认。来源变化、日期失效、失权、有活动草稿或审核时不能确认；确认也不能延长有效期。需要改答案、日期或来源时必须走新修订及独立审核。

## 浏览、搜索和旧链接

普通入口为“标准答案”，详情固定到所选修订。搜索仅支持自己的问题及所属空间；知识搜索页的文档分类、标签、文件类型、日期和术语建议不作用于卡片。点击“用原问题查标准答案”只预填，用户仍需明确提交。

排序依次为问题或问法归一后精确相等、问题字段文本命中、仅答案命中；每级先按全部当前条件过滤再截取。摘要是最多400个Unicode码点的答案原文前缀，截断会注明。详情提供原固定版本业务入口，文件预览和下载仍分别鉴权。

旧链接在所选修订被替换、到期或失去来源访问后统一不可用，不自动换成新答案。可主动重新浏览或搜索。成功空结果、服务不可用及容量繁忙分别显示。

## 写入结果未知

超时或断连不能证明操作失败。工作区保留原请求标识、原载荷和预期版本，冻结新冲突写入；可主动核对本人回执，或显式使用原绑定重试。NOT_FOUND仅表示本次未查到，仍可能有在途提交。

关闭弹窗或局部组件不清除待核对意图。资格正在重核时清理页面私有内容但保留未知写入原意图，确认失权后才清除相关载荷。明确放弃后先重读服务器事实，再开始新意图。完全刷新、退出或换号清理内存，不从浏览器持久存储恢复正文或自动重发。迟到响应不得进入新的用户或工作区。

## 空间生命周期与验证边界

卡片空间或任一来源空间归档后停止内容读取和操作。卡片所属空间管理者可看最小信息，但不能在归档期间调整责任人。取消归档后按当时来源、权限和日期重判，不重置复审日期。

空间只要存在任何卡片引用，包括草稿、暂停卡片和历史，就不能删除，只能归档。无卡片且无文档引用时才允许删除。
