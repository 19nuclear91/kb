# 文档资料、目录与筛选

## 权限与入口

| 入口 | 读取资格 | 写入资格 |
| --- | --- | --- |
| 文档详情资料 | 当前文档 view、密级及可见版本规则 | 当前 view + edit，能力明确返回 canEditMetadata=true |
| 文档编辑候选 | 该文档当前 view + edit | 只能选用已有分类、启用标签 |
| 文档中心筛选候选 | 当前可查看文档范围 | 无目录维护能力 |
| 空间详情分类管理 | 对应空间 manage 或 space:manage-all | 同左；归档空间只读 |
| `/admin/document-tags` | document:tag:read | 另需 document:tag:write |
| 文档管理搬迁 | 实际空间管理资格与最小上下文 | 源、目标空间管理资格 |
| `/admin/audits` | audit:read | 只读 |

标签读写权限互不蕴含；仅持写权限不能进入目录页面。空间管理资格不能替代全局标签维护资格，词库维护资格也不授予文档阅读权。

## 整文档资料

从详情打开“编辑资料”时重新读取当前标题、人工摘要、分类、标签和独立资料版本。标题最多 512 个 Unicode 字符，摘要最多 2000，最多 20 个标签。摘要空白视作清空；分类选择“未分类”明确清除分类。

保存后立即生效，不进入文件版本审核。切换历史文件只改变文件查看目标，不改变整文档资料编辑目标。资料版本与文件版本、审核版本、分类树版本相互独立。

分类逐层展开并可继续加载，同级按排序值及 ID 排列。文档编辑使用实际所属空间的目录；文档中心只显示可查看文档使用的分类及必要祖先。候选失败显示重读入口，不允许用手填 ID 补足。已有停用标签始终单独显示，可保留或移除；移除后在停用期间不能重新添加。

保存期间不能重复提交，删除确认期间不能开始保存，在途保存结束前不能确认删除。已知结果未确认的写入会参与删除前的提示。关闭编辑弹窗或离开页面只停止本地等待，不撤销服务端操作。

## 文档中心筛选

标题按不区分大小写的字面包含匹配，百分号、下划线和反斜杠也是普通字符。空间、分类、标签、文件类型及更新时间之间全部同时满足；多标签内部同样为全部匹配。父分类包含所有后代，“仅未分类”与指定分类互斥。

时间输入使用本地时间，提交转换为带时区的时间点，含起点、不含终点。类型只看当前发布版本文件名和 MIME；隐藏候选不会改变类型，没有发布版本显示“尚未发布”。

修改筛选草稿不会改变当前分页条件，点击“应用筛选”才回到首页重新读取。切换空间清除旧分类选择；分页沿用已提交条件，每页重新鉴权，不承诺冻结跨页快照。查询词通过请求体发送，地址栏和持久存储不保存关键词。

## 分类与标签管理

空间详情可选择根位置或分类，新建根/子分类，修改名称、父节点及同级排序，或删除无引用节点。最大深度八层；不能移到自身或后代。存在子节点或文档保留引用（含软删除文档）时删除被拒绝，不显示引用文档名称或数量。

目录分页检测树版本变化，失效后清除旧页并提供重新读取。维护发生版本或引用冲突时显示固定原因、刷新目录，再由用户重新选择和确认，不拼接旧表单与新树版本。归档空间保留只读目录。

全局标签页面支持名称筛选、启停状态筛选和续页。新建默认启用；改名和启停使用词条版本。停用保留已有文档关联，只阻止新增关联；名称仍被该词条占用。改名与启停不改变各文档资料版本或更新时间。

## 搬迁与恢复

管理者打开搬迁时读取只含文档 ID、来源空间和资料版本的最小上下文。没有正文查看权时仍可操作，界面以文档 ID 标识目标。选择目标空间后必须明确选择目标分类或“未分类”；尚未选择不会自动变成 null。切换目标清空旧选择及候选。

搬迁切换空间和分类、增加资料版本、清除文档例外、取消活动审核，并保留全部全局标签。回执显示清除总数、明细截断、目标分类身份、资料版本及密级受阻数；受阻数非零仍表示搬迁成功。

上下文缺少新字段或不可用时禁止确认。旧请求省略 targetCategoryId 或 expectedMetadataVersion 返回 400；旧审计标识没有新协议绑定时返回 409。版本或分类冲突后重新读取当前事实并由用户重选，不自动改为未分类或按名称换节点。

资料、分类、标签和搬迁响应丢失时，可按原标识、原版本和原内容匹配重试，或只读核对。“只读核对”不是原请求回执；“放弃核对”也不会撤回已发送的操作。已确认成功与随后读取失败分别展示。退出、改密、切换身份/资源、隐藏或离页会隔离旧响应；恢复先核对身份，再读取当前事实，不自动恢复提交。

## 审计展示

审计只显示稳定 ID、版本、布尔事实和固定变更字段，不加载标题、人工摘要、分类路径或词条名称。tagIds 最多 20 个精确整数，changedFields 仅包含 title、summary、categoryId、tagIds。空数组显示“空集合”，显式分类 null 显示“未分类”；历史未记录的分类/版本不补零或未分类。未知数组、嵌套对象或非法元素作为读取故障。

API 细节见 [API 说明](document-metadata-api.md)，发布与回退边界见 [运维说明](document-metadata-operations.md)。本变更仅使用明确白名单的纯内存测试、类型检查和静态构建；数据库与部署行为的设计不等于已完成运行时验证。
