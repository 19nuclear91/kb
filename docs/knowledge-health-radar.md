# 知识健康雷达

在“知识空间”中打开一个可管理且未归档的空间，点击“知识健康雷达”。入口还要求独立权限 `knowledge:health:read`，可由角色管理员分配。页面地址为 `/admin/spaces/:spaceId/health-radar`，支持在当前可管理的未归档空间间切换，每次查看一个空间。

## 读取维护信号

上方提供六类数量和去重后的受影响文档数：未指定责任人、责任人需重新指定、复审已逾期、即将复审、适用期已届满、适用期即将届满。点击数量或使用筛选器查看对应清单，同一文档命中多个原因时合并展示。

责任人与复审四类覆盖本空间未删除、未归档文档，包括尚未发布首版的文档；适用期两类仅覆盖本人当前可读的当前发布版本。各类数量不可直接相加，适用期数量为零不代表全空间没有过期资料，未声明日期也不代表长期有效。

复审逾期表示需要当前责任人重新确认准确性；适用期届满表示该版本声明的截止日已经过去。两者不自动改变发布、阅读或搜索状态，不代表系统已经认定正文错误或自动废止资料。

## 处理资料

- 每行以文档 ID 显示，并提供“管理责任人与复审”，可进入原管理页指定、改派责任人或查看复审设置。
- 适用期信号提供“核对此次诊断的版本”，使用固定版本预览，格式和 Office 配置仍遵循现有预览能力。
- “打开文档详情处理”会重新读取文档及当前可访问版本。编辑者需在原页面确认需要处理的版本，不能把详情页默认版本当作先前诊断版本。
- 只有当前合格责任人能确认资料仍准确；雷达权限和空间管理资格不会代替确认或编辑资格。

处理后返回或刷新查看最新结果。确认复审只消除相应复审原因；当前发布版本的适用期仍届满时，该文档仍在清单中。

## 翻页与恢复

页面每页最多 20 项，下一页替换当前页并重新取得统计。每页反映当前事实，数据更新或撤权可能使数量变化；“返回首页”或“刷新当前筛选”重新从首页读取。业务日期变化后，旧游标要求从首页重新查询。空结果会分别提示当前诊断范围没有可见信号、所选类别没有项目，或本次翻页没有项目；翻页为空时仍可返回首页查看最新结果。

空间归档时诊断暂停；空间目录加载失败时切换器显示故障，已独立核验的当前目标仍按其结果展示。读取失败提供显式重试，不将故障显示成零问题。页面隐藏、退出、换号或失去资格后清除旧结果，恢复先核对资格。

本期支持六类确定规则，不提供健康评分、正文重复/矛盾分析、跨空间汇总、导出、推送或单独整改流程。实现状态与离线证据见本次变更记录；真实迁移、部署和联调未执行。
