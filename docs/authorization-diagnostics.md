# 权限解释与授权预演

空间详情和文档管理面板中的“权限诊断”只对同时具备 `authorization:diagnose` 与当前资源管理资格的操作者开放。manage 或 `space:manage-all` 不隐含新资格；仅密级管理资格也不能开放文档诊断。可以搜索用户显示名，或从现有 USER 授权行点击“诊断此用户”。无需身份目录权限，不提供任意用户 ID 输入。

一次只分析一位用户、一个空间及可选的一份同空间文档。文档面板固定当前文档；没有正文权限时仍可用 ID 诊断，不补查隐藏标题、版本或文件。用户选择后再次读取身份；停用、生命周期限制、主部门无效或须改密统一显示“账号当前不满足访问条件”，来源与密级均未评估。不存在返回安全 404，依赖故障返回 503。

## 三层含义

| 层次 | 说明 |
| --- | --- |
| 空间授权 | view、download、edit、review、comment、manage 分别展示命中来源；全局管理只解释 manage |
| 文档授权 | 合并空间与 view／download／edit／comment 文档例外；review 只取空间，manage 仍取空间层 |
| 当前发布版本访问 | 仅当前发布指针，分别判断查看与下载；无指针显示未评估，不推断历史或待审版本 |

授权命中和通用门槛分别显示。空间归档保留来源但阻断非 manage 资源资格；密级只展示通过或未通过，不显示等级。下载授权独立于 view，但实际当前发布版本下载同时需要 view。edit、review、comment 不承诺上传、审批或评论可成功，仍有各自业务检查。未发布 V2 不影响当前发布 V1 的评估，也不披露 V2 的存在。损坏的非空发布指针整体返回 503。

## 可选预演

既有授权弹窗提供“预演影响”，先选择观察用户再主动计算。空间授予使用完整主体与权限位笛卡尔积，最多 50×6；空间撤销只使用所选 1–300 条显式项。文档例外每次一项。一次只能预演一种操作；含 manage 变更还需 `space:grant-manage`。

结果以“当前／若提交后”比较，完整条目显示拟新增、拟移除或无变化，不是成功授权回执。例：用户既有个人 view 又有部门 view，撤销个人行后仍保留部门来源，并明确提示授权判定和访问结果不变；撤销文档 download 例外后仍可由空间 download 授权；新增 view 后密级仍不满足时，授权命中改变而当前版本访问仍不允许。修改无关角色只显示该条目拟议变化，不展开成员，也不将条目数解释为影响人数。

预演始终只读：不调用授权写服务，不写成功审计、回执、临时业务记录或任务，不创建目标会话或探测原件。正式提交可以不经过预演，仍采用原确认、请求标识和实时鉴权；预演失败不会自动提交。

## 结果失效与恢复

本功能已于 2026-11-25 同步四份主规格并归档，42/42 项任务完成。最终核验为 0 CRITICAL、0 WARNING、0 SUGGESTION；见[归档记录](../openspec/changes/archive/2026-11-25-permission-explanation-and-authorization-preview/archive-record.md)及[最终核验报告](../openspec/changes/archive/2026-11-25-permission-explanation-and-authorization-preview/verification-report-3.md)。归档不代表已部署或执行 V43 迁移。

身份、资源、观察文档、目标用户或草稿改变，立即清除旧结果并取消读取；同草稿重复请求也只接受最新一次。关闭、离页、隐藏、退出及换号清理私有诊断状态，不写入 URL 或浏览器存储。恢复可见性或资格后必须主动重新诊断。

正式写入开始、写入结果未知，以及文档删除确认、搬迁或密级写入期间暂停诊断。关闭重开只读面板和成功解释不能结清原写入；原标识仍按原回执、明确拒绝或显式放弃规则处理。403／404 清理并有界核对资格，诊断故障只影响该区块。重核后仍有管理资格时保留固定失败提示；旧端点 404／405 显示诊断暂不可用，原授权操作继续按现有资格开放。API 细节见 [接口说明](authorization-diagnostics-api.md)，权限迁移见 [发布与回退](authorization-diagnostics-operations.md)。

授权弹窗内的预演触发资格重核时，同一身份和资源归属下仍有管理资格即可恢复原授权表单，保留主体、权限位和授予／撤销动作，并显示失败提示。即使诊断资格已撤销，也可以按原写资格主动提交；系统不会自动提交或重发预演。确认失去管理资格、文档搬迁、身份变化或离开详情页后，不再恢复旧表单；明确关闭已恢复表单后，后续重核也不会自动打开它。

实施仅执行独立单元／组件、内存替身及 jsdom 检查。真实 SQL、数据库并发／隔离、V43 执行、网络、真实浏览器和前后端联调未验证。
