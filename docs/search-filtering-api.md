# 知识搜索组合筛选

## 主搜索请求

`POST /api/search` 使用当前登录会话，JSON 请求体支持以下字段。query 必填且非空，最多 8000 个 Unicode code point；实际正文默认最多 128 KiB。URL 查询参数被拒绝，搜索条件仅保存在当前页面内存。

| 字段 | 规则 |
| --- | --- |
| query | 非空合法 Unicode，不含 NUL；保持原始问题，不静默截断 |
| candidates / topK | JSON 整数 1–200；省略或 null 时分别默认 50、candidates；topK 大于 candidates 仍合法 |
| spaceId / categoryId | 正整数 ID，支持至 Long.MAX_VALUE；省略或 null 不限制 |
| uncategorized | 省略为 false；提供时必须为布尔值，与非空 categoryId 互斥 |
| tagIds | 至多 20 个不重复正整数，全部匹配；省略或 [] 不限制，null 非法 |
| fileType | PDF、TXT、MARKDOWN、WORD、EXCEL、POWERPOINT、OTHER；省略不限，null 或 UNPUBLISHED 非法 |
| updatedFrom / updatedTo | 带时区时间，含起点、不含终点；省略不限，null 非法；双边存在时起点早于终点 |

条件按 AND 组合。成功结果仍为 `R` 包装的有序分块数组，保持版本化引用，不提供 total 或结果分页。知识搜索页面固定请求 candidates=50、topK=20。

```json
{"query":"报销流程","candidates":50,"topK":20,"spaceId":12,"categoryId":34,"tagIds":[56,78],"fileType":"PDF","updatedFrom":"2026-10-01T00:00:00+08:00"}
```

合法无筛选请求 `{"query":"报销流程"}` 保持原默认值。分类包含其后代，分类 ID 可以独立提交；合法但无可见匹配的空间、分类或标签得到空结果，不能去掉条件重试。停用标签的已有文档关联继续可筛选。

## 召回与版本

全部条件和权限谓词在 BM25、向量各自的候选截取前生效，随后按原 RRF、rerank 和 topK 处理；不会先取全局结果再在前端筛选。分类后代在同一召回语句计算，标签使用逐项 EXISTS，避免关联重复污染排名。

文件类型只读取当前发布版本：V1 是 PDF、V2 是待审 Word 时仍匹配 PDF。分类、标签、空间和更新时间读取文档当前资料，修改资料无需重新解析或重建向量；固定引用始终使用命中的原版本和分块。更新时间来自文档 updatedAt，分类/标签字典改名并不自动推进每篇文档更新时间。

分类与标签计算纳入现有召回剩余预算。Embedding 故障或 profile 变化关闭向量分支时保留完整筛选；rerank 失败回退本次已筛选候选的原顺序。组合条件没有命中是合法空结果，不自动移除条件。

## 输入兼容与错误

本次收紧未知字段行为：未知或重复字段、尾随 JSON、错误类型、溢出 ID 和冲突条件返回 400。原先被忽略的 userId、角色、密级、裸向量或 profile 字段也返回 400。合法的旧三字段请求和 AI 无筛选调用继续兼容。

原有 401/403 登录及主体门禁、400 输入无效、413 搜索请求过大、429 本人并发超限、503 容量或依赖不可用保持各自含义；未知内部错误为 500。错误不回显查询或筛选内容，Retry-After 不触发自动重试。

## 搜索专用候选

两个候选接口均为 POST JSON，实际正文最多 16 KiB，拒绝 URL 参数、未知/重复字段和尾随 JSON。每页默认 20、最多 100；cursor 为搜索用途的不透明分页值，最长 4096 字符。它们共享主搜索的用户/实例实际在途容量、总截止和响应限界，仅读取目录，不调用模型。

- `/api/search/categories`：请求 `{spaceId,parentId?,limit?,cursor?}`，spaceId 为必需正整数，parentId 省略或 null 读取根层。返回 `{items,hasMore,nextCursor,treeVersion}`，items 为 `{id,parentId,name,path,sortOrder}`，path 为 `{id,name}` 数组。同层按 sortOrder、id 升序。
- `/api/search/tags`：请求 `{nameQuery?,limit?,cursor?}`。名称去首尾空白后最多 64 个 Unicode code point，空白不限，百分号、下划线和反斜杠按字面匹配。返回 `{items,hasMore,nextCursor}`，items 为 `{id,name,enabled}`，按标签 ID 升序。显式 null 的 nameQuery、limit、cursor 非法。

候选仅来自本人可检索的当前已发布文档及其实际分块，保留空间归档、ACL 和密级门禁。首版待审文档不贡献候选；已有发布 V1、待审 V2 时使用该文档当前资料。Embedding 维护时仍可参与授权 BM25 的文档继续贡献候选。

分类展示所选空间中的相关节点与必要祖先。标签为本人全局可检索范围内的已用标签，包含停用项，不随空间、正文关键词、类型或时间动态收窄；候选出现不保证最终条件有命中。

游标绑定用途、当前用户、空间/父节点或名称条件及排序位置；混用文档中心游标、其他用户或其他条件返回 400。仍可访问的分类树版本变化返回 409，需重读目录；不存在或已无可见分类的上下文统一返回空页、treeVersion=0，不披露隐藏树版本。分页会重新授权，撤权后独有候选消失。

候选依赖故障为安全 503，404 或服务错误不能当成空目录，也不回退到文档中心、管理或编辑候选。

## 筛选协议与发布顺序

app 的全部主搜索成功响应携带 `X-Search-Filter-Version: 1`，包括无筛选、空数组及降级结果；JSON 包装不变。网关和代理仅透传该头，不生成或覆盖它。既有 CORS 配置暴露此头，允许来源保持原配置。

前端对每次带有效限制的成功响应先核对版本值精确为 `1`，再消费数组。缺失、重复合并或未知版本会丢弃材料，提示“无法确认服务端筛选支持”，保留输入；不产生结果、收藏查询或引用。用户明确清空限制后的无筛选请求继续兼容旧实例，无须版本头。

发布先更新全部 app、gateway 实例，再发布筛选页面。回退先恢复旧页面或撤下筛选入口，再回退后端；仅回退后端时，新页面拒绝未经确认的带条件结果。无需数据回填、索引重建或逆迁移。此处为发布说明，开发验证采用进程内控制器、服务和网关组件替身。

## 页面交互

搜索页把关键词和五类条件作为草稿，只在点击搜索并校验通过后提交完整快照。已提交条件摘要与结果绑定，修改草稿或清除筛选不会改写原结果含义，也不会自动查询。切换空间清除分类及未分类，保留全局标签；不选空间时仍可命中合法的空间外文档例外。

分类保留必要祖先并标明包含后代；标签显示停用状态且多个标签全部匹配。目录名称查询和分页独立于正文搜索，失败提供主动重读，409 不拼接旧分类页，不因目录故障删除既选限制。文件类型只提供发布类型，本地更新时间转换为带时区值。

提交新搜索会清理旧结果和引用，迟到响应不能覆盖当前条件。离页、隐藏、退出、身份变化和强制改密清理草稿、摘要、目录、游标、命中及引用；恢复按当前身份读目录，正文搜索仍须主动提交。收藏操作保持原结果顺序和版本引用。
