# 标准答案卡运维说明

`reviewed-answer-cards` 已完成47/47任务，交付 V44 迁移文件、后端接口、浏览与独立搜索、维护审核及责任人管理页面，并于2026-11-26同步6份主规格后[归档](../openspec/changes/archive/2026-11-26-reviewed-answer-cards/archive-record.md)。最终[核验](../openspec/changes/archive/2026-11-26-reviewed-answer-cards/verify-report.md)无critical或warning，逐场景证据见[交付记录](../openspec/changes/archive/2026-11-26-reviewed-answer-cards/verification.md)；尚未执行真实迁移或部署。

## 数据与迁移

V44 `reviewed_answer_cards` 新建稳定卡片、草稿分支、不可变内容修订、固定来源、分支贡献者、审核轮次、责任人设置、确认事实和命令回执。只创建新业务结构，不转换现有文件、私人会话或知识问题。

卡片引用知识空间，来源引用原文档与固定文件版本。来源同时保存适用期修订和当时声明；日期更正即使恢复原值也不恢复旧卡片的有效性。内容修订、来源、贡献者、确认记录及回执不可修改或删除。发布指针必须具有审核批准证据，发布与审核在业务事务内一并提交。

文本索引使用与现有检索相同的 ParadeDB 扩展及 `pdb.jieba`，卡片文本独立索引。卡片本身不需要解析或 Embedding；选择依据前需要已有可信发布文档。迁移由 app 单点执行，Worker 不执行 Flyway。

## 发布与回退说明

先排空不认识 `answer:card:write`、`answer:card:review` 的旧 app，再由 app 完成迁移和升级，然后更新 gateway 与前端。V44 仅在迁移时为已有 ROLE_ADMIN 一次性绑定两项功能资格；后续启动不得补回主动撤销的权限。功能资格不会修改空间或文档授权。

保留所有新表、不可变历史、权限绑定与索引。止损可先移除前端新入口，保留识别新权限和保护空间引用的业务版本；不可直接回退到忽略卡片引用或不认识新权限的旧 app，也不使用反迁移或删除权限掩盖兼容问题。

## 验证范围

本变更仅安排进程内单元/组件、Mock 或内存替身、模拟 DOM、编译和静态构建。迁移及 SQL 通过人工审阅交付，不编写检查文档内容或 SQL 文本是否存在的测试。

没有执行数据库迁移、真实约束/触发器、数据库锁/回滚、索引执行计划、Redis、对象存储、前后端联调或真实浏览器验证。离线结果不证明这些外部行为已经通过，也不作为当前变更完成的前置条件。

## 权限与排障

内容审核事实、当前展示资格和周期复审分别判断，完整矩阵见[使用说明](answer-cards.md)。维护和审核需要独立精确功能权限；最小管理只要求空间manage或space:manage-all，不取得答案或来源清单。全局审计仍独立要求audit:read。

来源每次访问都重核当前ACL、密级、空间和固定发布证据；缺日期行按修订0处理。来源发布新版、首次声明或任何日期更正均使旧绑定不匹配，即使值改回也不能恢复。系统不批量写入卡片暂停状态；排障结合有权读取的固定绑定与来源真实事件，不生成伪编辑/审核审计。

责任人失格只给出需改派标记，不返回其失格原因。管理员按当前合格候选改派，周期仍从原首次指定日或最近确认日计算。逾期继续展示且提示；确认只能由当前合格责任人执行，不能替代来源变化后的重审。

## 空间和历史

空间归档停止正文读取、维护、审核和确认，也禁止修改责任人配置；管理者仍可读取最小信息并通过既有空间入口取消归档。取消归档后重核当前事实，复审基准不会重置。删除预检查包含全部卡片引用，数据库空间外键RESTRICT提供最终保护；草稿、暂停卡片和保留历史都不能级联删除。

## 容量与事务

`kb.answer-card.search` 支持max-concurrent（默认/最大8）、per-user（默认/最大2）、budget-millis（默认/最大5000）及response-bytes（默认/最大262144）。非法配置拒绝初始化。搜索独立线程池无排队，容量满返回429及Retry-After；总预算耗尽或依赖故障503，不返回部分结果。每条SQL在搜索剩余预算内设置最多3000毫秒的语句与锁等待，编码后的响应受字节上限控制。

写入使用10秒READ_COMMITTED事务，锁和语句最多3秒。顺序为请求绑定锁、升序空间分类树共享锁、升序来源文档和版本共享锁、卡片、分支、活动审核、复审设置。锁后复读当前主体、来源和版本；审计与回执失败使业务事务失败。内存事务测试只验证Spring服务事务边界及失败处理，不证明数据库实际锁顺序、死锁处理或回滚。

## 发布合同

app提供`/api/answer-cards`业务，gateway明确路由到app，提前限制搜索16KiB、其他128KiB正文，所有响应no-store；跨域暴露X-Answer-Card-Version。成功协议头只能由实际业务生成。前端对缺头、旧结构或损坏响应显示不可用，不能把旧文档数组当卡片。

八项成功审计域统一以answer-card为目标，摘要仅含固定身份、状态、版本、日期和变化字段标记；原问题、答案、来源身份清单和驳回原因不得进入审计。命令核对、搜索和候选为只读，重放不增加成功事件。命令回执不是后续访问许可。
