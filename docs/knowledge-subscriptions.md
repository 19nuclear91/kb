# 知识订阅、个人更新与周报

2026-11-27已完成实现、离线核验、8份主规格同步及[变更归档](../openspec/changes/archive/2026-11-27-knowledge-subscriptions-and-digests/archive-record.md)，尚未部署。正式行为见[知识订阅](../openspec/specs/knowledge-subscriptions/spec.md)、[更新与周报](../openspec/specs/knowledge-update-digests/spec.md)及[用户界面](../openspec/specs/user-web-subscriptions/spec.md)主规格。

从导航的“知识订阅”添加文档、空间或标签订阅，也可从文档详情进入“订阅此文档的正式发布”。目标列表只包含你当前有阅读或发现资格的资源，管理资格不代替阅读资格。候选版本尚未发布时，具备该版本阅读资格的用户也可提前订阅文档。

## 生效规则

- 每人最多200条有效关系。已订阅目标不会重复建立关系；文档、空间及多个标签同时命中一次发布，只形成一条个人更新。
- 只记录订阅生效后的正式发布。上传、解析完成、资料修改、评论、补写说明都不单独生成更新。历史发布不会补发。
- 空间和标签按发布时归属匹配，之后搬迁、改标签不改变已记录的匹配依据。停用标签禁止新订阅，既有关系继续保留。
- 取消停止该代次尚未生成的提醒；同次发布的其他原命中订阅仍可支持提醒。个人更新及已经生成的通知、周报保留。
- 重新订阅建立新代次，不补发取消期间发布，也不会使旧更新重新获得提醒资格。

## 提醒频率

所有订阅共用个人频率，初始为每周汇总，也可改为逐次提醒。修改只影响之后发布；例如周三改为逐次提醒，周一、周二已记录的每周更新仍在原周报中，周三之后的新发布逐次提醒。

每周汇总使用北京时间，统计周一00:00（含）至下周一00:00（不含），从下周一09:00起生成。周内同一文档的多个发布归为一组，展开仍显示各次版本和发布时间。后台停机或积压会延迟送达，但更新继续归属于原统计周。无当前可读项目时不发空提醒。

“我的更新”包含两种频率的命中历史；“每周汇总”只包含已经生成提醒的周报。订阅匹配不是阅读授权，列表、文档组和数量始终按当前权限过滤。删除、归档、升密或撤权后可能不再显示；依赖故障显示不可用，不伪装成空列表。

## 说明和对比

更新详情固定指向此次发布版本，显示该版本当前最新的人工变更说明。未填写时明确提示；读取失败单独报错。补写和更正有标记，文字只按纯文本展示，不自动生成摘要，不把说明复制到通知正文。

对比采用人工说明原基准；无说明时可选最近可读旧发布。原基准不可读时不暴露其ID，也不改用其他版本。没有基准或缺少结构快照时会说明不可对比。打开更新、周报或原版本不自动标记通知已读，“标记已读”始终是独立操作。

## 网络结果未确认

提交后的响应丢失或等待超过15秒并不代表失败。页面保留原请求，提供“核对原回执”和“重试同一请求”；重试保持原目标、订阅代次、预期版本和请求标识。重新读取当前状态不能代替原回执。

尚未查到回执显示UNKNOWN，可能原事务仍在执行。显式放弃核对不会撤销已执行的操作，之后需重新读取并确认。隐藏页面、离开页面、退出或换号会清理本页私有内存；恢复后读取当前事实并重新确认，不自动重放写入。页面不把候选、标题、说明、请求或回执持久化到浏览器存储，也不发送到遥测或AI服务。
