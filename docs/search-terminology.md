### W4 修复：混合替换与扩展

歧义选择替换某处原词后，另一处已采纳术语可能合法补充该表达。2026-11-25 已修正前端校验：已选择位置只按替换后的标准名称判断是否存在；未替换位置及待确认建议继续按原片段判断。合成例：组 1 标准名 `PM`、别名 `项目`；组 2 标准名 `产品`、别名 `PM`。查询 `PM 项目` 并把第一处 PM 选为产品时，服务端计划为 `产品 项目\nPM`，前端现在接受第二处合法新增的 PM 及完整搜索结果。

## 公开范围与关系维护

- 词典为全公司公开、人工维护。启用名称、释义和关系可用于当前有效登录用户的搜索提示，不按空间形成私有词典。不要把不适合公开的资料写进名称或释义。
- 词条可见不表示存在可读文档；不会授予空间或文档权限，也不附带关联文档、命中数、查询历史或热度。
- 管理读取要求 `search:term:read`，创建、编辑、启停和本人回执核对要求 `search:term:write`，两项互不蕴含。普通搜索提示、管理员角色名称或其他管理权不能替代。
- 每个术语组有稳定身份、标准名称、释义和最多 20 个有类型别名：`SYNONYM` 为同义表达，`ABBREVIATION` 为简称，`FORMER_NAME` 为旧称。旧称仅表示检索关系，不表示旧制度仍有效。
- 名称、别名和错词去 Unicode 首尾空白、做 NFC，长度 1～64 个 code point；释义为 1～256。比较键只折叠 ASCII A～Z，内部空格保留，不自动转换简繁体、全半角或非 ASCII 大小写。非法 Unicode、控制字符和组内规范等价重复均拒绝，不截断。
- 标准名称按比较键全局唯一，停用组仍占用。不同组可共享别名，也允许一组别名等于另一组标准名称；同一表达关联至少两个启用组时是歧义，不按关系类型或创建顺序选定一组。
- 错词单独指向一个稳定术语组，正确表达使用目标当前标准名称。错词不能等于任何现存名称或别名，包括停用组；不是同义词，不支持错词链、反向扩展或模型猜测。

例如可登记“办公自动化”及简称 OA、旧称“旧办公系统”；把人工确认的“报消”指向“报销”；把 PM 分别登记为“项目管理”和“产品经理”的简称。共享 PM 合法，但新搜索不得自动合并两组。

## 字面匹配与原文位置

查询原文始终保留。仅用于比较的文本按完整扩展字素簇做 NFC 和 ASCII 折叠，匹配起止也必须落在完整簇边界。组合字符重排、Hangul Jamo、补充字符和包含连接符的 emoji 不会被截半。

原文位置为 Unicode code point 半开区间 `[start, end)`，不是 UTF-16 下标。例如 `😀OA` 中 OA 的位置是 `[1, 3)`。服务端回传完整原文片段，前端不自行猜测或重算词典关系。

- 中文可按字面子串匹配。表达首尾若为 ASCII 字母、数字或下划线，相邻字符不能也是这类字符。
- OA 可以命中 `oa流程` 和 `OA-流程`，不能从 `LOAD流程` 内部命中。
- 标点按字面处理，不解释为正则、通配符、拼音或编辑距离。相似但未登记的“报肖”不因此得到“报销”建议。
- 从左到右取最左匹配，同一起点取最长表达，再继续处理其后内容。最长片段的全部启用组仍须参与歧义判定，标准名称没有自动胜出权。
- 替换和扩展不会再次参与匹配，不能通过一个共享别名传播到另一组。

## 原始输入、确认替换与新增表达

计划区分三种文本：

| 字段 | 含义 |
| --- | --- |
| originalQuery | 本次搜索链最初、精确的用户输入 |
| effectiveQuery | 只替换用户明确选择的原文位置，其他文本逐字保留 |
| executionText | effectiveQuery 加上本次实际补充表达，供后续检索阶段统一使用 |

唯一术语关系自动纳入标准名称和当前无跨组歧义的别名，但不改写原输入。歧义或人工错词在确认前保持原词，只提供有界候选及释义。

`literal-append-v1` 不加入模板词或查询语言，每个补充表达前只有一个换行。按首次匹配位置、标准名称优先和别名比较键稳定排序；规范等价键只追加一次，已作为本次有效原文匹配或明确替换存在的表达不重复追加。同组重复位置保留各自说明，共享补充表达清单。

`appliedTerms` 表达已采纳的组及原文片段，其 `expressions` 只列实际新增表达；各项清单按稳定顺序去重后的并集与 executionText 的补充部分一致。已选择的标准名称可能已在 effectiveQuery 中，因此该项 expressions 可以为空，不能据此把明确替换显示为未采用。

下面使用合成词典说明规则：“报销”另有同义表达“费用报销”，“项目管理”另有“项目协调”。

| 输入与选择 | effectiveQuery | 实际补充表达 | 待确认 |
| --- | --- | --- | --- |
| `OA 使用说明` | 原输入不变 | 办公自动化、旧办公系统 | 无 |
| `旧办公系统入口` | 原输入不变 | 办公自动化、OA | 无 |
| `报消流程`，未确认 | 原输入不变 | 无 | 到报销的单向纠错 |
| `报消流程`，确认报销 | 报销流程 | 费用报销 | 无 |
| `PM流程`，未选择 | 原输入不变 | 无 | 项目管理／产品经理 |
| `PM流程`，选择项目管理 | 项目管理流程 | 项目协调 | 无 |
| `LOAD流程`／`报肖流程` | 原输入不变 | 无 | 无 |

即使已唯一采用“项目管理”，仍不补充其共享别名 PM。待确认选项的释义用于理解含义，不作为新的检索词，也不是文档语义的硬过滤条件。

## 累计选择与原词恢复

原查询含 `报消 报消 PM` 时，先确认第一个错词得到 `报销 报消 PM`，再选择最后一个 PM 的含义时提交**最初原文和累计两项选择**，得到 `报销 报消 项目管理`。中间错词仍待确认；第二次替换使用原文坐标，不使用已变长的 effectiveQuery 下标。

任一选择种类、位置或目标不属于当前完整候选时，整批拒绝，不先执行其他合法项。累计选择必须在同一修订下重新核验，不能把旧凭据当作当前候选或资源授权。

知识搜索页 `/search`：

- 点击建议只使用该次已提交的原始 query、全部空间／分类／标签／类型／时间筛选和数量，不夹带修改后未提交的草稿。
- “仅搜原词”主动提交 ORIGINAL，恢复最初原文和完整已提交条件，清空选择与上下文；不把当前 effectiveQuery 当作原文。
- ORIGINAL 计划不读取词典或凭据；采用关系、建议和选择为空数组，修订及上下文为 null。再次启用辅助须用户主动发起，旧选择不自动恢复。
- 签名上下文绑定当前身份、精确原文、完整规范化条件、数量和修订，有效期按数据库时间为 10 分钟。可信到期或修订变化拒绝采用，用户重新搜索；坏签名、换身份或改条件属于非法请求。
- 辅助故障、超限或过期不能触发自动重搜、放宽筛选、猜测新目标或自动切换 ORIGINAL。
- 查询上限默认 8000 个 code point，按当前前端配置校验并随已提交搜索冻结；采用和切换模式使用同一上限，不截断原文。服务端仍是最终判定，扩展后的表达另须满足全部辅助限额。

增强入口 `POST /api/search/assisted` 已接入本次已核验身份、共享预算与检索；每次完整成功带增强／筛选双版本头。页面遇到 404、405、缺头或不一致对象会整体拒绝结果，不转旧入口补搜。隐藏、离页、退出、改密及换身份会清空原文、条件、选择、凭据、结果和引用；恢复不自动搜索。

## 词典管理流程

`/admin/search-terms` 只按当前 `search:term:read` 加载，写动作另需 `search:term:write`，不依赖空间目录或管理员角色名称。术语组与错词映射分开查询，名称和状态草稿点击“查询词典”后生效，续页及重新读取沿用已提交条件；修订冲突废弃旧页，不拼接新修订。切换视图会结束旧等待并从目标目录重新读取。

术语组可创建、编辑名称／释义／最多 20 个有类型别名，共享表达可按需分页查看当前标准名称与释义。错词目标从启用术语目录选择，读取失败禁用内容保存，不允许手填 ID。自身启停与目标状态分别显示；目标停用时仍可独立停用错词。独立启停须确认影响，内容保存不顺带改变 enabled。

维护请求绑定完整规范化载荷、目标、前置版本和原请求标识。在途互斥；未知结果可“按原内容重试”或“重新读取核对”本人首次回执，不自动重发。本人回执 404、目录同值或当前实体版本都不能结清原未知结果。合法首次回执与之后刷新失败分别提示，刷新不改报保存失败。目录、草稿、选择、回执及未决意图只在页面内存中保留；隐藏、离开、换号或资格变化后清理，不自动恢复保存。

放弃核对或开始新提交会使旧回执核对失效；旧回执不能结清随后提交的新意图。目录、详情、共享含义、目标或本人回执收到 403 时，整页清理并重新核对资格；同资格仍被拒绝时不循环自动读取，可主动点击“重新核对词典资格”。恢复仅重新读取目录，不还原草稿或自动重放写入。

## 查询时生效与启停影响

首次成功维护使实体版本和全局 dictionaryRevision 各推进一次；匹配重放返回首次回执，不推进版本。目录当前读值与原首次回执分别表达，不能用重读相同值结清未知写结果。

后续词典计划的修订、时间、含义和扩展来自同一个短只读快照，计划生成后结束词典事务，再进入检索和模型阶段。维护不要求重新解析文档或重建向量；原词搜索不因词典维护而改变。

停用术语组使其名称、别名和指向它的错词建议退出新的辅助计划，但不改错词自身 enabled、不修改文档或授权。目标恢复后，只有自身仍启用的映射恢复可用；独立关闭的映射不自动开启。错词目标改名后使用其新标准名称。

已经取得修订 R 的在途计划可以按 R 完成并标明 R，后续采用按新修订重核。任何维护都使旧建议上下文失效，包括改动后恢复原值；不能声称已经显示给他人的文本已被撤回。

上述数据库运行效果未实测；本次只人工审阅 SQL 并使用事务、连接和结果集替身核对调用与投影。

## 固定限额与证据边界

辅助计划最多 8 个不重叠匹配、每处 8 个含义、8 项选择、32 个新增表达。新增文本和每项换行共同不超过 2048 个 code point，最终 executionText 还须满足本次配置的查询长度上限，当前默认 8000。发现第九匹配或含义、第三十三个表达或其他超限即拒绝，不截断成表面成功。

可靠的空词典或零匹配可以生成恒等计划，读取故障不能伪装空建议。TERMINOLOGY 默认 1000 毫秒，凭据、全部快照批次及 CPU 工作共用原搜索总截止、取消和实际退出容量；批次上限不是数据库扫描成本或真实时延保证。

本次验证纯规则、完整计划、精确数值投影、独立服务及传输替身、模拟 DOM 交互和静态构建。固定合成词典的 12 个查询样例分别核对匹配位置、有效原文和新增表达；没有真实业务语料或 topK 排名承诺。

BM25 参数、单个 QUERY 向量和 rerank 的统一表达通过独立编排与传输替身核对；页面交互通过模拟 DOM 测试。真实网络出站、数据库约束与快照、驱动取消、浏览器和排序收益均未验证。关键词能否提高召回或进入 topK 不能由本次离线测试推断；未验证事实不恢复为本变更的隐藏测试或归档前置条件。
