# 用户端

独立 Vue 3 / TypeScript 6 / Vite / Element Plus 工程，路由使用 vue-router 5，会话与管理资格通过 Pinia 暴露，组件统一使用 `<script setup lang="ts">`。要求 Node.js 24+、npm 11+。依赖版本与锁文件一并提交，构建不属于 Maven reactor。

从仓库根目录执行：

```powershell
Set-Location .\kb-web
npm ci
npm run typecheck
npm test -- --run
npm run build
```

单元测试仅使用内存替身和模拟 DOM，不启动应用、浏览器、数据库、Redis、MinIO 或模型服务，不测试说明文档内容。

类型检查由 `vue-tsc --noEmit` 完成；组件测试使用 `@testing-library/vue`、Vitest 与 jsdom，文件统一为 `src/**/*.test.ts`。`src/test/render.ts` 提供 Pinia/内存路由宿主和 Element Plus 交互辅助。`vite.config.ts` 的 Element Plus 测试内联配置用于正确处理 `async-validator` 默认导出，确保非法表单输入确实被拒绝。

会话和管理资格 facade 保持对象引用，在渲染、`computed` 或 `watch` 中读取当前属性，避免解构成快照；文档操作和评论使用子树级 `provide/inject`。外部核心对象与写入 Binding 保持原始身份，使用浅响应式容器桥接。组件显式导入 Element Plus，生产样式按需注入，根部提供中文语言包；正文只以文本插值展示，静态检查禁止 `v-html`。

## 构建与包体分析

包体分析使用当前源码生产构建；`dist` 只保留发布资产，manifest 和有效模块归属清单保存在本地 `.bundle-analysis`。首轮拆分的正式基线与候选报告已归档；日常检查在本目录执行以下命令，输出到本地目录：

```powershell
npm run bundle:test
npm run build
npm run bundle:report -- --check-isolation --out .bundle-analysis/current-report.json
```

与本次 Vue 迁移的 React 基线比较时，使用基线记录的 Node/npm、production 模式及公开构建开关。框架替换必然改变锁文件，须显式登记这一差异；`lifecycle` 是本轮补入报告的场景，旧报告没有独立基线：

```powershell
npm run bundle:report -- --baseline ../openspec/changes/archive/2026-11-08-migrate-web-to-vue3/bundle-baseline.json --allow-lock-change --new-scenarios lifecycle --check-isolation --check-growth --out .bundle-analysis/comparison-report.json
```

报告按 HTML 入口及递归静态依赖统计冷启动集合，动态页面只计入对应路由；共享 JS/CSS 按最终文件名去重，每个文件分别以 gzip level 9、Brotli quality 11 压缩后求和。路由报告包含累计及增量字节、文件数、有效项目模块归属和构建身份。缺少资源/模块映射或未经显式登记的基线条件差异会失败；`--allow-lock-change` 只允许锁摘要不同，两个摘要均写入报告，其他条件仍严格核对。`--check-growth` 要求入口、登录与文档列表累计 gzip 不超过基线 10%；旧的 `--check-reduction` 仍可用于同条件优化的严格下降检查。新增无基线场景只记录候选值，不能豁免门槛场景。公开开关仅记录白名单，报告不收集私有环境变量。

知识需求扩展新增 `knowledgeGapList`、`knowledgeGapNew`、`knowledgeGapDetail` 和显式打开的 `knowledgeGapFeedback` 场景。与不含这些场景的旧基线比较时，须将它们一并登记到 `--new-scenarios`，不能以新增场景绕过入口/登录/文档列表门槛。隔离检查仅允许入口使用极小的知识问题地址白名单助手，不允许提前包含问题 API、表单、详情或反馈弹窗实现。

Vue 切换后的入口/登录、文档列表、文档详情累计 gzip 分别为 126,896、232,444、256,878 字节；前两项较迁移基线减少 43.28%、34.52%，隔离与 10% 门槛通过。完整结果见[迁移验证记录](../openspec/changes/archive/2026-11-08-migrate-web-to-vue3/verification.md)。

首轮优化后，入口/登录、文档列表、文档详情累计 gzip 分别为 223,276、354,522、383,591 字节，相比原单包下降 45.50%、13.47%、6.37%。完整 26 个场景及测试范围见[归档实施记录](../openspec/changes/archive/2026-11-06-frontend-route-lazy-loading/verification.md)和[核验报告](../openspec/changes/archive/2026-11-06-frontend-route-lazy-loading/verification-review.md)。后续优化应在修改前为对应变更建立新基线，保留本次归档数据；依赖或运行环境变化后不能直接沿用历史比较条件。

企业 SSO 按明确文件名单执行独立单元测试，命令及范围见 [企业 SSO 前端](../docs/enterprise-sso-web.md)。

AI 用量与调用审计入口为 `/admin/ai/usage` 和 `/admin/ai/audits`，分别按 `ai:usage:read`、`ai:audit:read` 放行；页面状态仅保存在内存中。筛选、统计口径、托管与验证名单见 [AI 管理页面](../docs/admin-ai-usage-web.md)。

开发配置参考 `.env.example`。需要本机开发时自行运行 `npm run dev`，`/api` 按 `KB_WEB_GATEWAY` 代理到网关；这不是本变更的验证步骤。生产使用同源静态托管，页面路径回退到 index.html，`/api/**` 保留真实 HTTP 响应。

`VITE_CONVERSATION_ENABLED` 为公开构建开关，缺省 false。与 app/AI 的会话配置对齐，不得在 VITE 变量中配置密钥。开启但模型未配置时显示暂不可用。

## 路由加载与恢复

登录、强制改密和 `/auth/sso/result` 随入口直接加载。确认身份并选择业务页面后才下载该页模块，文档列表/详情、账户及管理页面分别加载；菜单显示、悬停和空闲不会主动下载页面。加载状态只占用内容区，导航与退出仍可操作。切页、退出、换号、改密及后台恢复继续清理旧内容并重新核对资格。

页面资源下载失败时显示“页面资源加载失败”，页面自身渲染异常另行提示。可直接离开，也可主动点击“刷新页面”；刷新会丢失未保存输入，并沿用原有身份确认和安全返回规则。不会自动刷新、重试下载或重放上传、删除、审核、改密、生成、SSO 交换和管理写入；已提交操作可能继续在服务端处理，应按原页面规则核对结果。

管理页面只在现有守卫确认入口资格后开始下载，下载成功或代码已缓存不代表当前用户具有管理权限。空间/文档详情仍核对目标资源，AI 用量和调用审计分别授权，运营报表不依赖空间目录。发布时先上传新哈希资产，再原子切换 HTML，保留旧资产供已打开的标签页使用；回退也保留被回退版本的资产。HTML 缓存、真实 404 与保留窗口见[静态托管说明](../docs/user-web-operations.md)。

## 登录与账户

通过本地用户名密码或服务端已启用的钉钉、企业微信、飞书连接登录，默认进入文档中心。企业目录未启用或暂不可用时，本地登录独立保留。企业授权在当前标签页继续，后端回调后进入固定 `/auth/sso/result` 页面。服务器要求改密时先完成原密码、新密码和确认密码表单；此期间不加载业务数据。账户页展示服务器 me 返回的本人摘要，可自助改密与退出。改密结果不确定时，相同表单内容重试会保留首次请求标识。

当前标签页的 sessionStorage 保存最小 satoken 凭据及短期、非敏感的企业授权与站内导航提示，刷新时重新确认 me；不保存密码、身份快照、授权码、state、搜索词、文档正文或聊天历史，不提供长期记住登录或离线阅读。退出立即清理本地凭据和活动请求；远端注销未确认时页面会明确提示。普通保护请求 401 要求重新登录；本人绑定密码验证的 401 先核对当前身份，有效会话继续保留。业务 403 最多核对一次身份，正常身份的业务拒绝不会循环登录。

个人账户显示三家连接是否启用、本人是否已绑定。仅在连接启用且未绑定时，可输入当前本地密码主动开始绑定，提交结束立即清除密码；成功不切换本平台登录身份。未绑定的企业登录会引导先登录本地账号并完成改密，再到账户重新发起绑定授权，不自动建号或复用旧授权。解除绑定或处理身份冲突请联系管理员。

结果交换只发送一次，刷新或重复挂载不会重发旧交换。登录结果丢失且未取得令牌时需重新授权；已保存令牌而 me 暂不可用时只重新确认身份。绑定结果未确认时可进入账户读取当前绑定事实，不把当前状态作为旧请求回执。同一浏览器新发起企业授权会替代之前的授权，不支持多个标签页独立并发完成。详细恢复与部署约定见 [企业 SSO 前端](../docs/enterprise-sso-web.md)。

## 文档与上传

全部文档包括通过文档例外授权可见的内容。空间下拉仅作为筛选，管理空间不等于可读。上传弹窗独立读取可编辑空间，允许仅有编辑资格的空间；候选可继续翻页。密级来自实际字典，显示真实数值，不固定级别集合。

选择 PDF、UTF-8 TXT/Markdown（.md）或常规 Office 文档，当前客户端上限为 50 MiB，实际大小、内容签名与格式校验以服务器为准。标题、空间和密级通过 multipart 请求体提交。上传、新版本和失败重试提交期间锁定，网络结果不确定时不自动重传，应先核对列表或处理状态。

上传受理不表示已发布或可检索。页面按返回的版本 ID 跟踪进度；V2 处理中时当前发布可能仍为 V1。详情可选择版本，分别查看排队、处理中、退避等待、维护等待、解析完成和失败；不显示虚构百分比。维护等待不是解析失败，截断及问题摘要会单独提示。

仅有编辑权限的上传者可能无法查看提交结果，页面保留成功受理提示并停止不可访问的进度查询。下载、新版本上传和重试按钮分别服从实时操作能力；能力暂不可确认时禁用相关操作。只有任务状态允许时才能重试选中版本，点击时仍可能因资格变化而被拒绝。后台页面与离开页面暂停查询；临时查询故障最多重试三次，401/403/404 停止。

详情页提供“重新核对操作资格”，同时重读文档及独立操作能力；相关资格在读取失败或未完成时保持禁用。新版本上传 403/404 后立即暂停提交，并重新核对；若文档仍可查看且新的 `canUploadVersion=true`，可由用户主动再次提交，否则维持暂停并提供“重新核对上传资格”。核对不会自动重传，也不证明原上传请求是否成功。普通新文档上传仍使用可上传空间和密级字典，不从阅读或管理权限推断编辑资格。

下载拒绝不等于阅读拒绝：详情会关闭旧预览并重核文档、能力和选中版本。仍可读的历史版本可以留在当前选择中，下载则继续服从独立资格；不会因一次下载 403/404 持续隐藏可读版本，也不会自动切到最新版本、下载或重新打开预览。重核故障可以主动重读，真实阅读拒绝则清理对应旧文件入口；文档、版本、身份切换或页面隐藏后的迟到结果不能恢复旧内容与资格。

文档详情的“删除文档”需要当前可查看且具备 edit 资格，只有服务返回 `canDelete=true` 才可用；旧服务缺少该字段时禁用。确认前重新读取文档及资格，删除影响整份文档和全部版本，取消未完成处理及审核，当前无法恢复；选中历史版本或尚无发布版本不改变范围。确认期间暂停本页新写入，已有上传、重试、审核、评论和收藏写入须先结束；结果未确认的既有操作会要求再次明确确认。取消尚未提交的删除确认可恢复交互。

只有 DELETE 合法成功响应才提示“文档已删除”并返回重新读取的文档中心；列表读取失败单独处理。删除响应丢失、超时或服务故障显示结果未确认，不自动重发。可主动“核对当前状态”：404 只表示当前不可访问，200 只表示当前仍可访问，均不是原删除回执。再次删除必须有新的 `canDelete=true` 并重新确认。离开、隐藏或退出只停止本地等待，不撤销服务端操作；恢复不重发删除。结果提示只保存在当前会话的短期内存中。

## 批量文件导入

批量清单支持本地多选和拖拽，统一选择当前可上传空间与真实字典密级，每项标题默认文件名，可编辑和移除。目录、ZIP 与外部链接显示不支持；无效文件不会静默跳过。能力值来自服务端，摘要通过单并发、可终止 Worker 计算，离页停止。

点击“核对清单并开始上传”后固定完整意图，创建成功后在原页面继续上传，不靠切换路由保留 File。相同项只受理一次；同批不同项和新批次允许同名同内容的新文档，不能以摘要覆盖原文档或自动创建版本。

创建结果未知时仅提供只读核对和原绑定主动重试；没有可信批次身份不发送文件。上传最多两个在途，单项失败不回滚其他项；“暂停后续上传”只停止新增发送，已发请求仍需核对。429 使用上传容量提示，不自动重试。

已受理只是原件、版本和解析任务已保存，不等于已解析、已发布或可检索。文件和清单草稿只留在内存，刷新、隐藏、换号和离页后重新读取任务，再选择未完成的匹配文件并主动继续。协议与故障处理见 [导入 API](../docs/document-import-api.md) 和 [导入运维](../docs/document-import-operations.md)。

主导航“我的导入任务”及文档中心“批量导入文件”进入 `/imports`，历史详情 `/imports/:importId` 可直接访问、刷新及合法登录返回。列表与文件项使用服务端游标分页；待上传、处理中、已受理、失败计数来自同次任务摘要，本页回执待确认数量单独展示，不伪造服务端失败。

重新登录后原任务仍属于原账号，无需保存浏览器清单。未完成项需明确选择对应序号的文件，按规范化名称、大小及 SHA-256 匹配；同名同大小异内容拒绝，替换文件必须新建意图。匹配本身不发送，点击“主动继续已选文件”或单项继续才使用最新 revision 和新请求标识。已受理与处理中项不重传。

待确认／处理中项每 3 秒有界核对，连续 3 次失败或 3 分钟结束后停止，提供手动核对。身份拒绝、空间资格失效和 429 暂停新增发送；清单字段被省略时清除旧文件描述和本地选择，仅保留本人最小历史。恢复资格后重新读取、重选并主动继续。固定版本的处理状态按按钮单独读取，没有 view 时显示“已受理，当前无法查看处理状态”，不持续轮询拒绝或改报上传失败。

摘要或任一文件项读取先显示上传资格撤销时，立即清理整个任务的旧描述、其他已加载页的选中文件及目标空间／密级。资格变化独立于项 revision 和 Session epoch：旧成功读取、上传回执或摘要结果不能重新启用文件选择；较新的已受理事实与固定回执继续保留。

隐藏、换号、身份核对及离页卸载私有页面、终止摘要和本地等待；回来先确认身份，再读取任务，不自动恢复上传。导入草稿、文件、摘要及回执不写 localStorage、sessionStorage 或 IndexedDB。

`batch-document-import` 已同步主规格并于 2026-11-08 归档。修复后导入模块 **9 个文件、43 项**离线测试通过，独立复核的 **2 项**实际 Session/API 与内存传输实验通过；类型检查、生产构建与包体隔离通过。导入列表／创建页及详情页累计 gzip 分别为 **178,023 / 137,925 bytes**，入口和文档列表不会提前加载导入实现。结果、场景映射和验证边界见[实施记录](../openspec/changes/archive/2026-11-08-batch-document-import/verification.md)与[核验报告](../openspec/changes/archive/2026-11-08-batch-document-import/verification-review.md)。

## 文档资料与组合筛选

详情的“编辑资料”独立要求 `canEditMetadata=true`，可修改标题、人工摘要、本空间单分类及至多 20 个已有标签。资料保存立即作用于整份文档；选择历史文件版本或文件仍在审核中时，编辑的仍是当前资料。停用标签保留已有关系，可主动移除，不因候选列表省略而自动删除。

文档中心使用 POST 请求体组合筛选：标题字面关键词、空间、分类（含后代）或未分类、多个标签全部匹配、当前发布文件类型及更新时间。草稿点击“应用筛选”后生效并回首页；翻页沿用已提交条件。切换空间清除分类选择，关键词和目录仅留在页面内存。

保存冲突时重新读取并人工确认；结果未确认时“按原内容重试”保留原版本、内容和请求标识。“重新读取核对”只读取现状，不证明旧提交结果。成功后的重读失败单独显示，已确认保存仍保留。保存参与详情页删除互斥，关闭页面不撤回已发出的请求。

空间详情提供分类管理；全局标签入口 `/admin/document-tags` 要求 `document:tag:read`，维护另需 `document:tag:write`。搬迁必须取得新上下文并显式选择目标分类或未分类。完整使用与恢复说明见[文档资料、目录与筛选](../docs/document-metadata-web.md)。

## 我的收藏

主导航的“我的收藏”位于 `/favorites`，登录并完成必要改密后可直接访问或刷新，不依赖 AI 会话开关。文档列表、详情和搜索结果均可收藏或取消；同页同文档按钮共享状态，提交期间共同禁用。收藏保存在本人账号下，跨登录保留。

收藏页按收藏创建顺序倒序显示当前可查看的文档，可“更多收藏”续页、“刷新收藏”重读首页，取消成功后移除该项。点击标题进入文档详情读取当前版本；尚无当前版本时显示“尚未发布”。在搜索结果中收藏不会改变原片段的排序或引用版本。

状态读取失败时按钮显示待确认，可主动“核对收藏状态”；写入结果不确定时不会自动重发，核对只说明当前状态。撤权、升密、空间归档或删除后的文档在下一次授权读取时隐藏，未取消的关系在权限恢复后重新可见。退出、切换账号及页面恢复时清理旧页面状态并重新确认身份。

收藏 API、迁移、白名单验证记录及前后端/网关发布回退顺序见 [个人文档收藏](../docs/document-favorites.md)；静态托管见 [用户端运维说明](../docs/user-web-operations.md)。

## 知识需求与问题处理

`knowledge-gap-feedback-loop` 的普通问题页面、反馈、处理、受理管理、新通知界面、网关及生产日志配置已接入，离线验证已完成，2026-11-14 已同步七份主规格并[归档](../openspec/changes/archive/2026-11-14-knowledge-gap-feedback-loop/)。前端合同见[普通问题界面主规格](../openspec/specs/user-web-knowledge-gaps/spec.md)和[受理界面主规格](../openspec/specs/admin-web-knowledge-gaps/spec.md)；后端/API 与保留边界见 [知识问题单 API](../docs/knowledge-gap-api.md)、[问题运维说明](../docs/knowledge-gap-operations.md) 和 [协调发布清单](../docs/knowledge-gap-rollout.md)。最终前端为 113 文件/1291 项 jsdom 单测、类型检查、生产构建和包体隔离通过，实际证据见[归档验证记录](../openspec/changes/archive/2026-11-14-knowledge-gap-feedback-loop/verification.md)；本轮未部署，离线通过及归档不等于上线验收。

- 主导航“知识需求”进入 `/knowledge-gaps`，默认查看本人问题；新建为 `/knowledge-gaps/new`，详情为 `/knowledge-gaps/:gapId`。支持直接访问和合法登录返回，不依赖 AI 开关。地址只携带合法 ID，不能用正文、筛选、候选名称、未注册后缀或片段作为登录返回。
- 搜索的“反馈知识需求”只预填实际已提交的本人搜索词；已保存且终结的问答轮次可“反馈此提问”，仅预填自己的原问题。生成中/未核对保存的临时内容无轮次反馈入口；不会附带回答、引用、会话/轮次/搜索身份，也不因故障自动创建或断言知识缺失。
- 提交前可自由编辑预填描述，明确确认原提问者、当前合格处理人和授权受理人员的分享范围。描述/方案最多 4000 个 code point，说明/原因最多 2000，超限须自行缩短，不静默裁剪。取消未发送表单不创建、不保存草稿，也不改变原搜索或会话。
- 已分享业务记录会保留；**撤回停止处理，不等于删除**，不能收回他人已经读取的内容。首期不提供编辑/删除正文、隐藏内部评论或终态重开。删除原会话不会删除独立分享的问题记录。
- “分派给我”须当前显式 `knowledge:gap:handle`，只显示当前分派；角色名称和身份目录资格不替代。当前合格负责人可提交说明型或固定资料型方案、带原因退回受理；允许的参与者可追加共享说明。问题能力与资料权限分开，不补 ACL、不调用模型或自动上传。
- 资料只从问题作用域的 POST 候选中选择本人当前可读的已发布固定版本，实际提交再核验双方资格。打开资料重新鉴权原版本，不替换最新版、不自动下载；资料失效隐藏其身份/标题，明确分享的人工文本仍按问题范围可读。
- 六态分别为待受理、处理中、待确认、已解决、已关闭、已撤回。只有原提问者针对当前方案明确确认才解决；资料不可用不能宣称确认成功，仍可说明未解决或撤回。待确认、人工关闭、撤回、通知已读和等待时间都不是本人确认事实。
- 每次修改固定目标、动作、版本、方案和原请求标识，同页同步互斥。未知结果不会自动重发：可重读事实，或显式按未改动的原内容匹配重试；创建改输入须重新确认并使用新标识。409 清理旧输入并重读，不覆盖新状态或确认新方案；退回后 404 清理原内容，由当前合格受理人员核对，不延续历史访问。
- 隐藏、离页、退出、换号、强制改密、目标或资格改变清理描述、方案、候选、草稿及绑定，恢复先核对当前身份。刷新只重新读取，不恢复或重发命令。正文、候选名称、草稿和回执仅驻当前身份内存，不进入 URL/history、浏览器持久存储、日志或遥测；HTML、脚本和远程图片标记仅作为纯文本展示。

该组验证仅使用 Vitest/jsdom、内存身份/transport、受控 Promise 和模块加载，外加类型检查与包体脚本单测，不包含真实浏览器、前后端联调或数据库验证，也不运行本文等说明文档的断言测试。

### 统一受理与接管

`/admin/knowledge-gaps` 及其正整数详情仅按当前 `knowledge:gap:read` 开放，不依赖可管理空间或身份目录；只有 assign/close/handle 不能进入受理页面。状态筛选和游标由服务端执行，读取故障不显示为零待办。负责人不再合格时只显示“需人工重新分派”，不暴露离职、停用、角色或部门原因，也不自动改派。

分派另需 assign 和当前问题能力，仅从 POST 最小候选选择人员；名称或资格改变清空原选择。改派清除待确认方案的当前身份但保留历史，不能确认旧方案。关闭另需 close、原因及明确影响确认，只记录已关闭，不代替提问者解决。全部操作按当前版本和同页互斥执行；未知结果先重读或原内容显式重试，恢复不会自动重发。

## 站内通知

主导航“站内通知”位于 `/notifications`，展示发给本人的审核、评论回复和知识问题提醒。新列表和导航未读数一致发送 `X-Kb-Notification-Contract: KNOWLEDGE_GAPS_V1`，故障不去头降级；缺省旧客户端只见旧四类及旧计数，新旧游标不混用。导航默认 60 秒刷新（`VITE_NOTIFICATION_POLL_MS`，最低 30 秒），后台/离线停止并清理旧数，失败显示待确认而非假零。

“打开目标”按原文档版本/轮次/评论或相同问题 gapId 重新鉴权。问题改派、失权或状态已变化时以详情重读为准，不恢复旧正文或确认旧方案；点击不自动标记已读或执行处理。已读是本人通知首次已读事实，不等于审批已处理或提问者确认解决。页面只显示本地固定提示，问题目标不含描述、资料身份或外链。详见 [站内通知](../docs/in-app-notifications.md)。

## 搜索与引用

知识搜索使用 POST 请求体，关键词必填，可叠加空间、分类（含后代）或未分类、最多 20 个标签、当前发布文件类型和更新时间。条件按 AND 组合，标签全部匹配，最多展示 20 条相关片段。编辑草稿和“清除筛选”不会自动搜索，点击搜索才统一应用，结果旁标明已提交条件。

分类按所选空间分层读取，切换空间清空分类及未分类，保留全局标签。候选只来自本人可检索的已发布资料；全局标签包含仍有关联的停用项，不随关键词或其他条件动态收窄，候选出现不保证最终命中。文件类型按当前发布版本判断，不提供未发布类型；更新时间含起点不含终点。

候选故障可主动重读，不自动删除既选条件。带限制的成功响应必须通过筛选版本头确认，缺头或未知版本不展示材料、查询收藏或打开引用；明确清空限制后可使用旧版无筛选搜索。空结果、目录故障和搜索故障分别显示。协议、发布与回退顺序见[知识搜索组合筛选](../docs/search-filtering-api.md)。

公开构建配置 `VITE_SEARCH_MAX_QUERY_CODEPOINTS` 默认 8000，补充字符按一个 code point 计算；超限、NUL 或孤立代理项阻止发送，不截断。服务端限制是最终判定。搜索 400/413/429/503 分别提示输入无效、搜索请求过大、搜索过于频繁、检索暂不可用，Retry-After 不会触发自动重发。关键词、筛选和游标仅存页面内存；离页、隐藏和身份切换清理草稿、目录、结果及引用。恢复重新核对身份和读取目录，搜索需重新输入后主动提交。

引用抽屉始终按文档、版本、分块三元组读取原版本。来源章节与页码只作提示，未知时保留未知。片段当前不可用时可使用服务器提供的原版本文件入口；缺少版本身份时不能定位，不补成最新版本；404 会清除旧片段和入口。

预览仅支持 PDF 和 UTF-8 纯文本/Markdown，Office 等格式可能返回 415；Markdown 按安全文本展示。下载需要独立 download 资格。预览与下载都通过带认证头的同源请求获取文件，不把令牌拼入链接。临时 Blob URL 在关闭、切换、拒绝或退出时释放；已经取得的文件无法从用户设备撤回。

## 会话、生成与停止

会话开关关闭时不请求会话数据。开启后如未配置多轮模型，生成显示暂不可用并保留输入；单个会话的 404 不会关闭全局助手。页面不调用旧单轮占位接口。

侧栏按服务器固定创建顺序分页，活动更新不改变分页位置。标题使用显式输入或服务器默认“新会话”，不会从正文自动生成。创建结果丢失时，相同标题重试保留原创建请求标识。

历史按服务端轮次序号展示和合并。被屏蔽的回答清除全部助手正文和引用，仅保留响应允许展示的本人问题。失败、取消、中断的轮次显示未完成，只显示已保存前缀；生成完成与用量结算分别显示，真实用量未知不作为零，额度扣除独立列出。

每轮只发送本次原问题、请求标识和预期序号，最多 8000 个 Unicode 字符，不静默截断。活动轮次限制新提交，409 时刷新事实并保留输入，不自动循环发送。提交结果不确定时“匹配重试”保留原三元组；明确选择“主动重新发送”才按最新序号创建新标识。

首次响应按 SSE 接收；匹配重放 JSON 只用来读取对应持久轮次，不重复订阅生成流。停止会关闭本页连接并核对已保存状态，完成与取消竞争时以服务器为准。done、error、畸形流及无 done 的 EOF 都重新核对持久轮次；仍 RUNNING 时最多核对六次，到限提示稍后刷新。没有轮次 ID 时不会虚构已受理记录。离开会话关闭连接，再次打开时读取事实；退出后停止保护查询。

SSE error 可选 `code=SEARCH_UNAVAILABLE` 显示固定检索不可用提示；缺失或未知 code 使用通用错误流程，不显示服务端任意 message。检索故障不显示无结果成功回答，仍需核对持久轮次。停止接收不证明服务端检索已退出或供应商计算已取消。

生成中的文字尚待保存确认，刷新读取的前缀会替换临时内容，不承诺续传或补全未保存尾部。参考材料表示本轮材料，不是对回答的逐句证明。删除前确认目标，先关闭当前连接；204 视为成功，拒绝或不确定时提示刷新核对，不自动重复删除。

页面恢复或重新聚焦时遮蔽旧内容并核对身份，再读取受保护资源。正文中的 HTML、图片及链接标记作为文本展示，不执行 HTML 或请求远程资源。部署、路由、CSP 和回退说明见 [用户端运维说明](../docs/user-web-operations.md)。

## 身份管理

审计查询入口为 `/admin/audits`，独立要求当前 `audit:read`；支持管理、本地登录及企业 SSO 事件的精确筛选、固定时间窗口续页与安全详情。默认最近 7 天，自定义最长 31 天，筛选和结果只保留在当前页面内存。使用、权限、恢复与验证边界见[审计查询管理页面](../docs/admin-audit-web.md)。

管理区同时提供 `/admin/spaces`、`/admin/spaces/:spaceId`、`/admin/documents` 和 `/admin/documents/:documentId`。知识空间入口由当前可管理空间或独立建空间/全局管理资格开放；文档管理面板入口在上述任一条件成立或持有 `document:security-level:write` 时显示，索引页只提供文档 ID 输入并跳转到面板，不发出管理请求、不枚举文档、不保存历史，入口显示不代表任何文档可管理，面板各区块（例外授权、搬迁、删除按管理清单，密级按功能权限）独立判定；文档详情按已确认资格显示管理入口。生命周期、上下文候选、例外授权、搬迁、删除和密级规则及已知限制见[知识空间与文档管理](../docs/admin-space-document-web.md)。

空间授权支持多主体 × 多权限位，最多 50 个主体、6 个权限位；已选清单跨主体类型与搜索保留，可逐个移除，候选故障时不能新增。提交前确认主体数、权限位数与授权总条数，整批经单次写入提交；成功逐条标明新增或已存在，并汇总密级受阻主体数。待核对时关闭弹窗或同身份资格重核不会丢失原请求标识，重开仍须按原内容重试、重新读取核对或显式放弃；绑定在会话内按身份与空间隔离，身份切换清空。批量接口返回 404/405 时提示“当前服务不支持批量授予”并保留选择，即使 1×1 也不回退为单条调用，撤销和列表不受影响。部署先后端再前端，回退前端恢复原单条授予交互。文档例外保持单选单条，切换条件或候选故障清空选择。

空间授权列表支持勾选显式条目后批量撤销，每批 1–300 条；manage 行需 `space:grant-manage` 才可选择。确认展示总条数与 manage 条数，本人提示仅识别当前用户 USER 类型的直接 manage，不推断角色或部门资格；选中全部直接 manage 时另行提示，两类提示均不阻止提交。成功逐条显示已移除/原本不存在及计数，清空选择与旧授予回执并重读列表和资格。结果待核对时，关闭重开仍保留原请求；即使当前列表已为空，也可按原内容重试，或重读/放弃核对。404/405 显示“当前服务不支持批量撤销”，只禁用批量撤销，授予、列表与单条撤销仍可用，不逐条补发。文档例外保持单条撤销，无多选入口。

管理区与用户端同一工程、同一登录与静态托管，入口为 `/admin/users`、`/admin/departments`、`/admin/roles`，分别需要 `identity:user:read`、`identity:dept:read`、`identity:role:read`。导航只显示有读取资格的入口；本人权限按完整 code 判断，不依据角色名称。写操作和部门/角色候选另需对应权限，缺少候选资格时禁用并说明，不提供手工输入 ID。完整权限矩阵、页面规则与错误分类见 [身份管理 Web 说明](../docs/admin-identity-web.md)。

工程约定：管理代码集中在 `src/admin`，复用 `Session`、`api.ts` 的安全 JSON 编解码、Pinia 管理资格与 `src/ui` 的共享 SFC。读取拒绝状态和成功回执只在当前会话 epoch 内保留，资格事实变化允许重新读取，身份切换立即清空。

- `access.ts` 与 `src/stores/adminAccess.ts`：本人权限 facade 与 Pinia store，随保护布局 attach/detach，与会话 epoch 对齐；`AdminGuard.vue`、`AdminNavigation.vue` 分别负责守卫与导航。
- `api.ts`：管理 DTO 路径、写意图构造、`adminWrite` 与有界错误消费。
- `hooks.ts`：`useAdminWrite`（请求标识绑定、互斥、不确定结果）、`useAdminResource`、`useCursorList` 等组合式函数。
- `WriteNotice.vue`、`AdminModal.vue`、`PasswordFields.vue`：写入状态提示、操作弹窗和密码输入；`ui.ts` 保留共享结算辅助。

管理写入一律经 `useAdminWrite`：请求标识只放 `X-Request-Id`，结果不确定时只允许按原内容重试或重新读取核对，不自动重发；ID 与 version 按精确整数回传。
