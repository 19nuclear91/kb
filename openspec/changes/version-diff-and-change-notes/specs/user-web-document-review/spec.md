# Spec Delta

## ADDED Requirements

### Requirement: 审核工作台必须提供与当前发布版本的对比入口

审核工作台 SHALL 在调用者可读取所审版本、文档存在当前发布版本且不是所审版本时，提供“与当前发布版本对比”入口，以当前发布版本为基准、所审版本为目标打开对比页。入口只使用当前审核状态响应中的精确版本 ID，不推断最新版本；对比结果不改变审核状态，也不替代审核决定。

#### Scenario: 审核人对比待审版本
- **WHEN** 合格审核人打开 IN_REVIEW 的 V2，而 V1 为当前发布版本
- **THEN** 页面提供以 V1 为基准、V2 为目标的对比入口

#### Scenario: 文档尚无发布版本
- **WHEN** 所审版本是文档的第一个版本，文档没有当前发布版本
- **THEN** 页面不显示对比入口

#### Scenario: 只能查看本人最小状态
- **WHEN** 上传者没有所审版本的读取资格
- **THEN** 页面不显示对比入口或说明内容

### Requirement: 审核界面必须只读展示所审版本的变更说明

审核界面 SHALL 在固定版本及轮次的上下文中，按当前访问资格读取并只读展示所审版本的变更说明及其基准版本。活动审核期间明确提示“审核期间变更说明已冻结，修改需先撤回”，不提供修改入口。说明读取失败只显示“变更说明暂不可确认”，不阻止查看、对比、批准或驳回，也不显示为没有说明。

#### Scenario: 审核人查看说明
- **WHEN** 合格审核人打开有说明的 IN_REVIEW 版本
- **THEN** 页面显示说明文本、基准版本和冻结提示

#### Scenario: 说明读取失败
- **WHEN** 审核界面读取说明返回 503
- **THEN** 说明区域显示暂不可确认，审核决定操作按原规则可用
