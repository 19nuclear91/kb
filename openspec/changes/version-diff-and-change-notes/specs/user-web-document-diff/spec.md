# Spec Delta

## Purpose

为审核人和读者提供同一文档两个版本的对比页，按服务端结果展示结构差异、关键数值变化、解析质量提示和变更说明，并把无法对比的各种原因分别说清楚，不以猜测或空结果掩盖。

## ADDED Requirements

### Requirement: 对比页必须绑定明确的文档和两个版本

用户端 SHALL 提供 `/documents/{documentId}/compare/{baseVersionId}/{targetVersionId}`，在当前身份和路由资格确认后按需加载，支持直接访问、刷新和合法登录返回。三个 ID MUST 为正整数并原样用于请求，两个版本相同时不发请求。页面不推断最新版本，也不按连续版本号补查。

#### Scenario: 直接打开合法链接
- **WHEN** 已登录用户打开指向两个可访问版本的对比链接
- **THEN** 页面按路径中的两个版本 ID 读取对比结果，并显示“从 vX 到 vY”

#### Scenario: 链接中的 ID 非法
- **WHEN** 路径中的版本 ID 不是正整数，或两个版本 ID 相同
- **THEN** 页面提示链接无效，不发起对比请求

#### Scenario: 任一版本不可访问
- **WHEN** 对比请求返回 404
- **THEN** 页面只提示版本不存在或当前不可查看，不说明是哪一个版本

### Requirement: 差异必须以安全纯文本按服务端结果展示

页面 SHALL 按服务端返回的顺序展示操作列表及各类数量：未变化的连续块默认折叠并可展开，修改块逐字标出删除与插入，移动块标明来源与去向，表格按行和单元格标出变化，RESTRUCTURED 表格并列展示两侧内容。所有正文 MUST 作为纯文本显示，不执行 HTML 或 Markdown，不自动请求外部资源；页码和标题路径只作为提示，不当作原生查看器的定位命令。

#### Scenario: 片段包含 HTML 标记
- **WHEN** 某个差异片段的文本包含 `<img>` 或 `<script>` 标记
- **THEN** 页面按原样文本显示，不执行脚本也不加载图片

#### Scenario: 大段未变化内容
- **WHEN** 两处修改之间有大量未变化的块
- **THEN** 这些块默认折叠，显示折叠数量，用户可以展开查看

#### Scenario: 修改块未提供逐字片段
- **WHEN** 服务端标记某个修改块过长、未提供逐字片段
- **THEN** 页面并列显示两侧全文，并说明该块未逐字比较

### Requirement: 关键数值变化必须单独列出并说明范围

页面 SHALL 在差异旁按日期、金额、百分比、条款编号分组列出数值变化，显示前值与后值，仅前值或仅后值的项分别标注。点击某项 SHALL 定位到对应的差异块。页面 MUST 说明该列表只包含修改内容中按规则识别到的数值，不代表全部变化。

#### Scenario: 查看金额变化
- **WHEN** 结果包含一条金额变化
- **THEN** 列表显示前值与后值，点击后滚动到对应的修改块

#### Scenario: 没有识别到数值变化
- **WHEN** 结果的数值变化为空，但存在修改块
- **THEN** 页面显示“修改内容中未识别到日期、金额、百分比或条款编号变化”，不显示为“没有变化”

### Requirement: 质量提示与无法对比状态必须分别表达

页面 SHALL 在差异上方显著展示 PARSER_DIFFERS 与 TRUNCATED 提示。SNAPSHOT_MISSING、TOO_LARGE、TIMEOUT、LOW_SIMILARITY 各自显示不同说明，不显示差异明细，并提供分别预览两个版本的入口（沿用既有指定版本预览交互）。429 提示对比繁忙、由用户手动重试；503 提示暂时无法完成对比。页面 MUST NOT 自动重试，也不得把任何失败显示为“两个版本相同”。

#### Scenario: 缺少快照
- **WHEN** 结果为 SNAPSHOT_MISSING 且标明目标侧缺少快照
- **THEN** 页面说明目标版本暂无可用的对比数据，并提供两个版本的预览入口

#### Scenario: 对比繁忙
- **WHEN** 对比请求返回 429
- **THEN** 页面提示稍后重试并提供重试按钮，不自动重发

#### Scenario: 解析器不同
- **WHEN** 结果为 AVAILABLE 且附 PARSER_DIFFERS
- **THEN** 差异照常显示，上方提示部分差异可能来自解析器而非内容修改

### Requirement: 对比页必须展示目标版本的变更说明并核对基准

页面 SHALL 读取目标版本的变更说明。说明的基准等于本页基准时，显示为本次对比的变更说明；不相等时显示说明并标明“此说明对应 vA 到 vY”，提供打开该对比的入口。没有说明时显示“没有变更说明”；读取失败只显示“变更说明暂不可确认”，不影响差异展示。

#### Scenario: 说明基准与本页一致
- **WHEN** 用户对比 V1 到 V3，V3 的说明基准为 V1
- **THEN** 页面把该说明显示为本次对比的变更说明

#### Scenario: 说明基准与本页不同
- **WHEN** 用户对比 V2 到 V3，而 V3 的说明基准为 V1
- **THEN** 页面显示说明并标明对应 V1 到 V3，不把它表述为 V2 到 V3 的说明

#### Scenario: 说明读取失败
- **WHEN** 说明读取返回 503
- **THEN** 说明区域显示暂不可确认，差异照常展示

### Requirement: 对比页必须隔离身份与迟到结果

对比结果和说明 SHALL 只保存在当前页面内存。退出、强制改密、身份变化、页面隐藏或离开、路径中的版本变化时停止读取并清除已显示内容；恢复时先核对当前身份再重新读取。迟到响应 MUST 不覆盖新的上下文，正文不写入持久存储或遥测。

#### Scenario: 切换对比版本后旧结果迟到
- **WHEN** 用户从 V1 到 V2 的对比切换到 V1 到 V3 后，前一个请求才返回
- **THEN** 旧结果被丢弃，不显示在新的对比上

#### Scenario: 切换账号
- **WHEN** 用户 A 打开对比页后退出，用户 B 登录
- **THEN** 不显示 A 的对比内容，B 需要按自己的资格重新读取
