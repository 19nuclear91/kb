# Tasks

按依赖顺序实施，范围以 `proposal.md`、`design.md` 和五份增量规格为准。各组同时交付对应功能的单元测试与说明；复选框记录当前实施与验证进度，规划完成不代表功能已实现。

验证仅使用进程内业务单元测试、Mock/Stub、模拟 DOM、依赖全部替换为 Mock 的 standalone MockMvc、ArchUnit、类型检查与静态构建。controller 与 service 分别测试，不组装完整业务链路；不创建或执行集成、端到端、真实浏览器或依赖外部组件运行的任务，不启动完整应用、开发服务器、网关或 HTTP 监听，不运行或连接数据库、Redis、MinIO、Docker、嵌入式数据库及供应商服务。后端测试按明确的类/方法白名单执行，打包跳过测试，不依靠未配置环境或条件跳过来筛选用例。

文档、README、Markdown、配置示例、OpenAPI 注解与 Javadoc 只交付并人工核对，不编写或执行内容断言、快照或示例测试；既有测试含此类断言时只选择业务方法，不整类运行。沿用既有接口、权限 code、数据库模型与前端依赖；数据库实际事务、锁、持久化和跨服务效果不作为本清单的完成条件。
