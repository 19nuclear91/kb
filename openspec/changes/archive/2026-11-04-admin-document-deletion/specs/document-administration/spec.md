# Spec Delta

## ADDED Requirements

### Requirement: 管理端删除必须按当前所属空间的管理资格判定

系统 SHALL 提供 `DELETE /api/admin/documents/{documentId}`，仅允许在该文档当前所属空间持有 manage 或持有 `space:manage-all` 的已认证操作者执行。资格 MUST NOT 由 view、edit、download、文档例外授权、上传者身份或角色名称替代，MUST 基于服务端解析的主体；已停用用户或主部门已停用的用户 MUST 被拒绝。已归档空间中的文档 SHALL 可以被删除。

#### Scenario: 空间管理员删除本空间文档

- **WHEN** 操作者在空间 S 持有 manage，但没有 S 中文档 D 的 view 或 edit
- **THEN** 对 D 的管理端删除被接受
- **AND** 操作者无需先为自己授予 edit

#### Scenario: 只有编辑资格

- **WHEN** 操作者持有文档 D 的 edit 或文档例外，但不在其所属空间持有 manage，也没有 `space:manage-all`
- **THEN** 管理端删除返回与目标不存在相同的 404
- **AND** 用户端按 edit 判定的删除接口不受影响

#### Scenario: 已归档空间中的文档

- **WHEN** 文档所属空间已归档，操作者仍持有该空间 manage
- **THEN** 管理端删除被接受
- **AND** 不要求先取消归档

#### Scenario: 已停用操作者

- **WHEN** 会话对应的用户已停用，或其主部门已停用
- **THEN** 系统拒绝该删除
- **AND** 不写入任何变更或审计事件

### Requirement: 管理端删除必须与用户端删除产生相同的文档效果

管理端删除 SHALL 软删除整份文档及其全部版本，在同一事务内取消该文档未完成的解析任务与审核轮次，事务提交后尽力清理全部版本原件。迟到的解析任务 MUST NOT 重新发布已删除文档的内容。删除后该文档 MUST 从检索、列表、详情、下载、预览、收藏、评论读取与管理文档清单中消失。系统 MUST NOT 提供恢复，原件清理失败 MUST NOT 回滚已提交的删除。

#### Scenario: 存在未完成解析任务

- **WHEN** 文档某版本仍在排队或解析中时被管理端删除
- **THEN** 该任务被取消，删除提交成功
- **AND** 此后 Worker 不得发布该版本的分块

#### Scenario: 存在进行中的审核

- **WHEN** 文档某版本处于审核轮次中时被管理端删除
- **THEN** 审核轮次被取消
- **AND** 相关审核待办不再可处理

#### Scenario: 原件清理失败

- **WHEN** 事务提交后对象存储删除失败
- **THEN** 文档保持已删除状态
- **AND** 残留原件由既有对象存储对账处理

### Requirement: 管理端删除必须对不可达目标统一返回 404 并在归属变化时拒绝

文档不存在、已删除或操作者无权管理其当前所属空间时，系统 MUST 返回同一 404，不区分三种情形。资格判定后、写入前文档归属发生变化时，系统 MUST 返回冲突错误且 MUST NOT 写入删除；调用方应重新读取归属后决定是否重试。路径参数不是正整数时返回 400。

#### Scenario: 不存在与无权管理

- **WHEN** 合格登录者分别删除不存在的文档和其无权管理空间中的文档
- **THEN** 两者返回相同形状的 404
- **AND** 响应不泄露目标是否存在或所属空间

#### Scenario: 已被用户端删除

- **WHEN** 文档已通过用户端删除，管理员随后以新的请求标识提交管理端删除
- **THEN** 返回 404
- **AND** 不产生新的审计事件

#### Scenario: 判定后被搬迁

- **WHEN** 资格按空间 S 判定通过后，文档在写入前被搬迁到操作者无权管理的空间 T
- **THEN** 删除返回冲突错误，文档保持未删除
- **AND** 不写入成功审计事件

### Requirement: 管理端删除必须幂等并产生最小披露的审计事件

删除 SHALL 要求请求标识，缺失返回 400。同一请求标识重复提交时，系统 SHALL 在重新核对操作者对首次删除时所属空间的管理资格后返回首次回执并标记 replayed，MUST NOT 再次写入。每次成功 SHALL 产生一条 `DOCUMENT_ADMIN_DELETE` 操作域的审计事件，记录操作者、文档 ID、所属空间、归档状态、时间与请求标识。回执与审计 MUST NOT 包含标题、文件名、正文、存储键或会话令牌。

#### Scenario: 相同请求标识重试

- **WHEN** 删除因超时被以相同请求标识重复提交
- **THEN** 系统返回首次回执且 replayed 为真
- **AND** 审计事件数量不变

#### Scenario: 回执与审计只含定位字段

- **WHEN** 被删除文档带有敏感标题、文件名和存储键
- **THEN** 回执仅包含文档 ID、所属空间 ID 与 replayed
- **AND** 审计摘要不包含上述敏感值

#### Scenario: 缺少请求标识

- **WHEN** 请求未携带 `X-Request-Id`
- **THEN** 返回 400
- **AND** 不执行删除

#### Scenario: 删除失败

- **WHEN** 资格、归属或持久化校验失败导致删除未提交
- **THEN** 系统不写入成功审计事件
- **AND** 失败信息不泄露操作者无权知悉的文档存在性
