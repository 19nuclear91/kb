# Proposal

回答质量与引用证据评测，对应[开发路线图 E-11](../../../../docs/development-roadmap.md)。本变更记录已确认的首期范围；实现及离线核验已完成，48/48 项任务完成，已同步主规格并归档，未部署。交付状态与证据见[归档记录](archive-summary.md)。

## Why

现有 `kb-eval` 只能判断文档版本是否命中，无法判断回答是否正确、关键结论是否得到实际输入材料支持，或材料不足时是否恰当拒答。需要可重复的研发回归流程，将固定测试集、真实运行证据、模型初评和人工复核关联起来，比较模型、提示词或检索配置变化。

## What Changes

- 交付独立回答评测工具，形成固定测试集、自动运行与采集、规则校验、模型初评、人工复核和基线比较的完整闭环；每个用例创建独立会话，只评第一轮。
- 随工具提供合成基准与导入模板，支持人工审定的脱敏业务集；记录数据集、评分规则、来源与准许外发范围，实际材料逐项核对审定语料清单。标准答案只用于评审，不进入被测问答输入。
- 在专用测试部署显式启用受控采集，绑定运行、用例、身份、会话和轮次，保存预算处理后实际发送的消息与材料；核对客户端输出、已保存回答和终态，不用事后查询的完整分块冒充当时输入。
- 规则检查身份、完整性、来源对应及执行状态；模型分别初评答案正确性、材料相关性、关键结论证据支持、拒答和提示注入表现，返回结构化判断与可核对证据。
- 裁判配置独立于被测模型，固定评分规则及提示词版本；评审失败、缺少输入证据和无法判定保持明确状态，不自动补零、通过或重复调用。
- 通过本地结构化文件复核，保留模型原判、人工结论及原因；复核绑定输入和初评摘要，变更后旧复核失效。关键失败、争议项及确定性抽查的通过项必须复核。
- 输出机器与人读报告，分别展示初评、复核、覆盖率、执行错误和基线变化；必要采集、评审或复核缺失时不能给出最终通过。

首期不建设线上抽样运营、管理页面、连续多轮评测、自动修改提示词/业务配置、生产会话导出或新解析供应商适配。提示词比较通过已部署制品版本和实际输入摘要识别，不增加任意客户端 system 指令。本次开发验证限于进程内单元/组件测试及编译、打包和静态检查，不安排需启动服务或外部组件的集成测试，也不安排说明文档的指定内容测试。真实联调与质量效果保持未验证，不作为本次任务完成或归档的前置条件。

## Capabilities

### New Capabilities

- `answer-evaluation-collection`：版本化回答用例、身份与运行绑定、第一轮自动执行、实际模型输入采集、完成状态核对及受控运行产物。
- `answer-quality-evaluation`：确定性检查、独立裁判调用、分维度初评、证据定位、未知状态与调用预算。
- `answer-evaluation-review`：本地人工复核、结论修订历史、复核覆盖、可比性、报告与最终门禁。

### Modified Capabilities

- `chat-model-adapter`：新增测试专用采集要求，在现有发送与流处理边界产生绑定当次执行的有界评测证据；普通日志和错误诊断仍禁止正文与秘密。
- `multi-turn-chat`：新增第一轮评测执行关联要求，采集不能改变当前授权、实际输入、生成次数、持久化、取消或结算语义。

现有 `retrieval-evaluation`、`retrieval-result-collection`、`citation-provenance` 和 `conversation-history` 的输入格式、离线边界、引用语义及本人访问规则保持原契约。

## Impact

- **工具**：拟新增 Java 21 模块 `kb-answer-eval`，包含采集、初评、复核导入与离线报告命令；运行时不依赖业务 Spring 容器或直连数据库，复用既有评测的设计约定而不改变其格式。
- **AI**：`kb-ai` 增加默认关闭的测试采集组件与执行关联，使用受控本地目录交换登记和产物；不增加公开 prompt 导出接口，不向模型供应商发送评测身份或内部凭据。
- **业务服务**：通过现有本人会话、轮次及身份接口执行与核对；不新增业务数据库表、管理员读取他人会话权限或前端页面。
- **交付与验证**：实现阶段需补样例、运行手册及无外部依赖的离线白名单回归；文档仅人工审阅，不设置内容断言或示例命令回放。后续实际使用的专用部署须具备已发布且可检索的固定语料、可用预算模式、被测模型与裁判配置，这些是运行条件，不是本次测试或归档的前置条件；新原件自动入库依赖 E-01，E-01 不并入本变更。
- **数据与成本**：内容产物限于合成或人工审定的脱敏资料，凭据由环境注入；裁判调用有独立请求、token 与期限限制，不借用业务用户的会话额度账本。
