# Spec Delta

## ADDED Requirements

### Requirement: 回答评测采集必须默认关闭并严格限定测试执行

模型适配的评测采集 MUST 默认关闭，仅在显式测试部署、允许身份及匹配的未过期运行登记同时成立时启用。生产 profile 启动不得开启采集；测试标识不替代运行方的物理隔离责任。登记绑定失败、采集关闭及未登记业务流不得保存输入或输出正文。评测产物不属于普通日志、错误诊断或遥测，不新增公开模型消息导出接口。

#### Scenario: 默认或普通业务启动
- **WHEN** 服务按默认配置启动，或请求没有有效测试登记
- **THEN** 不读取正文采集目标、不写入评测正文，原模型适配行为保持不变

#### Scenario: 生产配置试图开启采集
- **WHEN** 生产 profile 与评测采集同时启用
- **THEN** 启动配置校验拒绝且错误不回显凭据、路径或原配置内容

### Requirement: 测试证据必须绑定最终发送消息并区分执行阶段

已登记执行 SHALL 在发送前最终预算及请求大小校验后，从同一不可变发送视图取得完整角色消息、实际材料和摘要，绑定可信用户、会话与轮次；不得为采集重新裁剪或渲染不同内容。证据须区分输入就绪、请求订阅、模型正常完成和失败取消，记录已解码输出摘要及已知或未知 usage。准备或订阅事实不证明供应商已接受、执行或停止计费。

#### Scenario: 计数阶段重复渲染消息
- **WHEN** 上下文预算循环多次计算并裁剪材料
- **THEN** 不把中间计数视图写作最终发送快照，只在合法实际生成路径记录最终视图

#### Scenario: 正常模型输出
- **WHEN** 模型流按既有协议正常完成
- **THEN** 采集保留最终消息与解码输出摘要及完成事实，供运行器与业务输出核对，不把适配层完成当作持久化或交付完成

#### Scenario: 模型开始后输出许可撤销
- **WHEN** 已捕获输入的生成执行因原身份许可失效被取消
- **THEN** 采集记录已知阶段并停止追加，不订阅另一条流、不延长许可、不从旧数据补造成功

### Requirement: 测试采集失败不得改变生成与敏感信息边界

采集 MUST 使用有界工作量及存储预算，不阻塞响应式业务线程或撤权取消。写盘失败、队列饱和、超限和崩溃须使证据缺失或不完整，不能悄悄省略后标为可评审；业务流仍按原授权、终态和结算收尾。产物不得包含 API Key、会话令牌、内部签名或出站认证头，记录数据必须来自已批准的测试身份与本次登记。

#### Scenario: 采集队列已满
- **WHEN** 正常业务调用进行时采集无法接受下一份有界记录
- **THEN** 本次评测证据标为不完整，业务取消及保存仍正常执行，不无界缓存或额外调用模型

#### Scenario: 供应商错误包含凭据
- **WHEN** 模型请求失败且远程错误体含敏感内容
- **THEN** 仅保存既有固定错误类别和阶段，评测文件与普通日志均不复制错误体或秘密
