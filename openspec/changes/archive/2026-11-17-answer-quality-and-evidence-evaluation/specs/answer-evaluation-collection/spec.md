# Spec Delta

## Purpose

为回答质量回归提供版本化用例与可核对的真实运行输入，将测试身份、独立会话、实际发送给模型的材料和最终回答绑定到同一次执行，明确采集完整性、数据来源及故障范围，避免事后补查或缺失样本造成虚假的质量结论。

## ADDED Requirements

### Requirement: 回答用例必须版本化且区分数据来源

工具 SHALL 接受固定格式版本的数据集清单和完整用例集，声明数据集版本、语料快照标识、来源类型及准许外发目标。每例 MUST 有唯一 caseId、身份别名、问题、分类、预期 ANSWER 或 ABSTAIN、人工答案要点及适用的禁止行为；来源只接受 SYNTHETIC 或 HUMAN_APPROVED_DEIDENTIFIED。后者须有人工审定标识和内容摘要，审定记录不构成自动脱敏证明。

#### Scenario: 同一问题用于不同身份
- **WHEN** 同一问题用于两个不同测试身份
- **THEN** 两者使用不同 caseId 和分别标注的预期，不共享运行或答案判断

#### Scenario: 脱敏资料未审定或摘要改变
- **WHEN** 脱敏业务集缺少审定记录，或实际内容与审定摘要不符
- **THEN** 联网前拒绝该数据集，不自动修复审定记录或把它标成合成来源

#### Scenario: 标准要点隔离
- **WHEN** 执行有人工答案要点和禁止行为的用例
- **THEN** 被测问答只收到原问题及业务链路实际选择的材料，标注不注入其问题、历史或系统消息

### Requirement: 实际采集材料必须属于审定语料范围

数据集 MUST 包含审定的固定语料清单，绑定允许的文档、版本、分块及正文摘要。实际材料须逐项核对该清单及对应审定文本，裁剪内容只能是审定原分块的真实前缀。出现未审定来源或内容不符时，采集与运行器不得把该例正文持久化为评测产物或发送给裁判，只保留安全原因与不完整状态。清单不是业务授权，也不证明全库或 ACL 已冻结。

#### Scenario: 搜索召回测试集之外的可读资料
- **WHEN** 测试账号有权读取但未审定纳入本次评测的分块进入实际材料
- **THEN** 本例不产生可用正文评测包，不向裁判外发该回答或材料，保留来源范围不匹配的安全状态

#### Scenario: 相同身份的材料内容发生变化
- **WHEN** 固定分块身份仍匹配，但完整文本或实际裁剪前缀与审定文本不符
- **THEN** 证据核对失败，不以相同 ID 或 corpusSnapshotId 覆盖内容差异

### Requirement: 输入与本地路径必须有界并在联网前校验

工具 MUST 在联网前完整校验清单、用例、身份配置、必需文件及输出目录。输入只读，拒绝重复字段、未知契约字段、非法 Unicode、重复 caseId、不合法正整数身份和缺失用例；仅接受明确本地路径，拒绝网络共享、URI、通配符及越过允许根目录的链接。所有读取和输出须有字节、条数、深度、期限和磁盘预算，摘要来自本次已校验的同一份字节。

#### Scenario: 第一个用例合法而后续用例非法
- **WHEN** 批次后部出现重复 caseId、非法问题或超限内容
- **THEN** 整批在首个网络请求前失败，不先执行合法前缀

#### Scenario: 路径或文件在预检后改变
- **WHEN** 输出父目录被替换为越界链接，或原输入文件被修改
- **THEN** 写入时重新验证路径边界，执行仍使用已校验字节；不能混用新内容或写入越界目标

### Requirement: 采集必须显式限定专用测试运行

采集 SHALL 默认关闭，只接受显式启用的测试部署、测试身份白名单和未过期的本次运行登记。登记 MUST 固定运行、用例、预期用户、独立会话、问题摘要、第一轮序号及产物范围；实际用户与轮次由服务端事实绑定。未登记、过期、身份不符或非第一轮的请求不得产生正文采集。登记不是登录凭据或资源授权。

#### Scenario: 普通用户请求经过开启采集的实例
- **WHEN** 请求没有匹配的运行登记或用户不在测试白名单内
- **THEN** 不保存其问题、材料或回答为评测产物，原业务请求仍按原门禁处理

#### Scenario: 登记重用到其他会话
- **WHEN** 请求的问题摘要相同但会话、用户或第一轮序号不匹配
- **THEN** 不绑定原登记、不覆盖原证据，评测不能把该请求当作本例成功执行

#### Scenario: 登记已过期或一次执行已绑定
- **WHEN** 另一次执行尝试使用过期登记或已绑定其他轮次的登记
- **THEN** 不采集新正文，不把旧文件作为新执行结果

### Requirement: 在线运行必须使用已有本人接口和固定身份

运行器 SHALL 通过既有身份、本人会话与问答接口执行，首个写入前核对全部引用令牌的真实用户、启用与改密状态。令牌只从配置指向的环境变量读取，不自动登录、不直读数据库、不使用管理员资格代读他人会话。请求仅发送到固定 HTTPS 服务根地址；显式允许的本机 HTTP 除外。不得跟随重定向或传播额外 Cookie、追踪头、内部签名和客户端身份声明。

#### Scenario: 员工用例提供管理员令牌
- **WHEN** 身份核对得到的用户与预期用户不符
- **THEN** 批次停止，尚未创建任何用例会话或调用生成

#### Scenario: 运行中撤权或停用
- **WHEN** 原身份不再能够读取会话、回答或来源
- **THEN** 记录当前失败或不可核对状态，不更换身份、不通过采集目录恢复被拒绝的业务回答

### Requirement: 每例必须独立执行第一轮且禁止隐式再生成

运行器 MUST 为每例创建独立会话，以新请求标识和 expectedLastTurnSeq=0 发起至多一次新生成，按用例顺序串行执行。首次失败后停止后续生成，保留已执行结果并将其余用例标为 NOT_RUN。未知提交可进行有界只读核对，不能换标识、换身份或再次提交来取得更好的样本；匹配重放仅表示原状态。创建的测试会话不自动删除，清理须明确列出本次目标。

#### Scenario: 中间用例网络结果未知
- **WHEN** A 已完成，B 的请求可能已被受理但连接断开，C 尚未开始
- **THEN** B 保留未知或核对后的原状态，C 标为 NOT_RUN，不重新生成 B，也不只报告 A 的质量

#### Scenario: 用例回答错误但执行完整
- **WHEN** 某用例正常完成但回答不符合人工预期
- **THEN** 保留该回答交给评审并继续下一用例，不将质量差当作可重试网络故障

### Requirement: 模型输入证据必须来自当次最终发送视图

采集 MUST 保存当次预算完成及发送前复核后的角色消息、材料文本、固定版本身份、裁剪标记及内容摘要，并绑定可信轮次。材料位置以本次实际文本为准；不得查询最新版本或完整原分块替代。准备输入、订阅请求、模型流完成须分别记录，输入准备不证明远端已收到或执行。首期只接受能够提供该证据的内置文本适配路径，其他实现明确不支持。

#### Scenario: 模型只收到分块前缀
- **WHEN** 原分块有金额说明，但该部分被上下文预算裁去
- **THEN** 评审材料仅包含实际前缀，不能用原分块的金额为回答提供支持

#### Scenario: 捕获输入后请求未能发出
- **WHEN** 最终消息已形成，但订阅、认证许可或传输失败
- **THEN** 保留实际阶段，不把准备成功标为模型完成或成功回答

#### Scenario: 自定义模型没有可信采集能力
- **WHEN** 被测部署使用无法提供最终发送视图的自定义适配器
- **THEN** 预检或本例明确报告不支持，不把编排前材料伪作实际输入

### Requirement: 回答必须核对客户端输出与持久终态

运行器 SHALL 按 SSE 事件边界处理 citation、delta、done、error，并精确保留 64 位身份。成功样本 MUST 绑定响应轮次、完整客户端正文、当前本人可见的已保存正文、COMPLETED 终态及适用的模型完成证据；正文摘要和来源身份须一致。EOF、error、部分回答、缺少成功 done 或结算待确认均不能冒充完整端到端成功；模型已完成与最终交付成功分别表达。

#### Scenario: 模型完成但回答保存失败
- **WHEN** 模型流正常结束，业务写回失败且没有成功 done
- **THEN** 本例记录业务执行不完整，不能只用原始模型文本计算完整成功样本的质量

#### Scenario: 客户端正文和已保存正文不一致
- **WHEN** SSE 文本摘要与同轮次的可见持久回答摘要不同
- **THEN** 标记一致性错误，禁止人工或模型评分将该样本改为有效成功

#### Scenario: 读取成功但来源随后不可核对
- **WHEN** 终态核对时回答被来源门禁屏蔽或依赖不可用
- **THEN** 保留执行和核对事实，样本不可完整评审，不复用旧可见响应宣称当前核对通过

### Requirement: 无结果拒答与执行失败必须分别表达

工具 MUST 区分正常 MODEL 回答、合法 NO_RESULTS、执行错误、取消、中断和未知状态。NO_RESULTS 须有业务成功证据及未调用模型的采集声明，不要求不存在的模型输入；其拒答是否恰当由用例预期判断。检索故障、预算耗尽和认证拒绝不得转换成无结果或正确拒答。

#### Scenario: 本应有答案却返回合法无结果
- **WHEN** 预期 ANSWER 的用例正常完成为 NO_RESULTS
- **THEN** 执行有效，但拒答判断失败，答案要点未覆盖；不把执行成功等同质量通过

#### Scenario: 材料被预算完全裁去
- **WHEN** 服务返回 INPUT_BUDGET_EXCEEDED
- **THEN** 记录执行失败，不把它与合法空检索或正确拒答合并

### Requirement: 运行产物必须完整声明覆盖与来源

每个结束的采集尝试 SHALL 为全部用例保留恰好一个状态及已确认绑定，记录输入摘要、实际模型消息摘要、部署制品标识、配置声明和采集器版本。语料与权限快照未经独立核验时 MUST 标为 DECLARED_ONLY；模型别名不证明权重版本。相同声明标识不能掩盖实际输入或环境差异，SYNTHETIC 与脱敏业务来源分别汇总。

#### Scenario: 部分用例未执行
- **WHEN** 批次因失败提前结束
- **THEN** 产物仍列出全部用例与 NOT_RUN 状态，运行标为 INCOMPLETE，不成为完整质量通过报告

#### Scenario: 相同模型名对应不同部署
- **WHEN** 两次运行声明相同模型别名但制品、实际提示词或材料摘要不同
- **THEN** 差异记录在运行证据中，不宣称模型权重和输入完全相同

### Requirement: 产物必须有界且完整发布到受控新目录

正文产物 SHALL 仅位于显式受控的新目录，登记、逐例完成标记及最终运行清单必须完整发布；不得覆盖输入、既有产物或并发创建的目标。崩溃残留不能识别为完成运行。采集关闭、磁盘不足、队列饱和或写入超限时须使评测证据不完整，不得阻塞撤权取消或无界缓存正文。日志、汇总诊断与异常不得回显秘密、问题、答案或证据。

#### Scenario: 采集写盘失败
- **WHEN** 业务生成正常完成但采集文件写入失败
- **THEN** 业务按原语义收尾，评测标记证据缺失，不无限等待或改变该轮业务终态

#### Scenario: 输出目录被竞争创建
- **WHEN** 发布前其他进程创建了目标目录
- **THEN** 发布失败且原目标不变，只清理已确认属于本次尝试的暂存文件

### Requirement: 合成基准与真实质量验收必须分开

工具 SHALL 交付包含正确回答、错误数值、缺少条件、证据不足、恰当及错误拒答、裁剪和文档提示注入的合成基准及脱敏导入模板。报告 MUST 明确是否运行真实授权检索、真实模型和真实裁判；协议替身、手工记录或离线样例不得被标成真实闭环验收。原件新入库依赖既有第三方解析链路，不为评测恢复本地解析回退。

#### Scenario: 合成样例全部通过
- **WHEN** 使用本地合成输入或协议替身得到通过结果
- **THEN** 报告保留合成或替身范围，不声称企业语料质量、实时权限或生产部署已验收

#### Scenario: 测试环境解析服务未就绪
- **WHEN** 新基准原件尚不能完成解析发布
- **THEN** 运行前明确依赖未就绪，不以伪造索引或占位回答替代真实运行
