# Spec Delta

## MODIFIED Requirements

### Requirement: 解析元数据与分块发布必须原子且可重试

系统 SHALL 将解析版本的质量元数据、解析器版本和分块来源信息与索引结果关联保存；发布必须在同一原子操作中完成，重复处理同一文档版本
MUST 得到一个一致的最终结果。发布写入的分块 MUST 与文档当前所属空间一致，MUST NOT 因与所属空间变更并发而留下按原空间参与权限过滤的分块。

#### Scenario: 解析成功并发布

- **WHEN** 解析、切块和向量化均成功且任务租约有效
- **THEN** 系统保存解析元数据和全部分块来源信息
- **AND** 版本才进入可检索状态

#### Scenario: 发布过程中发生失败

- **WHEN** 元数据或分块写入中任一步失败
- **THEN** 该版本不得呈现为已索引
- **AND** 重试可以清理不完整结果并重新发布
- **AND** 不产生重复的同版本分块

#### Scenario: 同一版本重复处理

- **WHEN** 同一文档版本因重试或任务重投被再次处理
- **THEN** 最终只保留一套与最新成功结果一致的分块和元数据
- **AND** 不覆盖更新版本的当前版本指针

#### Scenario: 发布与文档所属空间变更并发

- **WHEN** 同一文档的分块发布与其所属空间变更在时间上重叠
- **THEN** 两者完成后全部已索引分块都按文档当前所属空间参与权限过滤
- **AND** 不残留按原空间参与过滤的分块
