# Spec Delta

## Purpose

为具有独立 AI 读取资格的管理人员提供聊天用量及调用审计页面，通过有界筛选、精确统计、稳定事件续页和安全详情追踪跨部门调用，并在权限变化、未知用量与采集缺口出现时保持可辨认的界面行为。

## ADDED Requirements

### Requirement: AI 用量与审计页面必须独立授权

页面 SHALL 在 `/admin/ai/usage` 按 ai:usage:read 展示汇总和分组，在 `/admin/ai/audits` 按 ai:audit:read 展示事件及详情。两页使用现有会话与本人权限事实，读取不依赖用户/部门目录或可管理空间加载成功。仅持有其中一项权限 MUST 不触发另一页的数据预取，现有管理审计资格不能替代新资格。

#### Scenario: 仅有用量权限
- **WHEN** 用户具有 ai:usage:read，没有 ai:audit:read
- **THEN** 可进入用量页，审计入口不可用且不请求事件数据

#### Scenario: 空间或身份目录故障
- **WHEN** AI 读取资格已确认，但空间或身份目录读取失败
- **THEN** AI 页面仍可按稳定 ID 查询，不以旧目录或额外资格作为放行条件

### Requirement: 筛选草稿必须与已提交查询分离

页面 SHALL 提供用户 ID、部门 ID、调用模式、生成/用量/结算状态及时间筛选；审计页另有调用 ID 与事件类型。默认最近 7 天，自定义时间带时区且窗口最多 31 天。仅显式提交合法草稿后发起新查询；刷新沿用已提交条件，重置恢复默认。非法 ID、枚举和时间 MUST 在请求前提示，不截断或忽略条件。

#### Scenario: 修改草稿后续页
- **WHEN** 用户编辑未提交的筛选，然后继续读取事件或分组
- **THEN** 使用原已提交条件和游标，草稿不混入当前查询

#### Scenario: 提交新条件时旧响应晚到
- **WHEN** 原请求在途时提交了新条件或刷新
- **THEN** 旧请求被取消，迟到响应不能恢复旧窗口、统计或事件详情

### Requirement: 用量页必须解释真实用量与结算差异

用量页 SHALL 分别展示调用数、模型调度意图数、已知输入/输出 token、未知用量数、未调用模型数、计划扣除额度、已确认结算额度和未解决结算数量。UNKNOWN、null 与 KNOWN 零值 MUST 可辨；已知 token 合计须同时显示已知样本数，不把它标为包含未知调用的完整消耗。首期不把 token 额度显示为货币费用。

#### Scenario: 只有未知用量
- **WHEN** 当前窗口包含调用但没有已知 usage 样本
- **THEN** 已知 token 合计显示未记录，未知数量独立展示，不显示“总消耗为零”

#### Scenario: 生成已完成但结算未确认
- **WHEN** 服务端报告生成 COMPLETED 且结算 PENDING
- **THEN** 两种状态分别显示，计划扣除额度不进入页面的已确认结算额度

### Requirement: 分组统计必须保留精度及读取时刻

页面 SHALL 支持按 UTC 日、部门 ID、用户 ID 查看分组，并显示实际时间窗口和 asOf。所有 ID、token 与计数 MUST 保持服务端整数精度；日分组须说明 UTC 日界。部门/用户分组按稳定键显式续页，保持服务端顺序，分组切换重置游标；不同 asOf 的分页不得被宣称为同一冻结快照或无界总排行榜。

#### Scenario: 超过安全整数范围
- **WHEN** ID 或累计用量大于 JavaScript 安全整数范围
- **THEN** 页面精确显示全部数字，不经 Number 转换或浮点运算改变结果

#### Scenario: 分组分页状态变化
- **WHEN** 后续页的 asOf 更新，且期间存在结算状态变化
- **THEN** 页面显示相应读取时刻，合计直接采用服务端汇总，不从已加载分页拼造全量总计

### Requirement: 调用审计必须展示安全事件与详情

审计页 SHALL 按服务端顺序展示调用关联、事件类型、模式、用户/部门 ID、时间、状态、固定结果码及适用的用量和结算值，按事件 UUID 读取详情并核对身份。详情只展示安全字段，不加载问题、回答、用户名称或私有会话；未知安全枚举按纯文本保留，缺失字段显示未记录。

#### Scenario: 多事件属于同一调用
- **WHEN** 同一调用包含登记、生成终结和结算确认事件
- **THEN** 各事件保留独立身份并可按调用 ID 筛选，页面不把事件条数称为请求数

#### Scenario: 切换详情或目标不可访问
- **WHEN** 用户切换事件、关闭抽屉，或详情返回 404
- **THEN** 清理旧详情并隔离迟到响应，404 提示事件不可访问，不恢复旧内容

### Requirement: 审计续页必须核对固定窗口与身份

审计页 SHALL 提供每次 20、50、100 条及显式继续读取，只在 hasMore=true 且游标有效时续页。一次查询同时至多有一个列表请求；续页保持原窗口、过滤条件与服务端事件上界。重复事件、窗口冲突、游标异常或损坏响应 MUST 作为读取故障，不把异常页追加到已确认结果。

#### Scenario: 重复点击与请求失败
- **WHEN** 用户重复点击继续读取，或续页网络请求失败
- **THEN** 不并行请求同一页，保留已确认事件和当前游标，显式重试成功后只追加一次

#### Scenario: 翻页期间出现迟到事件
- **WHEN** 服务端入库一个发生时间较早的新事件
- **THEN** 旧查询继续使用原事件上界，用户刷新后才可看到该事件

### Requirement: 页面必须明确采集覆盖与保留范围

两页 SHALL 展示采集状态、首次覆盖时间、有效保留天数及读取时刻。未启用、查询早于覆盖起点、保留期外仅有异常保留记录时 MUST 给出相应说明；采集缺口不能被解释为零调用。空结果、没有已知 token、依赖故障和未启用采集须分别展示，不能用静态默认数值代替服务端事实。

#### Scenario: 尚未启用采集
- **WHEN** 接口返回采集尚未启用且覆盖时间为空
- **THEN** 页面显示尚未开始采集，不以零值图表暗示已经完整统计历史

#### Scenario: 保留期之外的异常记录
- **WHEN** 旧窗口返回待核查的保留例外记录
- **THEN** 页面保留这些记录并提示该时间范围的普通历史可能已清理

### Requirement: 页面资料必须服从当前身份与资格生命周期

退出、身份切换、强制改密、权限撤销、进入后台或离开页面时，页面 MUST 取消请求并清理统计、筛选、游标和详情。后台恢复须重新核对身份与权限后按默认条件读取；旧代次响应不得恢复资料。401 沿用登录恢复，403 清理数据且同一拒绝上下文最多自动核对一次资格，503 或网络故障提供显式重试。

#### Scenario: 读取途中切换账号
- **WHEN** 列表、汇总或详情未完成时用户切换账号
- **THEN** 旧资料被清空，旧请求结果不进入新身份页面

#### Scenario: 服务端拒绝但权限快照仍包含资格
- **WHEN** 读取返回 403，而一次重新核对仍声称具有资格
- **THEN** 页面保留拒绝提示，不通过反复挂载自动循环读取

### Requirement: AI 查询资料必须限制在页面内存

筛选、统计、事件和详情 SHALL 仅保留在当前有效页面内存。页面地址保持固定路由，不携带用户、部门、调用或事件筛选值；浏览器持久存储、日志和遥测 MUST 不保存这些资料。响应遵守 no-store，文本不得作为可执行 HTML 展示，首期页面不提供导出、人工修复或删除审计操作。

#### Scenario: 输入标识并打开详情
- **WHEN** 用户按调用 ID 查询并打开事件抽屉
- **THEN** 浏览器地址和持久存储不出现该筛选，错误只显示安全类别

#### Scenario: 字段含 HTML 标记
- **WHEN** 服务端安全文本包含 HTML 或脚本样式字符串
- **THEN** 页面仅显示文本，不执行或自动加载外部资源
