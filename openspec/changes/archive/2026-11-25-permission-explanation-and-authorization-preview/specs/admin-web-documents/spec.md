# Spec Delta

## ADDED Requirements

### Requirement: 文档诊断必须独立取得功能与所属空间管理资格

文档管理面板 SHALL 仅在 authorization:diagnose 与当前文档管理范围均确认后开放诊断及最小目标用户选择。只有文档密级调整资格、正文 view／edit 或诊断资格本身均不足以开放。诊断读取失败只影响该区块；父文档管理资格失效则沿用原面板清理规则。管理但不可阅读时以 documentId 显示，不补查隐藏标题、版本或文件。

#### Scenario: 有管理资格但不能阅读
- **WHEN** 管理文档清单返回目标，普通详情返回 404，操作者另有诊断资格
- **THEN** 诊断可用且以 ID 标识资源，不因需要解释而授予正文或标题读取

#### Scenario: 只有密级管理资格
- **WHEN** 操作者有 document:security-level:write 和 authorization:diagnose，但无文档所属空间管理范围
- **THEN** 密级区块按原规则开放，诊断及其候选不加载

#### Scenario: 诊断故障隔离
- **WHEN** 诊断返回安全 503，而其他管理资格已确认
- **THEN** 仅诊断区块显示故障，例外授权、搬迁和其他独立管理区块仍按原规则工作

### Requirement: 文档诊断必须分层展示授权与当前发布版本访问

页面 SHALL 展示所选用户命中的空间授权、文档例外与必要阻断；view、download、edit、review、comment 独立解释，manage 标明为所属空间管理资格。当前发布版本层仅显示查看／下载是否满足权限条件；无当前发布版本时显示未评估。不得提供历史或待审版本选择、版本数量或通过诊断直接预览／下载，审核授权不表示审批一定可执行。

#### Scenario: 未发布新版不影响当前发布层
- **WHEN** 文档有当前发布 V1 以及未发布 V2
- **THEN** 页面仅展示对当前发布范围的查看／下载评估，不泄露 V2 或将结论概括为所有版本均可读

#### Scenario: 无当前发布版本
- **WHEN** 服务端返回 NO_CURRENT_PUBLISHED_VERSION
- **THEN** 显示“暂无当前发布版本可供评估”，授权来源仍展示，不渲染为整份文档不可访问

#### Scenario: 下载授权缺少查看前提
- **WHEN** 服务端报告 download 已命中，但当前版本查看条件不满足
- **THEN** 展示下载授权命中与实际下载不允许的区别，不启用原件入口

#### Scenario: 文档级 manage 与 review
- **WHEN** 诊断展示 manage 或 review 的命中来源
- **THEN** 明确它们来自所属空间或允许的全局管理来源，不制造文档例外 manage／review

### Requirement: 文档例外预演必须绑定单项草稿并保留空间授权

例外授予与单条撤销表单 SHALL 为合格操作者提供可选预演，使用已选诊断用户、路径文档、一个主体和一个 view／download／edit／comment。预演前后合并该文档的空间与例外来源；修改目标、动作、主体或权限位立即作废结果。MUST NOT 增加文档例外批量写入、空间权限改动或联合多操作提交。

#### Scenario: 撤销例外仍继承空间权限
- **WHEN** 拟撤销文档 view 例外，而目标用户仍命中空间 view
- **THEN** 展示例外来源拟移除及空间来源继续有效，访问结果不因例外撤销自动变为拒绝

#### Scenario: 授予例外无法绕过归档或密级
- **WHEN** 拟增加文档 view，但空间已归档或密级条件未通过
- **THEN** 展示授权与阻断分别存在，不承诺授权后可读，不代为取消归档或调整密级

#### Scenario: 例外草稿切换后响应迟到
- **WHEN** 对权限 view 的预演未返回，用户改为 download
- **THEN** 旧响应不能显示为 download 的结果，重新预演须使用新的完整草稿

### Requirement: 文档预演必须遵循面板写入协调而不成为提交条件

文档例外正式提交 SHALL 继续使用既有确认与请求标识，无预演或预演不可用不构成新增拒绝条件。进入删除确认、其他相关写入在途或结果待核对时，诊断区块停止新增预演并清除旧结论；不会解除原写入互斥或将读结果当回执。例外变更、搬迁、密级调整或删除开始提交及结果确认后，旧诊断均失效，后续须重新读取。

#### Scenario: 未预演直接授予
- **WHEN** 有原例外写资格的操作者未预演便明确提交
- **THEN** 原接口按当前资格处理，不要求诊断权限、时间戳或预演成功

#### Scenario: 进入删除确认
- **WHEN** 文档面板进入删除确认或已有相关写入结果待核对
- **THEN** 新预演不可提交，在途预演不能恢复旧结论；原写入核对继续遵守已有互斥规则

#### Scenario: 文档搬迁
- **WHEN** 搬迁已提交或管理上下文发现所属空间改变
- **THEN** 清除旧来源与预演，重新核对真实归属及管理资格后才能主动诊断，不沿用原空间例外

### Requirement: 文档诊断必须隔离身份及资源生命周期

文档诊断 SHALL 使用与空间诊断相同的最小用户选择、完整响应校验和内存保留规则。关闭区块、隐藏页面、离页、换号、改密、资源或资格变化均清理诊断数据并作废回调；重新打开不恢复旧结果或自动预演。诊断区块的清理与旧授权写入回执绑定分别管理，不能把关闭只读区块解释为放弃未决写入。

#### Scenario: 关闭后重新打开
- **WHEN** 用户关闭诊断区块后重新打开
- **THEN** 重新核对资格并主动选择目标／诊断，旧结果不会冒充当前事实，未决正式写入仍按原流程核对

#### Scenario: 退出后迟到成功
- **WHEN** 原用户的诊断响应在退出或换号后返回
- **THEN** 不显示原目标、角色／部门来源、密级判断或预演结果

#### Scenario: 损坏或不匹配的成功响应
- **WHEN** 服务端返回其他文档、其他用户或字段不完整的诊断对象
- **THEN** 整份结果被拒绝，页面显示诊断不可确认，不回退读取完整身份资料
