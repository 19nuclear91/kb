# Spec Delta

## Purpose

为显式获权的知识运营人员提供统一问题受理工作台，通过独立读取、最小人员选择和有界管理命令协调处理，使改派接管、关闭与撤权恢复不依赖空间管理资格，也不扩大文档或私人会话的访问范围。

## ADDED Requirements

### Requirement: 受理工作台必须使用独立读取资格和固定路由

用户端 SHALL 提供 `/admin/knowledge-gaps` 及 `/admin/knowledge-gaps/:gapId`，仅在当前持有 `knowledge:gap:read` 时加载页面与队列；直接访问、刷新和合法登录返回均重核资格。不依赖空间目录、AI 开关或身份目录；只有 assign、handle、close 或管理员角色名称不能开放该管理入口。

#### Scenario: 只有受理读取资格
- **WHEN** 用户只有 read，没有身份目录资格，且空间目录读取失败
- **THEN** 工作台仍可读取问题队列，但分派和关闭操作按独立资格不可用

#### Scenario: 只持处理或写权限
- **WHEN** 用户只有 handle、assign 或 close，没有 read
- **THEN** 不加载管理页面和统一队列；本人及当前分派问题仍按普通入口自身规则判定

### Requirement: 统一队列必须准确表达处理阶段与人工接管需要

工作台 SHALL 使用服务端状态筛选及有界游标，不维护全库客户端过滤副本。展示待受理、处理中、待确认及三类终态，不能把待确认或关闭计作解决。当当前负责人不再有效或缺少 handle 时，队列 SHALL 显示受控的需重新分派提示，不暴露停用、离职、角色或部门细节，不因提示自动修改分派或状态。

#### Scenario: 负责人不再合格
- **WHEN** 已分派人员被停用或处理资格被撤销
- **THEN** 合格受理人员可看到需接管提示并人工改派，不自动恢复旧资格、标记已完成或泄露生命周期原因

#### Scenario: 读取故障与空队列
- **WHEN** 队列或当前资格读取失败
- **THEN** 显示真实故障，不以空队列、零待办或旧列表宣称当前没有问题

### Requirement: 处理人选择必须限于当前合格最小候选

分派选择器 SHALL 只在当前问题可见且持有 assign 时调用该问题的候选接口，以 POST 请求体提交名称搜索及分页，只展示当前有效并持有 handle 的 userId 和显示标签。不返回用户名、部门、角色、密级、外部身份或完整用户目录，不提供任意手填内部 ID 的界面；不能回退身份管理查询。

#### Scenario: 无身份目录权限的分派
- **WHEN** 用户可读问题且有 assign，但没有 identity:user:read
- **THEN** 仍可选择受控候选，不请求用户、部门或角色管理目录

#### Scenario: 候选变化及失败
- **WHEN** 搜索条件改变、问题切换、候选失败或权限撤销
- **THEN** 清除旧候选与选择；提交结果仍以服务端重新核对为准，不使用过期候选绕过资格

### Requirement: 分派与关闭交互必须保留版本和未知结果边界

可见问题的分派和关闭 SHALL 分别核对 assign、close，绑定问题版本、请求标识与提交内容。改派必须说明当前待确认方案会失效；关闭必须输入原因，并明确这不是提问者确认解决。状态或版本冲突后先重读事实，不自动覆盖；结果未知仅允许显式核对或相同载荷匹配重试。

#### Scenario: 待确认改派
- **WHEN** 受理人员改派待确认问题并得到成功回执
- **THEN** 展示处理中和新负责人，旧方案保留在历史但不再提供确认入口

#### Scenario: 提问者停用后关闭
- **WHEN** 合格受理人员确认原因并关闭无法继续确认的问题
- **THEN** 显示已关闭，不生成已解决、代确认或已通知送达的虚假提示

### Requirement: 工作台必须隔离问题资格与资料权限及页面生命周期

工作台 SHALL 按详情能力展示操作，并对关联资料使用其独立当前授权，不以 read 读取原会话、受限版本正文或审核私有意见。切换问题、隐藏、离页、强制改密、退出、换号或资格失效时清理描述、历史、方案和候选；恢复先核对身份与 read，迟到结果不得恢复旧内容，局部故障不阻断其他页面或退出。

#### Scenario: 读问题不等于读文档
- **WHEN** 受理人员可读问题但不能读取方案所关联的资料
- **THEN** 只显示固定资料不可用提示，不以管理接口补查身份、标题或正文

#### Scenario: 加载中撤权或换号
- **WHEN** 工作台代码或详情请求尚未完成而身份或 read 资格改变
- **THEN** 不挂载旧问题或发起旧目标请求，旧描述和命令回执不会进入新身份
