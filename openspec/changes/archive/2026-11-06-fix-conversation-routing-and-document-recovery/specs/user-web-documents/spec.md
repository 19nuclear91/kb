# Spec Delta

## ADDED Requirements

### Requirement: 下载拒绝后的版本恢复必须依据独立阅读资格

文档详情中的下载请求返回 403 或 404 后，页面 SHALL 暂停该版本的旧文件入口、关闭旧预览，并重新核对当前文档、操作能力和明确选中的版本访问状态。页面 MUST NOT 将一次下载拒绝直接当作阅读拒绝并持续隐藏仍可读版本；恢复只使用当前成功核对结果，不自动下载、打开预览或切换到其他版本。

#### Scenario: 下载资格撤销但阅读资格保留
- **WHEN** V1 下载被拒，重核后文档仍返回 V1，且 V1 可阅读但不可下载
- **THEN** 页面继续显示 V1 并允许用户重新选择预览，下载入口保持禁用
- **AND** 无需离开再进入详情页才能恢复 V1，不重新发出下载请求

#### Scenario: 历史版本下载被拒
- **WHEN** 用户明确选择历史 V1，下载被拒后重核确认 V1 仍可读，而当前发布版本为 V2
- **THEN** 保留明确的 V1 选择，文件入口继续绑定 V1，不用 V2 的访问资格或状态替代 V1

#### Scenario: 重核确认版本或文档不可访问
- **WHEN** 重核后的文档不再包含所选版本，或文档及版本访问被拒，或版本状态不允许阅读
- **THEN** 清理对应旧文件内容与入口，不保留未经核对的可读状态
- **AND** 仅展示当前授权响应允许的内容，不补猜隐藏版本，也不把 404 解释为已删除

#### Scenario: 下载拒绝后重核暂时失败
- **WHEN** 文档、能力或版本访问重核遇到服务或网络故障
- **THEN** 依赖失败读取的操作保持禁用，显示重核失败并提供主动重读入口
- **AND** 不把失败当作空版本列表的确定事实，不自动重试下载；之后合法重核可以恢复仍可读版本

### Requirement: 文档上传资格必须支持拒绝后暂停与主动重核

详情页操作能力读取失败 SHALL 提供明确的主动重核入口。新版本上传返回 403 或 404 时 MUST 使旧上传资格失效并暂停再次提交，重新读取文档与操作能力；只有当前文档可访问且新能力明确允许上传时，用户才可再次主动提交。重核失败继续禁用并允许重读，不以刷新详情而未刷新能力冒充已恢复，不自动重传文件。

#### Scenario: 首次能力查询失败后恢复
- **WHEN** 详情读取成功而操作能力查询失败，用户点击重新核对操作资格
- **THEN** 页面重新请求操作能力并明确显示核对状态，依赖该能力的操作在核对完成前保持禁用
- **AND** 成功后按最新独立字段启用对应操作，不以一种权限推断其他权限

#### Scenario: 上传被拒且编辑资格已撤销
- **WHEN** 新版本上传返回 403 或 404，重新核对确认文档仍可读但 canUploadVersion=false
- **THEN** 新版本提交及上传入口保持禁用，页面保留仍可查看的文档
- **AND** 重复点击或表单提交不能继续使用旧 true 标记发出上传请求

#### Scenario: 上传被拒后仍有资格
- **WHEN** 上传拒绝后的重核成功且文档可访问、canUploadVersion=true
- **THEN** 页面允许用户再次主动提交，不因重核成功自行再次发送 multipart 请求
- **AND** 重核结果只表示当前资格，不冒充原上传成功回执

#### Scenario: 资格重核失败或文档不可访问
- **WHEN** 上传拒绝后的重核失败，或文档当前返回不可访问
- **THEN** 前者保留上传暂停和主动重核入口，后者关闭目标上传交互并清理不可访问的文档内容
- **AND** 不把重核的 404 当成原上传没有执行或已删除的证明

#### Scenario: 上传网络结果不确定
- **WHEN** 已发出的上传没有取得明确响应
- **THEN** 保持既有结果未确认提示及只读核对原则，不将其伪装为明确权限拒绝
- **AND** 资格重核不自动重传，不改变本页在途及结果未确认写入的删除协调事实

### Requirement: 文档资格恢复必须隔离目标与请求代次

下载和上传资格重核 SHALL 绑定当前身份、文档、必要的版本身份及请求代次。旧成功、错误或文件回调 MUST NOT 覆盖新的核对结果；文档切换、身份变化、页面隐藏或离开后，旧响应不得恢复内容、能力或上传窗口。手动重核只发起有界读取，不形成失败后的自动循环。

#### Scenario: 旧能力成功晚于新拒绝
- **WHEN** 旧能力查询返回 true 时，新一轮核对已确认对应资格为 false 或尚未完成
- **THEN** 旧响应不重新启用按钮或使暂停的上传表单可提交

#### Scenario: 版本切换后原下载响应才被拒
- **WHEN** V1 下载响应到达前用户已选择 V2
- **THEN** V1 的迟到拒绝不隐藏 V2、不关闭 V2 的有效状态，也不重新选择 V1

#### Scenario: 页面或身份已离开
- **WHEN** 资格重核尚未完成时用户切换文档、退出、更换身份或隐藏页面
- **THEN** 旧读取被中止或其回调失效，迟到结果不恢复新上下文中的旧内容和操作资格
