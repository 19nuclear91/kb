# Proposal

## Why

当前开发网关遗漏会话管理路由，启用助手后仍不能通过开发网关完整访问会话。文档详情还存在两处拒绝恢复断点：下载失败会持续隐藏仍可阅读的版本，新版本上传被拒或操作能力查询失败后缺少安全重核入口；本变更仅处理用户确认的待办第 2、8、9 项。

## What Changes

- 补齐开发网关 `/api/conversations/**` 路由，回归 dev/prod 的会话业务路由、AI 流式路由及内部接口隔离，不改变默认开关和超时策略。
- 文档下载被拒后暂停旧文件入口，重新核对当前文档、操作能力和所选版本；不能仅因下载被拒将仍可读版本持续排除。
- 为文档操作能力查询失败提供主动重核入口；新版本上传 403/404 后使旧资格失效、暂停提交并重读当前事实，只有当前资格重新确认后才能由用户再次提交。
- 重核不自动重传文件、不自动重新下载或打开预览；失败、迟到响应、文档或身份切换不得恢复失效能力。
- 补充针对性回归用例，并在实现时更新 README 中开发路由缺失的说明及有关前端行为说明。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `user-web-conversations`：明确开发及生产网关对会话管理与生成入口的一致路由边界，保留功能关闭和内部接口隔离。
- `user-web-documents`：明确独立能力拒绝后的重核、可读版本恢复、上传提交暂停及主动恢复入口。

## Impact

- 网关：`kb-gateway/src/main/resources/application-dev.yml`、`ConversationRouteTest` 及相关配置回归。
- 前端：`kb-web/src/pages/Documents.tsx`、相关文档/文件组件接口与测试；复用现有 `useResource` 请求代次、身份生命周期和 `DocumentOperations` 写入协调。
- 文档：实现后同步 `README.md`、`kb-web/README.md` 的相关说明。
- 不新增公开或内部 API，不修改后端授权、文档审核发布、删除协调或上传不确定结果语义，不引入依赖或数据库迁移。
- 不包含第三方解析接入、模型预算、浏览器 E2E 基建或实际部署验收。此次提案阶段不修改业务代码、不运行应用或外部服务。
