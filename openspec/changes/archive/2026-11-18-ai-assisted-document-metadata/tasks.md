# Tasks

本清单的后端测试在进程内运行，存储、配额、模型调用和跨服务通信使用测试替身。前端组件测试使用模拟 DOM 和内存传输。接口、运维和编辑者说明作为文档交付。

## 1. 请求、结果与外部协议

- [x] 1.1 在 app 增加整理请求、生成终态、额度事实及短期结果的 Flyway 迁移。静态审阅迁移 SQL 的唯一约束、结果过期及待收尾索引。
- [x] 1.2 实现创建与查询协议、请求绑定和状态投影。在服务测试中并发提交同标识、尝试变更目标及模拟首次响应丢失，断言只登记一项；覆盖匿名、停用、强制改密、跨用户、不可见和不可编辑。
- [x] 1.3 建立成功结果的限时读取和清理。用可控时钟验证过期后不返回建议正文，仍可核对最小请求状态和既有保存回执，原标识不触发再生成。
- [x] 1.4 编写公开接口说明。在控制器单元测试中检查状态码、固定原因、请求标识、期限和 no-store，覆盖已受理后的失败与查询接口本身读取失败。

## 2. 当前发布版本、完整材料与预算

- [x] 2.1 实现 app 的单版本授权快照读取。覆盖 V1 已发布且 V2 待审、首版待审、旧版本缺快照、任务代次不匹配和依赖读取失败，验证只返回当前获准的 V1 材料或对应固定原因。
- [x] 2.2 按结构块顺序传递正文、完整表格、可信定位及所属空间可选分类。用空目录、跨空间同名分类、大目录续页及跨页树版本变化的用例校验候选范围；校验截断和空正文均不调度。
- [x] 2.3 在 AI 服务构建一次不可变结构化输入并匹配显式预算模式。用完整表格、分类路径和转义字符测恰好装入及超出一单位的边界，覆盖计数溢出、策略缺失、包装或字节超限；所有拒绝路径断言上游调用数为零。
- [x] 2.4 实现单次纯文本模型输出解析及字段、来源和分类校验。用受控输出覆盖无合适分类、未知块、越界分类、超长标题或摘要、正文含指令、输出中断与协议错误，验证只有合法完整结果可采用。
- [x] 2.5 编写启用开关、模型与预算配置及正文覆盖约束的说明。用进程内配置绑定和内存传输替身检查默认关闭、显式模式、实际消息格式及外发头隔离。

## 3. 调度、取消与额度结算

- [x] 3.1 实现 app 与 AI 间有界执行和受认证的内部协议，覆盖起始会话与固定执行身份；测试错误服务身份、过期执行身份和撤权都不能获得材料或发送许可。
- [x] 3.2 将按输入和输出上限算出的预留接入部门配额，以整理请求绑定唯一租约。验证额度不足时不调度、预留确认丢失可核对、与聊天并发占用同一部门额度时不能重复领取或超发。
- [x] 3.3 在发放一次性发送许可时原子复核来源、资料、可选分类、会话及预留。在同一测试进程中模拟两个执行者竞争、发放许可前后中断和确认丢失，断言每个逻辑请求最多触发一次模型传输替身。
- [x] 3.4 实现取消、完成、失败、超时的终态竞争及跨实例停止。验证取消先提交时迟到正文不可查询或保存，完成先提交返回完成事实，客户端断连可按原标识查明结果。
- [x] 3.5 独立记录生成、用量与内部结算。覆盖 NOT_INVOKED、KNOWN 零值、已知值高于或低于预留、UNKNOWN、取消后有可靠用量、输出无效但有消耗，核对实际 token、扣除依据和应扣额度。
- [x] 3.6 持久化固定结算意图，完成释放、幂等确认、超时恢复和待核查处理。注入“扣除成功但确认丢失”、重复收尾及去重证据缺失，断言不重复扣额、恢复不调用模型且不改写生成终态。
- [x] 3.7 补齐审计、结算和停用运维说明。用进程内测试捕获安全事件和错误日志，验证运行记录不会泄露正文、名称、凭据或模型输出。
