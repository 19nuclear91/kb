# Spec Delta

## Purpose

为普通用户建立文档浏览、上传处理、版本查看和授权搜索的浏览器交互契约，使界面准确反映服务端处理状态与独立操作权限，并通过固定版本引用和受保护文件入口查看原始材料，避免上传、阅读与下载资格相互混淆。

## ADDED Requirements

### Requirement: 文档中心必须使用当前用户的真实读取结果

文档中心 SHALL 提供全部文档、可见空间筛选及分页，按既有列表接口读取当前用户可查看的文档。空间目录可管理或可见 MUST NOT 被当成文档可读取的保证；列表 SHALL 区分加载、空集合与失败，不提供当前接口未支持的标题或正文筛选。

#### Scenario: 文档仅通过例外可见
- **WHEN** 用户能够查看一个文档，但其所属空间不在可查看空间目录中
- **THEN** 全部文档列表仍显示服务端返回的该文档
- **AND** 页面不借此枚举或猜测不可见空间的名称

#### Scenario: 仅可管理空间或空间已归档
- **WHEN** 空间目录包含仅可管理或已归档空间
- **THEN** 用户端不将其作为可阅读内容的保证，归档空间不进入普通文档筛选候选
- **AND** 文档展示只采用受保护列表响应

### Requirement: 上传必须选择独立的可上传空间并使用实际密级字典

上传弹窗 SHALL 使用当前可上传空间候选及真实密级字典，允许选择空间、文件和可选标题。页面 MUST NOT 从查看、manage、角色名称或文档所有者推断上传资格，不写死密级数量和名称；服务端校验为实际提交的最终判定。

#### Scenario: 用户只有空间编辑权
- **WHEN** 用户没有某空间 view 或 manage，但上传候选包含该空间
- **THEN** 页面允许选择该候选提交上传，不要求输入空间 ID 或获得管理权限

#### Scenario: 密级字典包含新增值
- **WHEN** 服务端字典包含 0–3 之外的合法密级，或字典读取失败
- **THEN** 前者按返回的实际数值提供选项，后者阻止不完整表单提交并显示读取失败
- **AND** 页面不伪造级别名称或擅自引入服务端没有的上传密级上限

### Requirement: 上传提交与解析发布必须分别展示

用户端 SHALL 区分文件上传、后端已受理和版本解析发布，成功受理后保存返回的文档及版本身份。上传和新版本上传 SHALL 防止重复点击；网络结果不确定时 MUST NOT 自动重发或宣称上传失败一定未落库，也不得因为取得 contentHash 提供越权秒传。

#### Scenario: 上传成功后尚未完成解析
- **WHEN** 上传返回成功，而版本仍处于待处理或解析状态
- **THEN** 页面显示已提交及实际处理状态，不将其显示为已可检索
- **AND** 后续状态查询绑定本次返回的 versionId

#### Scenario: 上传成功但没有后续查看权
- **WHEN** 用户具备上传资格，上传成功后的详情或进度因当前 view 不足返回 404
- **THEN** 页面保留本次提交成功提示并显示当前无法查看后续状态
- **AND** 不自动扩大查看权限、不持续轮询该拒绝，也不把它改报为文件上传失败

#### Scenario: 上传响应丢失
- **WHEN** 文件提交后的网络响应丢失
- **THEN** 页面显示结果尚未确认并允许用户核对文档列表，不自动重复上传创建新版本

### Requirement: 版本详情必须准确跟踪选中版本的处理状态

详情页 SHALL 展示服务端返回的元数据与版本列表，按选中 versionId 查询状态，区分当前发布版本和正在处理的新版本。页面 SHALL 展示排队、处理中、退避等待、维护等待、成功、失败及服务端报告的解析问题，不编造解析百分比；非终态轮询 MUST 有间隔和失败上限并随页面离开暂停。

#### Scenario: 新版本尚未替换旧版本
- **WHEN** 当前版本 V1 已发布，新上传的 V2 仍在解析
- **THEN** 页面分别显示 V1 为当前版本、V2 为处理中，不以 V1 的成功状态冒充 V2 已完成

#### Scenario: 向量维护或解析截断
- **WHEN** 进度返回 EMBEDDING_MAINTENANCE，或版本返回解析截断/问题摘要
- **THEN** 页面分别显示维护等待或相应解析提示，不把维护等待标成失败，不伪造缺失正文

#### Scenario: 页面离开或权限拒绝
- **WHEN** 用户离开详情页、页面隐藏，或轮询返回 401、403、404
- **THEN** 该轮询停止，恢复页面时先重新读取当前事实，不继续无界后台请求

### Requirement: 文档操作按钮必须结合独立能力和版本状态

详情页 SHALL 依据当前操作能力控制下载、新版本上传和失败重试；能力读取失败时相关操作 MUST 不被默认启用。重试 SHALL 同时满足编辑资格与所选版本可重试状态。任何能力标记 MUST 不作为后续操作的授权凭证，操作拒绝后 SHALL 更新页面事实。

#### Scenario: 可查看但不可下载或编辑
- **WHEN** 用户可读取详情，但能力响应的 canDownload、canUploadVersion 和 canRetry 均为 false
- **THEN** 页面保留查看行为，禁用或隐藏相应操作，不依据管理员名称或 ownerId 重新启用

#### Scenario: 版本可重试且能力允许
- **WHEN** 选中版本处于可重试失败状态且 canRetry=true
- **THEN** 用户可以向该明确版本发起一次重试，并显示新返回的处理状态
- **AND** 提交期间防止重复点击，超时不自动重发

#### Scenario: 点击前授权已被撤销
- **WHEN** 页面曾取得 true 标记，但实际下载或上传版本请求被新权限拒绝
- **THEN** 页面按最新拒绝更新操作状态，不继续依赖旧标记重试放行

### Requirement: 搜索必须只消费现有授权检索能力

搜索页 SHALL 通过 POST JSON 提交 query 及有界数量参数，展示服务器返回的有序片段、标题和版本信息。首期 SHALL 搜索全部当前可见内容，不发送未支持的空间筛选或使用旧 GET 检索；失败不能伪装为空结果，空结果不得推断存在不可见文档。

#### Scenario: 提交搜索
- **WHEN** 用户输入关键词并提交
- **THEN** 请求发往不含关键词的固定 POST 路径，页面按实际响应顺序展示结果
- **AND** 页面地址、持久存储和日志不保存该关键词

#### Scenario: 未命中和依赖故障
- **WHEN** 检索成功返回空列表，或接口返回 503
- **THEN** 前者显示未找到可用结果，后者显示暂不可用，两种状态可区分

### Requirement: 引用抽屉必须绑定原始文档版本和分块

搜索和问答 SHALL 复用固定版本引用查看交互，按返回的 docId/versionId/chunkId 核对片段。AVAILABLE 展示完整存储片段及来源提示；CHUNK_UNAVAILABLE 只表示当前没有匹配片段，并提供服务器返回的原版本入口。缺少版本身份或读取被拒时 MUST 不猜测、补最新版本或保留旧正文。

#### Scenario: 引用产生后发布新版本
- **WHEN** 用户点击命中 V1 的引用，而文档当前版本已变成 V2
- **THEN** 抽屉仍核对 V1，不自动显示 V2 或用相同 chunkIdx 替换旧分块

#### Scenario: 原分块不可用
- **WHEN** 引用接口返回 CHUNK_UNAVAILABLE 且仍提供 V1 的文件路径
- **THEN** 抽屉提示片段当前不可用，保留原版本文件入口，不宣称永久删除或曾存在该分块

#### Scenario: 来源未知或当前被拒
- **WHEN** 引用缺少 versionId，或核对接口返回 404
- **THEN** 前者不构造版本引用请求，后者清除对应旧片段、标题和文件入口
- **AND** 页码或来源范围缺失保持未知，不生成精确原件高亮承诺

### Requirement: 预览和下载必须分别消费受保护文件入口

用户端 SHALL 通过带认证头的同源业务请求读取指定版本文件，不拼接令牌、对象存储地址或签名直链。预览仅按现有 PDF 和纯文本支持范围展示，下载按独立权限执行；读取前重新处理实际授权结果，临时文件资源在关闭、切换或退出后 SHALL 释放。

#### Scenario: 有查看权但没有下载权
- **WHEN** 用户可预览某版本但不具备其 download 权限
- **THEN** 页面可以请求受保护预览，不将预览资格解释为下载资格，也不绕过下载拒绝

#### Scenario: Office 文件不能预览
- **WHEN** 指定版本预览返回 415
- **THEN** 页面提示当前格式不支持在线预览，只有独立下载资格允许时才提供下载操作

#### Scenario: 切换版本或关闭预览
- **WHEN** 用户从 V1 切换到 V2、关闭预览或退出登录
- **THEN** V1 的临时 Blob 地址和页面文件状态被释放，不在新上下文恢复旧文件
