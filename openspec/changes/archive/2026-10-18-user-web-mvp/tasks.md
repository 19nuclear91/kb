# Tasks

实施范围见 proposal，设计见 design，行为契约见四份新增规格。复选框记录实施完成情况；实际检查命令与结果记录于 `docs/user-web-operations.md`。

执行与验证范围：仅保留进程内的纯函数、状态机、单组件、独立 service/controller 单元测试，以及类型检查、静态构建和纯架构检查。依赖使用 Mock/Stub，组件使用模拟 DOM，HTTP 和流式响应使用内存替身；controller 与 service 分别测试，不组装完整业务链路。MyBatis 只构建内存映射、绑定参数并消费 Mock ResultSet，不取得数据库连接或执行 SQL。

本变更不编写或执行集成、端到端、真实浏览器测试；不启动完整应用、开发服务器、网关或 HTTP 监听，不运行或连接 PostgreSQL、Redis、MinIO、Docker、Testcontainers、嵌入式数据库及真实模型/供应商服务。说明文档继续编写，但不为 README、Markdown、配置示例或 Javadoc 文案编写内容断言/快照测试。测试命令必须限定上述范围，不运行会带入外部依赖或文案测试的全量旧测试集。
