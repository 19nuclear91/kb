# Spec Delta

## ADDED Requirements

### Requirement: 空间详情必须提供受独立资格控制的健康雷达入口

空间详情 SHALL 在当前 knowledge:health:read、目标 manageable=true 且未归档均确认后显示“知识健康雷达”，链接到 `/admin/spaces/:spaceId/health-radar`。入口不自动预取雷达统计或专用页面代码；任一资格未确认或查询失败时不按旧结果开放。原复审概况与管理操作继续按各自既有资格提供，不强制先经过雷达。

#### Scenario: 合格管理员进入雷达
- **WHEN** 用户有雷达读取权限且当前空间可管理、未归档
- **THEN** 空间详情提供指向本空间的入口，用户主动打开后按雷达路由重新核验

#### Scenario: 缺少独立雷达资格
- **WHEN** 空间管理资格有效但用户没有 knowledge:health:read
- **THEN** 不显示可用雷达入口，原四类复审概况和合法管理动作仍按原规则使用

#### Scenario: 归档与取消归档
- **WHEN** 空间已归档，或刚完成取消归档
- **THEN** 前者显示诊断暂停而不提供可用入口；后者重新读取空间及当前资格后才恢复入口，不推断复审日期已重置

### Requirement: 空间雷达入口必须随当前资格变化失效

空间管理资格或雷达权限失效时，入口 SHALL 立即按已确认的新事实关闭；空间详情重新核对、切换目标或身份时不能复用旧目标入口与统计。雷达结果及返回链接不授予空间管理、文档阅读或处理资格，返回空间详情后继续执行既有目标读取规则。

#### Scenario: 管理资格被撤销
- **WHEN** 空间摘要重读后 manageable=false
- **THEN** 入口与该空间受保护内容清除，不能通过先前显示的入口继续访问诊断

#### Scenario: 从雷达返回后处理
- **WHEN** 用户从诊断页返回空间或文档管理页面
- **THEN** 目标页面按当前资格重新加载，不能把雷达的成功响应作为指定、改派或其他写入许可
