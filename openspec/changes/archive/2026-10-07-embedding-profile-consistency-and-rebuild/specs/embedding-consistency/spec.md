## Purpose

为查询和文档向量建立可追踪、不可混用的语义身份，保证模型接入、配置变更和重建切换期间，同一次向量比较始终使用兼容的模型与预处理规则，并对未知来源的历史数据采取明确的安全降级。

## ADDED Requirements

### Requirement: 向量空间身份必须由不可变 profile 描述

系统 SHALL 使用部署预配置的 profile 描述模型来源、模型标识及版本、维度、距离度量、查询与文档的配套预处理/任务类型及适配器版本。同一
profileId 的语义定义 MUST 不可变；改变任一语义字段必须使用新身份。连接凭据、超时和批量大小 MUST NOT 被当成向量空间身份。

#### Scenario: 同名同维度但不同模型来源

- **WHEN** 两个 profile 的模型名和维度相同但模型来源或版本不同
- **THEN** 系统将它们判为不兼容，不在一次向量检索中混用

#### Scenario: 重启试图改写已有身份

- **WHEN** 实例以已有 profileId 加载不同的语义定义
- **THEN** 实例拒绝启动或就绪，不覆盖持久化定义及当前启用身份

#### Scenario: 配套查询与文档预处理

- **WHEN** 同一 profile 声明不同但配套的查询和文档预处理规则
- **THEN** 两侧分别执行对应规则，不因规则名称不同而错误拒绝，不忽略未支持的规则

#### Scenario: 凭据正常轮换

- **WHEN** 部署仅轮换访问同一模型的密钥
- **THEN** profile 身份保持不变，不因此要求重建

### Requirement: 生产配置必须显式合法且与存储兼容

系统 MUST 拒绝生产环境的 local-hash profile、未声明身份的默认配置、未知 provider/预处理规则以及非 1024 维或非余弦配置。非法配置
MUST NOT 静默回落为 local 或默认维度；持久存储维度不匹配 MUST 阻止向量服务就绪。显式开发环境 SHALL 支持合法的 1024 维本地
profile。

#### Scenario: 生产误用离线实现

- **WHEN** 生产实例配置 local-hash 或只保留旧的隐式默认 provider
- **THEN** 实例拒绝启动并提示配置名，不输出密钥

#### Scenario: 配置跨维度模型

- **WHEN** 新 profile 声明 768 或 1536 维，或者数据库向量列与 1024 维约束不符
- **THEN** 系统拒绝该配置，不自动执行跨维度数据或索引迁移

### Requirement: profile 管理不得成为任意内容外发入口

系统 SHALL 只向有管理读取资格者提供无密钥的已登记 profile 摘要。重建请求 MUST 仅引用 profileId，MUST NOT 接受或回显
endpoint、密钥、模型覆盖或客户端自称的语义身份。模型预检 MUST 使用固定非敏感输入，不使用业务正文进行连通性探测。

#### Scenario: 请求夹带外部地址

- **WHEN** 发起重建时请求包含 endpoint、apiKey 或模型覆盖字段
- **THEN** 返回 400，不调用该地址且不开始维护

#### Scenario: 查询配置摘要

- **WHEN** 合格操作者查询 profile 清单
- **THEN** 返回身份、语义和就绪摘要，不包含 endpoint 或访问凭据

### Requirement: 向量结果必须可验证且与输入一一对应

系统 MUST 在查询和写入前验证结果的 profile、数量、1024 维、有限数值和非零范数。批量结果必须与输入一一对应；缺失、重复、越界或额外结果
MUST 被拒绝，不得排序后误配正文。上游提供模型身份时 MUST 按受控适配映射核验，响应缺少身份不能被描述为已验证实际模型权重。

#### Scenario: 重复 index 但数量正确

- **WHEN** 两条输入收到数量正确但 index 重复的远程结果
- **THEN** 本批被拒绝，不将任一错误匹配向量写入分块

#### Scenario: 非法数值或零向量

- **WHEN** 查询或文档 embedding 含 NaN、Infinity、全零值或错误维度
- **THEN** 向量不用于距离计算或持久发布，错误可诊断且不泄露输入内容

#### Scenario: 上游声明其他模型

- **WHEN** 返回的模型标识不符合选定 profile 的受控模型映射
- **THEN** 拒绝结果，不将其标记为目标 profile 产物

### Requirement: 向量查询必须绑定当前可信身份与执行代次

系统 SHALL 在一次查询中固定生成向量的 profile 和执行代次，并在实际向量检索前重新核验当前启用事实；仅匹配身份的当前版本分块可参与向量召回。状态或代次变化时
MUST 改为仅 BM25 或明确拒绝，不得用旧向量比较新数据。无身份的裸向量 MUST NOT 绕过此规则。

#### Scenario: 模型响应期间开始重建

- **WHEN** 查询已选择旧 profile，但模型返回前系统进入维护
- **THEN** 该查询不执行旧向量召回，改为受权限保护的 BM25

#### Scenario: 向量检索正在执行时切换

- **WHEN** 一次旧 profile 的数据库向量检索尚未完成，维护请求准备覆盖向量
- **THEN** 覆盖等待该检索安全结束，不出现一次查询读取新旧空间进行比较

#### Scenario: 同维度不兼容历史分块

- **WHEN** 库中存在其他 profile 或未知 profile 的 1024 维向量
- **THEN** 它们不参与当前 profile 的向量召回，历史版本也不因此进入当前版本检索

#### Scenario: 内部调用仅提供向量字面量

- **WHEN** 调用方尝试不携带可信 profile/执行代次直接提交向量
- **THEN** 系统拒绝该向量调用，不通过兼容接口跳过一致性检查

### Requirement: BM25 降级必须保留原授权边界

系统 SHALL 在维护、未知身份或兼容客户端不可用时提供受控 BM25 降级；全文召回 MUST 不依赖 embedding
profile。ACL、密级、当前版本、发布及归档约束 MUST 保持不变。控制事实读取失败 MUST 明确报错，不得凭旧缓存启用向量服务；合法远程临时故障可降级但必须可观测。

#### Scenario: 维护期间撤权或升密

- **WHEN** 重建期间用户权限被撤销或文档密级升高后发起新搜索
- **THEN** BM25 按最新权限事实过滤，不因向量关闭而放宽访问

#### Scenario: 当前实例未配置新 profile

- **WHEN** 系统已激活新 profile，但某运行中的查询实例没有对应客户端
- **THEN** 该实例仅执行 BM25 并报告 embedding 不就绪，不调用旧模型代替

#### Scenario: 无法读取控制状态

- **WHEN** 实例无法可靠读取当前控制事实
- **THEN** 返回服务错误，不依靠缓存中的 ACTIVE 状态继续向量查询或写入

### Requirement: 向量写入身份必须来自生成过程

系统 MUST 将生成向量时固定的 profile、执行代次和执行资格与结果关联，提交时重新校验；MUST NOT
从提交时的默认模型配置补标身份。已失效资格、旧代次或与当前允许目标不匹配的结果 MUST 不得覆盖向量、发布版本或修改新持有者状态。

#### Scenario: 旧 Worker 迟到提交

- **WHEN** 已失去资格的 Worker 在新代次恢复后提交旧结果
- **THEN** 提交被拒绝，当前向量、任务进度和版本指针保持不变

#### Scenario: 提交时模型配置改变

- **WHEN** 结果由 profile A 生成，提交时默认客户端已经变为 B
- **THEN** 系统不把结果标记成 B，不通过更换标签接受不兼容结果

### Requirement: 旧数据和首次初始化必须显式建立信任

系统 MUST 保留旧正文、分块标识、索引及原模型名称，将无法确认完整来源的旧向量视为未知身份，不得仅凭模型名认领。首次升级及空库初始化
SHALL 进入仅 BM25、上传可用且普通解析暂停的未初始化状态，经显式选择 profile、重建和校验后启用混合检索。重启 MUST NOT 自动选择或切换
profile。

#### Scenario: 旧数据库只有 embed_model

- **WHEN** 数据库升级且旧分块只有模型名称
- **THEN** 原分块和模型名称保留，向量身份仍未知，不参与向量召回

#### Scenario: 空库首次部署

- **WHEN** 尚无文档的系统显式选择合法 profile 并完成预检及零目标校验
- **THEN** 系统进入 ACTIVE，后续普通解析使用该 profile

#### Scenario: 首次协议升级仍有旧二进制

- **WHEN** 部署准备首次启用新协议但仍存在不支持身份/代次检查的旧 app 或 Worker
- **THEN** 升级流程要求停止并排空这些实例后才允许恢复业务，不宣称旧新二进制混部安全
