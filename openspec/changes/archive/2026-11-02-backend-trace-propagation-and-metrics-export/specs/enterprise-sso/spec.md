# Spec Delta

## MODIFIED Requirements

### Requirement: 浏览器认证响应和日志必须最小化

新增认证响应 MUST 标记 Cache-Control: no-store；回调与返回页面契约 MUST 防止通过 Referer 传播授权参数。日志、审计、错误与追踪属性不得输出密码、授权码、state、浏览器证明、结果凭证、会话令牌、外部 subject 或平台原始响应。生产代理访问日志 SHALL 使用不带查询参数的路径投影，服务端追踪 SHALL 只记录不带查询参数的路由模板；错误只使用固定类别和服务端关联标识。

#### Scenario: 平台错误含敏感内容
- **WHEN** 平台错误正文包含用户信息、授权码或令牌
- **THEN** 客户端、应用日志及审计仅出现固定错误类别，不回显原文

#### Scenario: 通过网关访问回调
- **WHEN** 浏览器带平台授权参数进入回调并跳回本平台
- **THEN** 认证响应禁止缓存，跳转不复制原查询字符串，日志配置不记录回调原始 URI 参数

#### Scenario: 回调进入追踪
- **WHEN** 追踪已启用且浏览器带授权参数进入回调
- **THEN** 跨度属性只含路由模板与状态类别，不含授权码、state 或原始 URI 查询串
