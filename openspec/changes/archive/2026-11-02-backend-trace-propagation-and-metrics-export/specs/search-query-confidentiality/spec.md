# Spec Delta

## MODIFIED Requirements

### Requirement: 查询相关日志不得记录原始敏感内容

系统控制的业务应用、AI 服务及网关的日志与遥测输出（追踪跨度属性、指标标签与 exemplar）SHALL 不记录检索词、问答问题、筛选值、候选名称查询、原始查询字符串、请求或响应正文、会话令牌，以及可能包含这些内容的原始异常文本或堆栈。此规则 MUST 同时覆盖 `/api/search`、`/api/search/categories` 和 `/api/search/tags` 的成功与失败。失败诊断 SHALL 使用固定处理阶段和安全的错误类别或状态。前置代理的访问日志规则 SHALL 在上线前核查，不得记录原始查询字符串或请求体。

#### Scenario: 异常内容回显检索词

- **WHEN** 召回、检索、模型或配额流程抛出消息、原因链或上游响应体含有检索词的异常
- **THEN** 应用异常日志只包含固定阶段与安全类别或状态，不包含该词或原始异常内容
- **AND** 对外错误仍遵循既有通用文案与授权边界

#### Scenario: 旧 GET 到达受控网关

- **WHEN** 旧客户端向受控网关发送带 q 的 GET 请求并被拒绝
- **THEN** 系统控制的访问日志不记录原始查询字符串或其值

#### Scenario: 发布前核查前置代理

- **WHEN** 将新检索入口部署到带前置代理的环境
- **THEN** 上线核查确认该代理的访问日志不会保存查询字符串或请求体；未完成核查时不得宣称端到端日志保密已验证

#### Scenario: 搜索候选异常携带名称
- **WHEN** 分类或标签候选读取、分页解码或依赖调用抛出包含目录名称、筛选值或游标内容的异常
- **THEN** 日志不输出这些值及原始堆栈，响应使用固定安全错误，候选子路径不退回通用异常明细日志

#### Scenario: 追踪与指标输出
- **WHEN** 启用追踪或指标导出后处理搜索、候选或 AI 召回请求
- **THEN** 跨度属性、指标标签与 exemplar 只含固定阶段、路由模板与安全类别，不含检索词、筛选值、请求头值或查询字符串
