# Spec Delta

## MODIFIED Requirements

### Requirement: 降级和容量占用必须可观测且不泄露查询

系统 SHALL 提供检索结果类别、固定阶段耗时、降级原因、准入拒绝、实际在途和响应结束后仍执行的低基数指标，并使其可经业务应用的指标导出端点被监控系统抓取；阶段耗时直方图 MUST 按既有阶段与总预算显式分桶。AI 检索客户端 SHALL 以固定类别记录检索失败原因，区分拒绝、超时、依赖故障与协议损坏。日志与指标 MUST 不包含查询、正文、令牌、完整远程异常或按用户/请求/profile 任意身份扩张的标签。配置项须校验正值、容量关系、阶段与总预算及响应预留关系，非法值不得静默回落默认值。

#### Scenario: 成功降级与整体失败
- **WHEN** 一次请求成功降级为 BM25，另一次因数据库超时失败
- **THEN** 运维可区分阶段降级和整体失败，不将两者都记录为零命中

#### Scenario: 取消后仍执行
- **WHEN** 请求已返回而其底层工作尚未退出
- **THEN** 实际在途及结束后仍执行指标保持占用，实际退出后下降

#### Scenario: 非法预算或容量配置
- **WHEN** 总预算不大于响应预留、阶段上限超过可执行总预算，或用户上限超过实例上限
- **THEN** 配置校验失败并只报告配置项，不静默调小或输出敏感配置值

#### Scenario: 导出端点抓取
- **WHEN** 监控系统抓取业务应用的指标端点
- **THEN** 取得上述检索指标，阶段耗时直方图包含 2 秒、3 秒、1.5 秒与 8 秒的边界桶

#### Scenario: AI 检索失败分类
- **WHEN** AI 检索因超时、拒绝、依赖故障或协议损坏失败
- **THEN** 失败原因以固定类别计数，不含问题文本或远程错误体

## ADDED Requirements

### Requirement: 查询 Embedding 与 rerank 出站调用不得携带内部追踪上下文

查询 Embedding 与 rerank 的远程调用 MUST NOT 携带追踪传播头或 baggage，也 MUST NOT 携带调用用户的会话令牌；该约束对预算路径与默认客户端路径同等成立。供应商响应中的追踪头 MUST NOT 改写本地追踪上下文。

#### Scenario: 远程调用请求头
- **WHEN** 搜索触发远程 Embedding 或 rerank 调用
- **THEN** 请求仅含服务端配置的认证头与请求体，不含 `traceparent`、`tracestate`、baggage 或 satoken

#### Scenario: 两条调用路径一致
- **WHEN** 同一 profile 分别经预算路径与默认客户端路径发起调用
- **THEN** 两条路径的请求头规则一致，均不携带追踪上下文
