## 3. 身份核对与有界 HTTP 传输

- [x] 3.1 实现受控 base URL、路径前缀、HTTPS 与显式 loopback HTTP 校验，构造仅含必要认证和 JSON 头的独立客户端；组件测试覆盖路径前缀、非法 URL、不同身份令牌隔离、无 Cookie/追踪头及重定向不转发凭据。
- [x] 3.2 实现引用令牌的批次冻结和所有引用身份的 `/api/auth/me` 预检；测试错用用户、过期会话、停用、强制改密、缺失凭据及第二身份失败时搜索零调用，确认未引用身份不请求。
- [x] 3.3 实现连接、绝对请求期限和实际响应字节/深度限界，覆盖正文读取与解析并支持中断取消；使用进程内响应流替身和可控时钟验证慢正文、持续小块、无长度超限、不支持的编码及资源关闭，不启动 HTTP 服务或建立网络连接。
- [x] 3.4 实现单次请求、不自动重试、不跟随重定向或认证重放的失败路径；使用进程内传输替身返回状态和异常，核对 3xx、401、403、429、503、断连和超时的调用次数及后续调用停止。
- [x] 3.5 在采集文档中补充环境变量注入、身份预检、超时及服务端限制说明；人工核对不包含令牌赋值样例或自动登录流程，并区分客户端取消与远端执行停止。

## 4. 响应转换与最终排名保留

- [x] 4.1 实现身份和搜索成功包装的严格解码，搜索只接受 HTTP 200、UTF-8 JSON、code=200 和数组 data；组件测试覆盖合法空数组、204、200 失败包装、空/null、重复键和尾随数据。
- [x] 4.2 实现有效筛选识别和唯一 `X-Search-Filter-Version: 1` 校验；测试带条件的缺失、重复和未知版本全部失败，无筛选仍兼容缺少头的响应，不会取消条件重发。
- [x] 4.3 实现有界命中转换，仅保留精确三元组并维护原数组顺序；测试大于 2^53 的 ID、Long.MAX_VALUE、小数/字符串/溢出/缺失版本、重复三元组、同版本不同分块及 score 与顺序相反的结果。
- [x] 4.4 在采集文档中说明合法空结果、协议失败、最终排名和同版本多分块的区别；以转换测试验证正文、标题、score 和远程错误不进入结果或诊断。
