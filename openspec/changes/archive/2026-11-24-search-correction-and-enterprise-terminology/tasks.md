# Tasks

依据 [proposal.md](proposal.md)、[design.md](design.md) D1–D11 和 [10 份增量规格](specs/) 实施。复选框表示实际完成状态；生成规划产物本身不代表代码、迁移或验证已执行，完成证据见 [verification.md](verification.md)。

任务按依赖排列：数据与资格先行，管理写入和凭据机制支撑管理 API；匹配计划、执行协议和入口保护就绪后接入页面。每组同步交付自身单测及说明，第 10 组汇总离线回归与构建结果。文中测试名称为建议名称，实施时可按现有组织调整，并在验证记录中记录实际名称和命令。

验证仅限本地独立单元测试、无连接的参数绑定与结果映射、模拟 DOM、静态检查、类型检查及编译构建，所有身份、持久化、HTTP 和模型依赖使用 Mock／Stub／内存替身。不编写或执行集成测试、前后端或跨服务联调、端到端测试和真实浏览器验收；不启动或连接 PostgreSQL／ParadeDB、Redis、对象存储、容器、前后端服务或第三方 API，也不使用 Testcontainers、嵌入式服务或独立 HTTP 测试服务器替代。

说明文档和迁移脚本作为交付物人工审阅；不编写或执行针对 README、Markdown、规格、注释、文案或 SQL 文本的内容断言、快照及存在性测试。业务输入输出、HTTP 协议、参数映射及构建产物的依赖隔离仍按功能行为验证。原 10.1～10.5 已移除，相关真实约束、锁／回滚、执行计划、网络取消、浏览器和业务排序效果保留为未验证范围，不转为隐藏待办或本变更完成、核验、归档的前置任务；删除任务不代表这些行为已验证。
