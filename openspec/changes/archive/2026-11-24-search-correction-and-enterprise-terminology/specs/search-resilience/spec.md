# Spec Delta

## MODIFIED Requirements

### Requirement: 一次搜索必须共享绝对截止时间

合法请求通过已有会话与强制改密门禁、开始搜索处理时 SHALL 建立单调时钟截止时间，默认总预算 8 秒，覆盖权限解析、连接与锁等待、控制事实、词典读取与一致性核验、匹配与查询扩展、Embedding、分类关系与全部筛选计算、召回、重排及结果准备。各阶段 MUST 使用剩余总预算，不重置计时；默认预留 500 毫秒用于结果准备和响应交付。截止后不得接受迟到成功或启动下一阶段，应向应用响应链路交付明确失败；网络向客户端实际送达时间不计入该执行预算。搜索候选请求独立取得同样的总预算，包含其授权、目录读取和响应准备。

#### Scenario: 前置阶段耗时
- **WHEN** 权限解析与控制读取已经消耗部分总预算
- **THEN** 后续阶段只使用剩余时间，不再获得新的 8 秒

#### Scenario: 总预算耗尽
- **WHEN** 截止时间到达且没有可交付的合法结果
- **THEN** 搜索以 503 结束等待，取消在途工作，不把迟到结果改写为成功

#### Scenario: 没有可见范围
- **WHEN** 当前权限已可靠解析为无可见范围
- **THEN** 文档命中为空，不调用外部模型，不披露是否存在不可见文档；ASSISTED 仍按公开词典契约取得或核验辅助信息，其读取失败不能伪装成功空建议

#### Scenario: 分类和标签筛选耗时
- **WHEN** 分类后代或标签关联计算消耗召回剩余预算
- **THEN** 后续召回及响应使用原截止，不另开无预算的文档 ID 预查询或重置阶段计时

#### Scenario: 候选目录读取超时
- **WHEN** 已通过准入的搜索候选请求在权限、目录读取或响应准备期间超时
- **THEN** 按既有 503 与实际工作退出规则收尾，不以空目录表示成功，也不因响应结束提前释放在途容量

#### Scenario: 词典查询接近总截止
- **WHEN** 词典核验和匹配消耗部分预算，剩余时间不足以执行向量阶段
- **THEN** 按原阶段预算规则跳过向量，仍使用一致查询计划完成受限 BM25；总预算不足时明确失败，不另给词典或召回一个新时限

### Requirement: 检索失败必须具有稳定且安全的信号

搜索 SHALL 保留各入口规定的成功响应结构；非法输入返回 400、正文超限返回 413、用户并发超限返回 429、实例满载或可识别的依赖/预算不可用返回 503。增强入口另以 400 与固定类别 ASSISTANCE_LIMIT_EXCEEDED 表示辅助规模超限，以 409 与 ASSISTANCE_STALE 表示已验证建议的修订变化或到期。401/403 继续表达已有认证与资格门禁，未知内部错误保留 500。AI 的检索故障 SHALL 通过既有 error 事件附加固定 code=SEARCH_UNAVAILABLE，页面映射为“检索暂不可用，请稍后重试”，不展示远程错误体或推断文档存在性。

#### Scenario: 可选阶段失败但成功返回候选
- **WHEN** Embedding 或 rerank 发生允许的降级且有合法结果
- **THEN** 搜索仍返回成功结果，降级事实通过受控观测呈现，不误报整体不可用

#### Scenario: AI 检索故障到达页面
- **WHEN** 单轮或多轮已建立流，而本轮检索失败
- **THEN** 发送安全 error 事件及 SEARCH_UNAVAILABLE，页面显示固定检索不可用提示，随后按既有规则核对轮次

#### Scenario: 未知错误码
- **WHEN** 前端收到旧服务没有 code 的 error，或未知 code
- **THEN** 使用现有通用错误提示并核对状态，不回显未经白名单映射的 message

#### Scenario: 区分过期和伪造
- **WHEN** 可验证上下文已过期，或上下文损坏、身份和条件绑定不匹配
- **THEN** 前者返回 409 ASSISTANCE_STALE，后者返回 400，不把任意非法输入都当成可自动刷新的版本冲突

## ADDED Requirements

### Requirement: 增强工作必须共享原搜索准入与退出边界

原搜索、ASSISTED、ORIGINAL 和搜索候选 SHALL 共享既有实例与可信用户准入、无等待队列及实际工作退出后释放规则。词典读取和匹配也计入占用，不因词典处理在召回前执行而绕过容量。取消或超时须停止新阶段、取消在途工作并隔离迟到结果，仍在执行的词典工作占用原名额，不创建无界线程、请求或队列。

#### Scenario: 多入口占满同一用户名额
- **WHEN** 同一用户已有普通搜索和增强请求占满默认两个实际在途名额
- **THEN** 再次提交 ORIGINAL 或建议采用返回 429 与 Retry-After，不作为另一类免费容量放行

#### Scenario: 词典读取未退出
- **WHEN** 请求已超时响应但词典底层读取仍未退出
- **THEN** 原用户名额与实例名额继续占用，迟到读取不能恢复原结果或提前释放容量

### Requirement: 匹配与扩展必须在召回前完整检查规模

ASSISTED 默认最多处理 8 个不重叠匹配位置，每个歧义位置最多 8 个组候选，累计选择最多 8 项，自动扩展新增表达最多 32 个、其文本与包装合计最多 2048 个 code point。各阶段最终查询表达还须满足原查询字符上限。任一超限 SHALL 在模型调用与召回前返回 ASSISTANCE_LIMIT_EXCEEDED，不截断候选伪装唯一、不部分采用选择或悄悄丢弃原文；ORIGINAL 不受词典匹配数量影响。

#### Scenario: 一个简称有过多含义
- **WHEN** 同一匹配位置存在 9 个启用组
- **THEN** 返回辅助规模超限，不只取前 8 项后对外声称候选完整或自动选定一项

#### Scenario: 合法长查询扩展后过长
- **WHEN** 原 query 未超限，但加入全部应采用表达后超出最终查询上限
- **THEN** 在首次 Embedding 和召回前拒绝辅助执行，用户可明确以相同完整原文选择 ORIGINAL

#### Scenario: 多个选择中一项非法
- **WHEN** 累计选择中的一个目标不属于对应片段
- **THEN** 整个请求按非法输入拒绝，不先搜索其他合法选择

### Requirement: 词典读取失败不得隐式变成原词成功

ASSISTED 中词典修订、关系或建议核验无法可靠取得时 SHALL 返回安全 503，不使用未核验旧快照、成功空词典或自动 ORIGINAL 代替。已成功核验的零匹配与真正空词典可以正常搜索；ORIGINAL 和旧入口须不依赖词典。查询相关的有限工作预算须覆盖匹配与结果准备，不靠每次加载完整无界词典证明限界。

#### Scenario: 空词典与读取失败
- **WHEN** 首次空词典可靠返回 revision=0，或读取发生超时
- **THEN** 前者以空扩展完成合法搜索，后者返回 503，两种情况不混淆

#### Scenario: 词典坏而原检索可用
- **WHEN** 用户主动使用 ORIGINAL 或旧接口且其必要依赖正常
- **THEN** 正常执行原检索，不额外要求词典健康，也不发送辅助成功说明

### Requirement: 增强响应与外部载荷必须共同受限

结果和全部辅助字段 SHALL 共同纳入既有默认 4 MiB 搜索成功响应上限，在完整编码和交付前核对。不得先发送成功命中再拼接未核验说明，超限时明确失败；辅助字段也不得单独截断成合法空建议。传往 Embedding 与 rerank 的编码载荷继续遵守原限额、超时、取消和降级规则，采用建议不会获得新的外部调用重试额度。

#### Scenario: 结果加建议超过响应限额
- **WHEN** hits 单独未超限但完整响应超过上限
- **THEN** 返回明确不可用错误，不交付不完整 JSON 或省略建议后冒充完整辅助结果

#### Scenario: 重排请求超限
- **WHEN** 已授权材料与本次有效表达使重排载荷超限
- **THEN** 按既有规则回退原授权候选顺序，不删除筛选或重发另一组查询

### Requirement: 辅助状态观测必须使用有限类别

系统 SHALL 在现有搜索观测中区分 ORIGINAL、ASSISTED、成功无词条、成功有扩展或建议、辅助超限、建议失效和词典不可用，并观测词典阶段耗时及实际执行占用。标签只能采用固定模式、阶段和原因，不含 query、词条名称或 ID、dictionaryRevision、selectionContext、用户或任意查询派生值。不得以建议生成数作为搜索成功或真实质量提升证明。

#### Scenario: 辅助失败与正常零匹配
- **WHEN** 一个请求未匹配任何词条，另一个因词典不可用失败
- **THEN** 运维可以按固定类别区分，不把两者都记为无建议成功

#### Scenario: 多次维护和查询
- **WHEN** 词典修订持续增加且用户提交不同查询
- **THEN** 不因词条、修订和查询值增长而产生任意基数标签，不输出输入内容
