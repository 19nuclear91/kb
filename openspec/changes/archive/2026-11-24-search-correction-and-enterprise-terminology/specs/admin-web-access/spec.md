# Spec Delta

## ADDED Requirements

### Requirement: 企业词典管理入口必须按独立读取资格开放

管理导航 SHALL 增加 `/admin/search-terms`，仅当前有效权限包含 `search:term:read` 时加载页面与目录数据。页面直接访问、刷新及路由懒加载沿用既有身份门禁，不依赖可管理空间或身份目录。只有写权限、标签权限、空间管理或管理员角色名称不能开放入口；资格未确认或读取失败时不得按旧值加载。

#### Scenario: 空间目录故障
- **WHEN** 当前 search:term:read 已确认，但可管理空间目录不可用
- **THEN** 词典管理入口仍按自身资格开放，不额外读取空间或身份目录判断资格

#### Scenario: 只有写权限或缓存模块
- **WHEN** 当前只有 search:term:write，即使页面代码之前已缓存
- **THEN** 不挂载管理目录或发出读取请求，不从缓存或写权限推导读取资格

#### Scenario: 模块加载期间撤权
- **WHEN** 页面资源下载期间当前读取资格被撤销
- **THEN** 迟到模块不恢复旧页面或发起词典请求，应用导航与退出继续可用

### Requirement: 词典管理登录返回与恢复必须重新核对资格

登录返回 SHALL 只接受固定 `/admin/search-terms`，不接受名称查询、术语正文、筛选、片段、未注册子路径或站外地址。返回后重新核对身份与 search:term:read；后台恢复或权限变化时清理目录、游标、草稿和回调，再按当前资格读取，不自动恢复或重放写入。非法返回值沿用文档中心安全回退。

#### Scenario: 登录后返回管理页
- **WHEN** 未登录用户访问固定词典管理路径并完成登录和必要改密
- **THEN** 可返回该路径，当前读取资格确认后才加载页面与目录

#### Scenario: 返回地址携带词条查询
- **WHEN** 返回值为 `/admin/search-terms?nameQuery=...` 或未注册的词条子路径
- **THEN** 不将其作为合法返回地址，不保存或记录查询内容，使用既有安全回退

#### Scenario: 写入未知后恢复页面
- **WHEN** 页面隐藏前有结果未确认的词典写入，随后恢复
- **THEN** 按当前身份与资格重新读取事实，不自动发出原写入，也不因清理本地请求宣称服务端已撤销
