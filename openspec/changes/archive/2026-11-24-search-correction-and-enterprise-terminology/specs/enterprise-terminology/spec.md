# Spec Delta

## Purpose

建立供企业登录用户共同使用的人工术语词典，以稳定的术语组和单向错词映射表达正式名称、简称及旧称。通过独立维护资格、明确的歧义与启停规则，让搜索能够采用当前可信的词条关系，同时不从词典推导文档访问资格或知识命中事实。

## ADDED Requirements

### Requirement: 术语组必须具有稳定身份和明确的名称关系

术语组 SHALL 具有稳定 termId、标准名称、简短释义、别名列表、enabled、version 和创建及修改时间。别名类型仅接受 SYNONYM、ABBREVIATION、FORMER_NAME，分别表示同义表达、简称和旧称；这些关系仅表示检索用途的人工等价关系。新建初始启用且 version=0，编辑保留 termId；首期通过启停维护已有身份，不提供物理删除。

#### Scenario: 创建带简称的术语
- **WHEN** 合格维护者创建标准名称“办公自动化”、释义及简称“OA”
- **THEN** 系统保存一个稳定术语身份及明确的简称关系，后续改名不会生成另一 termId

#### Scenario: 旧称不代表制度有效性
- **WHEN** 用户通过已登记旧称查到资料
- **THEN** 旧称关系不改变文档当前发布版本、适用期或审核状态，不表示旧制度仍然适用

### Requirement: 词条文本必须统一规范化并有界校验

标准名称、别名及错词 SHALL 去首尾空白并做 NFC 规范化，长度为 1–64 个 Unicode code point；简短释义规范化后为 1–256 个 code point。文本 MUST 为合法 Unicode 且不含控制字符，内部空格不折叠。比较键仅将 ASCII A–Z 折为小写，不自动转换简繁体、全半角或拼音。每组最多 20 个别名；名称、别名、关系类型和其他字段非法、未知或重复时返回 400，不截断或忽略。

#### Scenario: 大小写及规范等价输入
- **WHEN** 维护者以首尾有空白的“OA”和“oa”作为同组两个别名提交
- **THEN** 规范化比较后判为重复并返回 400，不保存两个等价别名

#### Scenario: 超长和非法文本
- **WHEN** 名称超过 64 个 code point、别名超过 20 项，或文本包含 NUL、孤立代理项
- **THEN** 返回 400，既有词条、版本及成功审计均不改变

### Requirement: 名称唯一性与跨组歧义必须分别表达

标准名称 SHALL 按比较键全局唯一，停用组仍占用名称，重名返回 409。同组内标准名称与别名不得重复；不同组允许共享别名，或某组别名等于另一组标准名称。一个表达关联两个及以上当前启用组时 SHALL 为歧义表达，不能按创建顺序、关系类型或标准名称优先级自动选择其中一组。歧义由当前启用关系整体判定，不能依据已截断候选推断唯一。

#### Scenario: 简称有两个含义
- **WHEN** “PM”同时是“项目管理”和“产品经理”两个启用组的简称
- **THEN** 搜索将 PM 作为歧义表达，候选带标准名称与释义，由用户选择

#### Scenario: 标准名称与其他组别名碰撞
- **WHEN** 一个组的标准名称也是另一个启用组的别名
- **THEN** 该表达同样按歧义处理，不以标准名称身份自动胜出

#### Scenario: 停用名称仍被占用
- **WHEN** 创建请求使用已有停用组的标准名称
- **THEN** 返回重名冲突，维护者须操作原有身份

### Requirement: 错词必须是指向明确术语的单向映射

错词映射 SHALL 具有稳定 correctionId、错误表达、目标 termId、enabled、version 及创建修改时间；目标必须是已存在的启用术语组，正确表达取其标准名称。错误表达按比较键全局唯一，包含停用映射，且不得与任何现存组的标准名称或别名相同；反向创建名称或别名时也须检查。冲突返回 409。错词不得指向另一错词、加入同义集合或产生递归纠正链。

#### Scenario: 登记常见错词
- **WHEN** 维护者把“报消”登记为指向标准名称“报销”的术语组
- **THEN** 搜索“报消”可获得到“报销”的建议，搜索“报销”不会反向扩展“报消”

#### Scenario: 错词与合法术语冲突
- **WHEN** 新错词已作为某组名称或别名存在，或新别名已被错词映射占用
- **THEN** 返回 409，不同时把同一表达解释为自动同义扩展和待确认错误

#### Scenario: 目标改名
- **WHEN** 错词目标组的标准名称修改成功
- **THEN** 后续新建议使用该组新标准名称，旧建议的采用须经过版本重核

### Requirement: 全公司公开词条必须独立于文档命中和管理资格

启用词条 SHALL 可用于当前有效登录、主体有效且已完成必要改密用户的搜索辅助，不要求词典管理资格或某空间 view。普通搜索仅返回当前查询相关的词条、释义和建议，不提供完整管理目录。提示 MUST 不含关联文档身份、标题、命中数、查询热度或其他用户输入；词条可见不表示存在可访问文档，也不授予文档、空间或管理权限。

#### Scenario: 当前没有可见文档
- **WHEN** 用户身份有效但没有可检索文档，查询匹配公开启用术语
- **THEN** 可以展示术语建议，搜索 hits 为空，不提示存在隐藏资料，也不调用外部模型

#### Scenario: 没有管理读取资格
- **WHEN** 普通用户可获得某词条的搜索建议并请求管理目录
- **THEN** 管理读取仍按独立资格拒绝，建议不能作为管理授权凭据

### Requirement: 启停必须同时约束扩展和建议采用

停用术语组 SHALL 使其名称、别名及指向它的纠错映射退出新的搜索辅助；相关映射自身 enabled 保留。重新启用后，仅自身仍启用的映射恢复可用。停用纠错映射只停止该项建议。写入成功后的新请求须读取已提交事实，不凭旧缓存继续使用；在途请求可以完成其已取得的一致词典版本，响应必须标明该版本。

#### Scenario: 目标组停用再启用
- **WHEN** 目标组被停用后重新启用，其中一个映射自身仍启用，另一个已独立停用
- **THEN** 前者恢复建议，后者保持不可用，不自动重建或启用映射

#### Scenario: 在途搜索与停用竞争
- **WHEN** 搜索已取得词典版本 R，随后停用提交为 R+1
- **THEN** 原搜索可以按 R 返回并标明 R，提交之后启动的新搜索须采用 R+1，点击旧建议按过期规则处理

### Requirement: 词典修订必须提供一致的全局版本

词典 SHALL 提供单调递增的 dictionaryRevision，初始为空词典时为 0；每次首次成功维护使其恰好递增一次，并与实体版本、业务数据、命令回执和审计原子提交。一次搜索的关系、歧义判定、扩展、纠错建议及说明 MUST 来自同一修订，不混用新旧字段。实体匹配重放不再次推进任一版本；读取不能改变版本。

#### Scenario: 两个组同时调整同一简称
- **WHEN** 多个管理写入并发改变“PM”的关联
- **THEN** 每次搜索只观察一个完整已提交修订，不从混合状态误判 PM 的唯一含义

#### Scenario: 写入事务失败
- **WHEN** 实体、回执或成功审计无法完整提交
- **THEN** 本次词条修改及两个层级的版本递增都不生效

### Requirement: 词典写入必须绑定意图并检测并发冲突

创建、编辑和启停 SHALL 要求 X-Request-Id，更新另要求 expectedVersion。回执绑定当前操作者、操作、目标、前置版本及完整规范化载荷；别名顺序不改变集合含义。匹配重放须先核对当前写资格，再返回首次最小回执。过期版本、同标识不同载荷、无实际变化或绑定不完整返回 409，不重复写入或覆盖并发事实。明确成功回执与后续当前状态读取分别表达。

#### Scenario: 编辑与停用竞争
- **WHEN** 两个请求基于同一实体版本分别编辑名称和停用
- **THEN** 至多一项首次变更成功，另一项返回版本冲突

#### Scenario: 响应丢失后匹配重试
- **WHEN** 创建已提交，用户以同一请求标识及等价载荷重试
- **THEN** 返回原身份与首次版本回执，不重复创建、递增修订或写成功审计

#### Scenario: 撤权后重放
- **WHEN** 原操作者写资格被撤销后请求旧回执重放
- **THEN** 返回 403，不因原请求曾成功而延续资格

### Requirement: 管理目录必须按用途有界分页

术语组和错词管理目录 SHALL 分别支持名称字面包含查询、启用状态过滤及按稳定 ID 升序的游标分页，limit 默认 20、最大 100。nameQuery 规范化后最多 64 个 code point，空白表示不限，经 POST 正文提交。返回 items、hasMore、nextCursor、dictionaryRevision，不返回文档关联或全局命中数。游标至多 4096 字符，绑定用户、目录种类、条件、修订和位置，每页重新鉴权。

#### Scenario: 名称包含通配符
- **WHEN** 管理者以包含百分号或下划线的 nameQuery 查询
- **THEN** 按字面值匹配，不将字符解释为查询表达式

#### Scenario: 分页期间修改词典
- **WHEN** 当前有读取资格，但续页所绑定 dictionaryRevision 已变化
- **THEN** 返回 409，重新读取目录，不拼接不同修订的数据

#### Scenario: 跨目录或身份复用游标
- **WHEN** 把术语目录游标用于错词目录，或以另一身份和条件提交
- **THEN** 返回 400，不继续沿用旧上下文

### Requirement: 管理输入和失败必须保持可辨认且安全

管理接口 SHALL 严格拒绝未知或重复字段、尾随 JSON、非法 ID、版本、枚举和 URL 查询参数；请求体实际读取上限为 32 KiB。无认证为 401，无对应资格或身份门禁拒绝为 403，授权后目标缺失为 404，非法输入为 400，正文超限为 413，状态冲突为 409，依赖故障为安全 503。响应均为 no-store；不回显原始异常、查询或输入载荷。

#### Scenario: 未声明长度的大正文
- **WHEN** 无 Content-Length 的管理请求实际读取超过 32 KiB
- **THEN** 停止读取并返回 413，不先加载完整正文

#### Scenario: 目录依赖不可用
- **WHEN** 管理目录查询失败
- **THEN** 返回安全 503，不显示为成功空词典或无可用目标
