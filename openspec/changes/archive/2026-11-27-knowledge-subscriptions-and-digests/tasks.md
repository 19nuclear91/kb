# Tasks

本变更已完成实现及约定的独立离线检查，47/47项完成。证据和边界见 [verification.md](verification.md)。需求见本变更八份增量规格，事务、数据及接口选择见 [design.md](design.md)。2026-11-27已同步8份主规格并归档，见[归档记录](archive-record.md)。未执行迁移或部署。

本变更的测试仅限可独立运行的进程内单元/组件测试、内存仓储或 Mock、虚拟时钟、模拟 DOM，以及无连接的映射解析/参数绑定检查。前端和后端分别测试，不启动应用或 HTTP 测试服务器，不执行前后端联调、真实浏览器端到端测试，也不连接或启动数据库、Redis、对象存储、Docker、模型等外部组件；不新增这些集成测试入口或验收任务。编译、类型检查、静态构建、包体隔离和 OpenSpec 结构校验保留。

文档任务只负责编写和维护说明，不编写或运行检查文档是否存在、是否包含指定文字/章节、示例是否出现等内容断言；迁移 SQL 和 Mapper 也不以字符串包含断言代替行为测试。离线结果不代表真实数据库锁、约束、事务、查询计划、浏览器或部署已验证，这些边界不作为本变更任务完成条件。
