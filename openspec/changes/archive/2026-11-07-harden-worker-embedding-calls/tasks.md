# Tasks

以下任务依据 `design.md` 与三份规格增量实施。每组同步交付自身测试和说明；测试默认使用受控时钟、响应流、执行屏障和内存替身。真实网络、数据库或供应商验证须在记录中单独说明，不能用 mock 结果代替。

## 1. 配置与受控故障契约

- [x] 1.1 在 Worker 绑定 `kb.worker.embedding` 的请求／响应／深度及重建／探测超时配置，落实设计默认值和校验范围；通过默认绑定、边界、零／负数／小数／溢出／错误类型测试，并验证错误不回显秘密。
- [x] 1.2 定义有限的 Embedding 故障原因与可重试属性，使故障对象不持有供应商正文、完整地址或原始异常消息；通过原因映射与敏感值探针测试，确认 TIMEOUT 与 LEASE_LOST／LEASE_UNKNOWN 可区分。
- [x] 1.3 更新 `docs/embedding-rebuild-operations.md` 的 Worker 配置、默认限额及调优说明；人工逐项核对实际绑定项，并通过 profile 指纹回归确认调整运行限额不改变模型身份。

## 2. 执行预算、双通道容量与实际退出

- [x] 2.1 实现 Worker 执行身份、单调父截止、HTTP 子截止和一次性结果选择，按需兼容扩展 common 的纯 JDK 预算接口；通过可控时钟测试验证剩余预算、晚注册取消、成功交接、旧计时器迟到及超时不等于数据库失租。
- [x] 2.2 实现普通解析／重建共用一个业务槽位、独立一个探测槽位及零等待队列，已准入工作进入执行通道后才执行 claim；通过并发准入、执行器拒绝、空领取与异常测试，验证未准入时数据库领取次数为零。
- [x] 2.3 实现独立截止调度、每通道有限取消动作、关闭与实际工作退出记账；通过忽略中断、阻塞关闭、重复取消和完成竞争测试，验证槽位不提前释放、不启动替代执行且最终只释放一次。
- [x] 2.4 增加通道实际占用与逻辑结束后仍占用指标；使用内存指标注册表验证忙／闲转换、逻辑终结后继续占用、两通道隔离及标签不含任意身份。
- [x] 2.5 更新 `docs/embedding-rebuild-operations.md` 与 `docs/parse-task-recovery-operations.md` 的槽位、取消和实际退出语义；人工对照状态机及指标，说明阻塞通道的定位与恢复边界。

## 3. 双限制分批与完整结果组装

- [x] 3.1 为公共远程 Embedding 客户端增加可选分批扩展，保留既有构造和 app 查询默认策略；通过现有 `RemoteProfileEmbeddingClientTest`、`EmbeddingCallBudgetTest` 及新增兼容用例验证原行为和预算传递。
- [x] 3.2 实现 Worker 按实际 JSON UTF-8 字节与条数双限制的有序计划及完整单条预检；使用真实编码器验证中文、补充字符、转义、前缀、包络、恰好限额和末尾单条超限零发送。
- [x] 3.3 将各 HTTP 子批的局部下标映射回完整输入，保留数量、模型身份、1024 维、有限非零向量校验；通过多子批下标重置、重复／缺失下标及后续失败用例验证不交付部分结果。
- [x] 3.4 更新 `docs/embedding-rebuild-operations.md` 的 HTTP 子批与数据库领取批次关系；以固定示例人工核对拆批规则、原文完整性及未提交子批可能重复调用的恢复语义。

## 4. 有界 HTTP 传输与生产装配

- [x] 4.1 建立 Worker 隔离的双通道 JDK HTTP 客户端及早期禁止自动重试／重定向策略，替换生产装配中的无界 transport 并拒绝无预算网络入口；通过装配、初始化顺序与供应商头隔离测试验证三个入口使用相同限制。
- [x] 4.2 实现非 200 响应零正文消费、有界成功响应及严格 JSON 校验；通过受控响应流验证长度头超限、无长度头、边界多一字节、内容编码、重复属性、深度、尾随根、未知字段及一次传输尝试。
- [x] 4.3 将请求编码、连接／等待、正文读取和解析接入子截止与取消登记，确认客户端／响应资源实际退出后才解除占用；通过慢响应、截止前后竞态、阻塞关闭及跨通道隔离测试验证迟到结果无效。
- [x] 4.4 增加固定用途与原因的调用耗时／故障指标并更新传输运维说明；通过指标和异常摘要探针验证无正文／凭据／地址，记录 JDK 重试初始化、客户端生命周期的专门检查及真实网络尚未覆盖的边界。

## 5. 普通解析接入与恢复语义

- [x] 5.1 将 `ParseTaskRunner` 接入共享业务通道，实际领取最多一份立即执行任务，替换依赖 Future 完成状态的容量释放；通过 `ParseTaskRunnerRecoveryTest` 及新增准入用例验证配置领取多条、空领取、超时未退出时不再次 claim。
- [x] 5.2 从流水线开始传播现有 900 秒默认父预算到全部 Embedding 子批，绑定心跳与取消信号并实现成功发布交接；通过 `DefaultParsePipelineTest` 及竞态用例验证前置解析耗时、停止下一子批、旧心跳隔离和迟到结果不发布。
- [x] 5.3 将受控模型故障接入 `FailureClassifier` 与原恢复服务，永久错误立即死信、408／429／5xx 等暂时故障退避；通过分类及恢复测试验证固定摘要、超时仍有资格时记录失败、维护／失租不写旧状态及无部分索引发布。
- [x] 5.4 更新 `docs/parse-task-recovery-operations.md` 的新失败分类、领取上限、实际退出及人工重放说明；人工核对 API 与持久恢复行为，保留无解析器时不领取的现有约定。

## 6. 重建生成接入与原子提交

- [x] 6.1 将 `EmbeddingRebuildRunner` 接入共享业务槽位，续租失败或异常均停止本次执行；通过 Runner 与租约服务回归验证普通解析未退出时不领取、空批次释放、迟到心跳和新执行隔离。
- [x] 6.2 为重建生成阶段建立默认 300 秒截止，覆盖读取分块、编码与全部子批，成功后原子交接至既有提交门禁；通过生成／提交测试验证续租不延长截止、子批共用剩余时间、旧计时器无效以及 token／epoch／正文复核。
- [x] 6.3 更新重建故障映射，使超限／协议错误／认证拒绝直接 BLOCKED，临时故障按原预算退避；通过失败及恢复测试验证旧持有者不能写回、当前领取批次无部分提交、原成功批次不重新生成。
- [x] 6.4 更新 `docs/embedding-rebuild-operations.md` 的生成截止、粗粒度公开错误码与细分诊断、BLOCKED 恢复说明；人工核对原 run、成功进度及恢复版本前置条件。
