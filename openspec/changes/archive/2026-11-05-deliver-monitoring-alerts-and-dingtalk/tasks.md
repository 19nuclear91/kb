# Tasks

按组推进，每组同时交付相关行为测试和操作说明。所有任务已完成并经限定范围的离线验证；实现和验证证据见 `docs/monitoring-verification.md`。实际部署地址、secret、自建适配器发布镜像 digest 仍由部署环境提供，不在本变更中构建镜像或执行部署。

验证范围仅包含进程内单元／组件测试、Mock 或内存传输替身、合成时序、编译打包及本地 CLI 静态配置检查。不包含需要启动前端、完整应用、HTTP 监听服务、数据库、Redis、监控组件或容器的集成／端到端／烟测，也不交付或执行真实钉钉验收入口。文档编写和人工核对保留，不编写针对文档、README、Markdown、注释或示例文本的内容存在、字符串或快照断言测试；运行时配置的语义校验仍属于验证范围。

- [x] 4.3 实现中文故障／解除模板和受控链接，按转义后 UTF-8 字节预算省略详情；通过敏感 annotation canary、未知告警、外部 URL、长度边界及截断计数测试。
- [x] 4.4 实现隔离 HTTP 传输及钉钉加签，固定生产目标、禁止重定向并限制响应；使用官方契约核对、已知签名向量及注入的进程内传输替身，验证请求不携带入站身份头或追踪传播。
- [x] 4.5 实现 errcode=0 才返回 204、外部失败映射 503 且单次最多一次发送；通过内存传输替身模拟 HTTP 200／非零业务码、损坏响应、超时、连接失败、响应丢失和调用方取消，不启动 HTTP 替身服务。
- [x] 4.6 实现单实例滑动窗口限流、并发上限和总期限，失败尝试也计入速率；用可控时钟与并发屏障验证上限、边界、实际退出后释放及无后台补发。
- [x] 4.7 导出固定结果枚举的投递指标，收口日志和 HTTP 指标；通过 registry 抓取及日志 canary 测试确认正文、机器人 URL、token、签名和原始错误体均不泄露。
