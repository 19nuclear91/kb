# 文档管理查询规格增量

## Purpose

为文档授权和搬迁提供独立于正文阅读权限的最小管理查询，使具有当前空间管理资格的操作者能够定位文档，同时保持标题、文件名、正文、版本内容和存储地址的既有访问边界。

## ADDED Requirements

### Requirement: 管理文档清单必须按当前管理范围过滤

系统 SHALL 提供 `GET /api/admin/documents`，仅返回调用者当前拥有所属空间 manage 资格或 `space:manage-all` 资格的未删除文档。查询
MUST 不以 view、edit、文档例外授权、文档所有者或角色名称替代管理资格。最小清单不因正文 ACL 或操作者密级不足而隐式授予正文读取能力。

#### Scenario: 只有空间管理资格

- **WHEN** 启用用户能够管理空间 A，但没有 A 中文档的 view 权限
- **THEN** 清单返回 A 中未删除文档的最小管理记录
- **AND** 该用户通过内容接口读取标题、版本或正文仍按原有规则被拒绝

#### Scenario: 只有正文读取资格

- **WHEN** 用户能够阅读某文档，但不具备其所属空间的 manage 或跨空间管理资格
- **THEN** 管理清单不包含该文档，即使用户是上传者或拥有文档例外授权

#### Scenario: 跨空间管理资格

- **WHEN** 用户当前持有 `space:manage-all`
- **THEN** 清单可包含全部空间中的未删除文档，但不因此提供内容读取或密级调整资格

### Requirement: 管理清单必须使用固定的最小字段投影

每条管理记录 SHALL 仅包含 `documentId`、`spaceId`、`spaceArchived`。响应 MUST NOT
包含标题、文件名、文档密级、所有者、版本、解析错误、分块、存储键、外部地址或正文；即使调用者同时持有 view，也 MUST
使用相同的最小投影。正文信息只能通过既有受保护接口另行取得。

#### Scenario: 管理者同时可以阅读

- **WHEN** 同一用户同时持有管理和阅读权限并调用管理清单
- **THEN** 返回字段仍严格限定为三个管理字段，不自动合并普通文档摘要

#### Scenario: 文档包含敏感标题和文件名

- **WHEN** 查询命中的文档带有敏感标题、文件名、存储键和解析错误信息
- **THEN** 响应及查询错误信息不包含这些值

### Requirement: 归档内容必须保持管理可达而不恢复读取

管理清单 SHALL 默认包含归档空间中的未删除文档，支持显式 `spaceArchived` 布尔过滤；无当前发布版本的新文档也 SHALL
可被定位。软删除文档 MUST 始终排除。查询 MUST NOT 取消归档、激活版本、触发解析或改变既有读取与检索结果。

#### Scenario: 归档空间中的文档

- **WHEN** 空间已归档且用户仍有该空间管理资格
- **THEN** 管理清单仍返回文档 ID 并标记 `spaceArchived=true`
- **AND** 普通文档列表、详情、预览、下载和检索不因本查询恢复可见

#### Scenario: 首个版本尚未解析完成

- **WHEN** 新上传文档已有记录但尚无当前发布版本
- **THEN** 管理清单可按文档 ID 定位它，不把“没有当前版本”误认为文档不存在

#### Scenario: 文档被删除

- **WHEN** 管理者以精确 ID 查询已软删除的文档
- **THEN** 返回空集合，不返回历史标题、版本或对象信息

### Requirement: 管理清单必须支持有界且授权一致的分页过滤

清单 SHALL 支持可选的正整数 `spaceId`、`documentId`、布尔 `spaceArchived`、`limit` 和 `cursor`，按 `documentId` 倒序返回
`items`、`hasMore`、`nextCursor`。limit 默认 20、范围 1–100；非法参数、未知过滤字段和不匹配查询条件的游标 MUST 返回 400。过滤及分页
MUST 在当前可管理范围内完成，MUST NOT 返回未授权总数。

#### Scenario: 指定无权管理的空间或文档

- **WHEN** 合法用户使用无权管理或不存在的 spaceId/documentId 过滤
- **THEN** 两种情形均返回相同形状的空页，不泄露目标是否存在

#### Scenario: 翻页期间新增文档

- **WHEN** 第一页之后出现 ID 更大的新文档，调用者使用返回的游标继续查询
- **THEN** 继续按上一页末尾 ID 向后读取，不因新记录插入重复返回已遍历记录
- **AND** 不承诺跨请求的冻结快照；删除、搬迁和权限变化按当前事实过滤

#### Scenario: 使用正文相关过滤条件

- **WHEN** 请求试图以 title、fileName 或正文关键词过滤最小管理清单
- **THEN** 返回 400，不使用隐藏字段的匹配结果充当存在性探针

### Requirement: 管理查询必须在每次请求重新校验资格

新查询 SHALL 对无效或缺失会话返回 401，对用户或主部门停用、强制改密状态返回 403；正常身份无管理范围时返回空页。分页游标 MUST
NOT 充当授权凭据。管理授权变更完成后的下一次查询 SHALL 使用新权限范围，响应 MUST 标记 `Cache-Control: no-store`，依赖故障
MUST 不被伪装为空结果。

#### Scenario: 使用旧游标继续访问已撤权空间

- **WHEN** 第一页查询后该用户的空间 manage 被撤销，下一次请求继续使用原游标
- **THEN** 不再返回该空间的文档，也不要求退出并重新登录才生效

#### Scenario: 文档在两页之间搬迁

- **WHEN** 文档迁入调用者无权管理的空间，调用者随后精确查询或翻页
- **THEN** 文档不再出现在管理清单中，游标不能保留原空间管理资格

#### Scenario: 权限或数据库查询故障

- **WHEN** 当前请求不能可靠取得授权事实或执行查询
- **THEN** 返回安全的 503，不返回“没有文档”的成功空页，不暴露 SQL 或底层异常
