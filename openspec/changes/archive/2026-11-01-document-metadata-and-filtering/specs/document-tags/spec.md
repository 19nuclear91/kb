# Spec Delta

## Purpose

建立跨知识空间共享的受控标签词库，使不同空间能够使用同一稳定主题身份组织文档，同时明确标签维护、停用、文档关联及授权筛选的边界，避免名称变化或权限变化造成不可解释的结果。

## ADDED Requirements

### Requirement: 标签必须具有全局稳定身份和唯一名称

标签 SHALL 使用全局稳定 tagId，具有 name、enabled、version、createdAt、updatedAt，初始启用且 version=0。名称去首尾空白、按 NFC 规范化后为 1–32 个无控制 Unicode code point，按不区分大小写全局唯一；停用标签也占用名称。改名保持 tagId，重名返回 409，非法 Unicode、NUL、超限或未知字段返回 400。

#### Scenario: 不同空间使用同一标签
- **WHEN** 财务空间与研发空间的文档都选用“项目 A”
- **THEN** 两者关联同一个全局 tagId，跨空间筛选仍只返回调用者可查看的文档

#### Scenario: 停用后再次创建同名标签
- **WHEN** 字典已有停用标签，管理者再次创建相同规范化名称
- **THEN** 返回 409，引导维护既有标签，而不是产生第二个同名身份

### Requirement: 标签维护必须具有独立功能资格

管理目录读取 SHALL 要求 document:tag:read，新建、改名和启停 SHALL 要求 document:tag:write；两项分别判定，不由空间管理、文档 edit、其他功能权限或角色名称代替。文档编辑者通过受保护候选选用已有标签，不获得创建标签资格。管理响应不含关联文档清单、标题或引用数量。

#### Scenario: 编辑者输入不存在的标签
- **WHEN** 普通文档编辑者希望添加字典中不存在的名称
- **THEN** 不能通过文档保存或候选接口自动建标签，新增词条须由有管理写资格的人员完成

#### Scenario: 标签管理者没有文档阅读权
- **WHEN** 用户具有标签管理资格，但没有某文档的 view
- **THEN** 可以维护字典，不能从字典响应获得该文档的身份、标题或是否关联该标签

### Requirement: 标签启停必须保留已有文档关联

停用 SHALL 阻止新建文档关联，但保留已有关系、当前名称和停用标记；已有关系仍可显示、筛选、保留或移除，移除后不能在停用期间重新添加。重新启用恢复可选性。字典改名或启停不推进每篇文档的 metadataVersion 或 updatedAt，关联变更由文档资料保存执行。首版管理提供启停而非删除已存在标签身份。

#### Scenario: 停用正在使用的标签
- **WHEN** 管理者停用一个被多篇文档使用的标签
- **THEN** 文档关系保持，下一次授权读取显示停用标记；新的关联请求返回 409

#### Scenario: 停用后移除并尝试加回
- **WHEN** 编辑者先移除某停用标签，随后再请求添加它
- **THEN** 第二次请求被拒绝，原先曾关联过不构成重新添加资格

#### Scenario: 文档搬迁
- **WHEN** 文档跨空间搬迁且原来关联的标签含停用项
- **THEN** 已有全局关联整体保留，停用标签不会因搬迁被误判为新关联

### Requirement: 标签写入必须检测并发并严格幂等

新建、改名和启停 SHALL 要求 X-Request-Id，已有标签变更另要求 expectedVersion；绑定操作、操作者、目标及规范化输入。过期版本、相同标识不同载荷和无实际变化为 409。匹配重试重新核对当前写资格后返回首次最小回执，不重复递增版本或写审计；业务、回执和无名称审计必须同事务提交。

#### Scenario: 改名与停用并发
- **WHEN** 两名管理者基于同一版本分别改名和停用
- **THEN** 至多一次首次变更成功，另一请求返回 409，不能以较旧字段覆盖先提交事实

#### Scenario: 创建响应丢失
- **WHEN** 创建已经提交而客户端以原绑定重试
- **THEN** 返回原 tagId 和创建回执，不把本次已创建名称视作另一次重名失败

### Requirement: 标签目录与候选必须有界且按用途授权

目录及候选 SHALL 按 tagId 升序分页，limit 默认 20、最大 100；名称关键词最多 64 个 Unicode code point，采用字面包含匹配并通过 POST 请求体提交。管理目录由独立读取资格访问，编辑候选由目标文档当前 view/edit 访问并仅返回启用词条，筛选候选仅返回当前可查看文档使用的标签（含停用项）。游标绑定用途、上下文和条件，每页重新鉴权，不返回全库关联总数。

#### Scenario: 只有一个文档的编辑例外
- **WHEN** 用户只对某文档有 view/edit 例外，请求该文档标签候选
- **THEN** 可选择全局启用词条，无需标签管理读取权限；候选不提供其他文档信息

#### Scenario: 筛选候选中没有可见引用
- **WHEN** 某标签仅关联当前用户不可查看的文档
- **THEN** 普通筛选候选不展示该标签或隐藏引用数量，管理目录仍按其独立资格工作

#### Scenario: 跨用途复用游标
- **WHEN** 把管理目录游标提交到文档编辑候选，或改变已绑定查询条件
- **THEN** 返回 400，不继续使用原上下文读取词条

### Requirement: 多标签筛选必须全部匹配且按身份判定

文档筛选 tagIds SHALL 为至多 20 个不重复正整数，空数组或省略表示不限制；非空时文档必须关联全部选中 tagId。名称只作展示，不能以同名匹配替代身份。合法但不存在或当前无可见文档引用的 tagId 返回空结果，不忽略条件；重复或非法 ID 返回 400。结果与 total 按文档去重。

#### Scenario: 两个标签只有部分命中
- **WHEN** 选中 A 和 B，文档甲只有 A、乙只有 B、丙同时具有两者
- **THEN** 只有当前可查看的丙进入结果，甲乙不能以任一匹配方式出现

#### Scenario: 标签改名
- **WHEN** 已选 tagId 在两次请求间被改名
- **THEN** 筛选仍按同一身份执行，重新读取使用当前名称，不重新绑定另一个相似标签
