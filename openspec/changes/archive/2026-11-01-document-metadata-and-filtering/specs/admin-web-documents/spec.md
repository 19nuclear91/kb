# Spec Delta

## MODIFIED Requirements

### Requirement: 搬迁必须声明来源并说明例外清除后果

搬迁区块 SHALL 在所属空间可管理时可用，目标空间仅为当前可管理、未归档且不同于所属空间的候选。确认前读取最小搬迁上下文取得 fromSpaceId 和 metadataVersion，明确选择目标分类或未分类；请求携带 targetCategoryId（可显式 null）及 expectedMetadataVersion，MUST 不携带密级。确认说明清除全部例外且不可恢复、需目标管理员重新授出，分类将切换到所选位置、全局标签保留。

#### Scenario: 没有可选目标
- **WHEN** 除所属空间外，当前可管理空间均已归档
- **THEN** 搬迁不可提交，页面说明没有可迁入的空间

#### Scenario: 确认搬迁
- **WHEN** 文档有 3 条例外授权，用户选择目标空间和分类并查看确认说明
- **THEN** 确认说明提示将清除 3 条例外且不可恢复，显示选定的目标分类或未分类
- **AND** 提交包含声明来源、目标、显式分类和元数据版本，不包含密级字段

#### Scenario: 尚未选择分类
- **WHEN** 用户选择目标空间后尚未明确选择分类或未分类
- **THEN** 确认提交保持禁用，不把空选择控件自动解释为 targetCategoryId=null

### Requirement: 搬迁回执与冲突必须按最新归属重新核对

搬迁成功 SHALL 展示回执的清除数量、明细截断标记、clearanceBlockedPrincipalCount、目标分类身份及 metadataVersion；受密级限制人数非零不显示为失败。随后重新读取管理区块、上下文及候选。来源不符、已在目标、目标归档、元数据版本过期和分类不可选 SHALL 分别提示并刷新当前事实，不自动用新版本或未分类重发。匹配重试始终保留原目标分类和预期版本。

#### Scenario: 文档已被他人搬走
- **WHEN** 搬迁返回 409 及 SOURCE_MISMATCH
- **THEN** 页面提示归属已变化并重新读取所属空间，不自动以新来源重试

#### Scenario: 回执明细截断
- **WHEN** 回执 clearedExceptionsTruncated=true
- **THEN** 页面显示清除总数，并说明清除明细未完整列出

#### Scenario: 目标空间有主体受密级限制
- **WHEN** 搬迁回执 clearanceBlockedPrincipalCount 大于 0
- **THEN** 页面说明搬迁已完成，目标空间中部分主体因密级不能看到该文档

#### Scenario: 文档元数据已修改
- **WHEN** 首次搬迁被拒绝为元数据版本过期
- **THEN** 页面提示资料已变化并重新读取最小上下文，下一次人工确认使用新意图而非修改原请求重试

#### Scenario: 目标分类失效
- **WHEN** 提交时所选分类已删除或不属于目标空间
- **THEN** 提示重新选择目标分类，不能自动改为未分类或按名称选另一节点

## ADDED Requirements

### Requirement: 搬迁分类候选必须按目标空间隔离

页面 SHALL 从目标空间管理分类目录分层分页读取选择项，明确提供“未分类”。切换目标空间立即清除旧分类、游标和加载状态；旧响应不得进入新目标。分类目录不可确认或树版本冲突时禁用分类提交并提供重读。目录名称来自目标空间管理资格，不借读取源文档资料补足。

#### Scenario: 切换目标空间后响应迟到
- **WHEN** 用户从目标 A 改为 B，而 A 的分类响应随后返回
- **THEN** A 的分类不能填入 B 的选择器或用于构造搬迁请求

#### Scenario: 目标目录为空
- **WHEN** 目标空间没有任何分类
- **THEN** 页面仍允许用户明确选择未分类，不制造虚拟分类 ID 或自动勾选确认

### Requirement: 搬迁上下文必须支持不可阅读文档的管理者

搬迁 SHALL 使用独立最小上下文获取并发版本，不能要求文档详情成功或从文件版本推算 metadataVersion。详情被拒绝时继续以文档 ID 标识管理目标。上下文失败或无当前管理资格时禁止确认，网络不确定结果沿用原绑定核对，不通过读取新上下文猜测上次成功。

#### Scenario: 管理者无法读取标题
- **WHEN** 文档详情返回 404，而管理清单和最小搬迁上下文均合法返回
- **THEN** 仍可选择目标空间及分类并完成搬迁，确认界面以文档 ID 标识目标

#### Scenario: 新后端接口尚未部署
- **WHEN** 前端无法取得合法最小上下文或新字段
- **THEN** 搬迁保持禁用并提示当前不可用，不回退成省略分类和版本的旧请求
