# Tasks

各组按依赖顺序实施；具体行为见对应 delta spec，接口与锁顺序见 `design.md`。下列任务均为待实施，每项的验收应记录实际执行结果。

本次执行范围：

- 仅包含编码、纯内存单元/组件测试、编译、类型检查和静态打包；测试使用明确的类/文件白名单，不使用全库自动发现入口。
- 允许 Mock/Stub、受控时钟/Promise/流、使用服务替身的独立控制器测试和模拟 DOM；不启动完整应用或监听 HTTP 端口。
- 不编写或执行集成、端到端、真实浏览器、数据库及跨实例测试，不运行或连接 PostgreSQL、Redis、MinIO、Docker、模型服务或嵌入式数据库/缓存等组件；不执行迁移、SQL、真实事务/锁验证、查询计划或部署演练。
- SQL、迁移和数据库访问代码作为实现产物交付并静态审查；内存替身验证仅证明已覆盖的输入、业务分支和调用生命周期，不证明真实数据库约束、隔离、回滚或并发行为。
- 文档条目仅交付说明。不编写或执行 README、Markdown、说明文案、注释和示例的内容断言测试，不运行其中示例作为验收，也不以源码/DDL 字符串断言替代功能测试。OpenSpec 结构校验可单独执行。
