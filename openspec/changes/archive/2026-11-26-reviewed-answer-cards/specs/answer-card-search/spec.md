# Spec Delta

## Purpose

为用户提供可浏览、可按问题查找的经审核标准答案，在排序和数量截取前核对卡片及所有依据的当前访问与有效性，并明确搜索条件、结果身份及故障语义，使用户取得可核对的审定答案原文。

## ADDED Requirements

### Requirement: 卡片文本搜索必须具有独立输入与响应协议

`POST /api/answer-cards/search` SHALL 仅接受 query、spaceId、limit。query 去首尾空白后为 1–256 个 Unicode code point；spaceId 省略或 null 不限，否则为规范正整数十进制字符串；limit 默认 10、范围 1–20 的 JSON 整数。成功返回 R 包装的 items、asOfDate、evaluatedAt 和 appliedQuery、appliedSpaceId，并声明 `X-Answer-Card-Version: 1`。不返回总数或搜索游标。

#### Scenario: 独立空间限定
- **WHEN** 用户提交问题并限定空间 A
- **THEN** 仅搜索归属 A 且当前可展示的卡片，响应准确回显已应用条件

#### Scenario: 夹带文档筛选
- **WHEN** 请求包含 fileType、categoryId、tagIds、updatedFrom、mode 或其他未知字段
- **THEN** 返回 400，不忽略不支持的条件或调用普通文档搜索替代

#### Scenario: 缺省空间与非法数量
- **WHEN** 用户省略 spaceId 或提交合法 null，或将 limit 设为 21、字符串或小数
- **THEN** 前者搜索本人全部可见空间中的卡片，后者拒绝且不执行搜索

### Requirement: 搜索必须匹配审定正文并优先问题命中

搜索 SHALL 只以当前已发布内容修订的标准问题、常见问法和答案正文参与文本匹配，按标准问题或常见问法归一后精确相等、问题字段分词命中、仅答案正文分词命中三组依次排序；组内按文本相关性、卡片 ID 确定顺序。返回原审定文本，不生成新答案、不把相关性解释为适用性证明。适用范围及来源原文不参与匹配。

#### Scenario: 问题与正文都出现关键词
- **WHEN** 卡片 A 的常见问法匹配完整问题，B 仅答案正文命中同一关键词
- **THEN** A 排在 B 前，匹配到的是当前审定卡片修订

#### Scenario: 草稿加入关键词
- **WHEN** 新关键词只出现在未发布草稿或旧卡片版本中
- **THEN** 不因该词返回当前卡片，也不输出草稿摘要

#### Scenario: 无匹配
- **WHEN** 授权与有效性检查成功，但审定文本没有匹配项
- **THEN** 返回真实空 items，不借来源文档全文或历史聊天拼造答案

### Requirement: 权限与来源检查必须先于结果截取

每一路候选 SHALL 在排序截取前应用卡片空间、当前发布修订、卡片及全部来源访问、来源最新版本与适用期修订、全部适用日期和 spaceId 条件。不可见或暂停卡片不得占用 limit，不以全局 topN 后剔除代替。搜索项按卡片身份去重，不因多条来源、问法或 ACL 命中复制结果。

#### Scenario: 高分不可见卡片占满全局前列
- **WHEN** 无权或来源已变化的高分卡片多于 limit，而可见范围仍有相关项
- **THEN** 从完整合格集合截取相关项，不因先取全局前列而伪造空结果

#### Scenario: 关联来源部分可读
- **WHEN** 用户只可读某卡片两份依据中的一份
- **THEN** 卡片不进入结果，不展示摘要、标题、隐藏数量或另一份来源的身份

### Requirement: 搜索结果必须足够核对且不携带维护私有内容

每项 SHALL 返回 cardId、固定 revisionId 与 revisionNo、标准问题、至多 400 个 Unicode code point 的答案原文前缀及 truncated、适用范围、卡片日期声明、复审提示和受保护详情相对路径。普通结果不含审核私有意见、贡献者、请求回执、原始排名分值或来源正文。所有身份精确字符串化；来源完整清单在详情按当前权限独立读取。

#### Scenario: 长答案摘要
- **WHEN** 审定答案超过 400 个 Unicode code point
- **THEN** 摘要为 Unicode 安全的原文前缀并标记 truncated，不由模型改写

#### Scenario: 复审已逾期
- **WHEN** 卡片符合展示条件且复审为 OVERDUE
- **THEN** 仍可命中并返回待复审提示，不宣称内容已经失效

### Requirement: 打开结果必须固定选中修订且重新判定

从搜索项打开的详情 SHALL 携带选中的 revisionId。只有该修订仍为当前可展示发布版时返回其原文；若已被新卡片修订替代、暂停或失去访问，返回统一 404，不自动展示另一修订。用户可以主动重新搜索或浏览以取得新事实，旧结果不形成持续授权。

#### Scenario: 点击前发布新版卡片
- **WHEN** 搜索命中修订 R1，随后卡片发布 R2，用户点击 R1
- **THEN** 不以 R2 替换点击目标，提示原结果不可用并允许用户主动重新搜索

#### Scenario: 来源在搜索后到期
- **WHEN** 搜索后业务日期跨过来源截止日，再打开详情
- **THEN** 详情按新日期拒绝，不因已有搜索摘要而继续返回整张答案

### Requirement: 卡片浏览必须独立于关键词检索并按当前范围分页

`GET /api/answer-cards` SHALL 支持可选 spaceId、limit、cursor，limit 默认 20、最大 100，按卡片 ID 倒序返回当前可展示卡片的最小列表、hasMore、nextCursor 和 asOfDate。游标绑定用户、用途、空间及排序位置，每页重新检查完整展示条件。无关键词浏览不调用搜索接口，也不返回维护草稿或隐藏总数。

#### Scenario: 浏览期间来源更新
- **WHEN** 两页之间部分卡片来源发布新版
- **THEN** 后续页排除这些卡片，游标不能冻结旧展示范围

#### Scenario: 不可见空间
- **WHEN** 普通用户限定不存在或不能查看的空间
- **THEN** 两者均返回空列表，不披露空间名称、隐藏卡片数量或区分存在性

### Requirement: 卡片搜索必须有界并真实表达不可用

卡片搜索 SHALL 使用独立有界容量：每实例同时最多 8 个请求、每用户每实例最多 2 个，总预算 5 秒，单语句超时不超过剩余预算且最多 3 秒，响应正文最多 256 KiB；非法运行配置阻止启用。无排队容量返回 429 与 Retry-After，预算耗尽或事实依赖失败返回 503，响应超限不得返回部分成功。浏览与来源候选亦须有界读取。

#### Scenario: 搜索超时
- **WHEN** 卡片搜索未能在预算内完成
- **THEN** 返回安全 503，不标记为没有标准答案或使用上次结果

#### Scenario: 容量已满
- **WHEN** 同一用户或实例的卡片搜索名额耗尽
- **THEN** 新请求返回 429，不创建无界等待队列或自动放宽条件重试

### Requirement: 搜索内容与查询行为必须保持私密

query SHALL 只经 POST JSON 正文传输，不进入 URL、浏览器持久存储、日志、审计或遥测标签。输入上限 16 KiB，未知字段、非法 Unicode、重复字段及尾随 JSON 拒绝。成功及错误均 no-store，身份切换后的旧结果不得复用。搜索为只读，不生成卡片、通知、持久搜索历史或成功维护事件。

#### Scenario: 搜索失败包含原问题
- **WHEN** 数据库或参数处理异常包含查询文本
- **THEN** 对外及日志仅保留固定错误类别，不回显异常或保存原问题

### Requirement: 卡片检索必须保留既有消费者契约

新增卡片结果 SHALL 仅经独立卡片协议返回。现有 `/api/search`、`/api/search/assisted`、AI 上下文、SSE、固定文档分块引用及检索采集工具保持原结果种类。卡片搜索使用用户明确提交的卡片 query，不隐式应用文档搜索中的术语选择或查询扩展；卡片故障不伪装成文档检索故障或自动调用 AI。

#### Scenario: 原 AI 与评测采集
- **WHEN** 既有调用方请求文档搜索
- **THEN** 仍仅取得原格式的文档分块，不能出现伪造 docId、versionId 或 chunkId 的卡片

#### Scenario: 文档搜索采用纠错
- **WHEN** 用户只在文档区域采用术语纠错或歧义建议
- **THEN** 不暗中改变卡片区域已提交的问题或已有结果

#### Scenario: 客户端遇到旧后端
- **WHEN** 卡片响应缺失协议头或返回未知结构
- **THEN** 客户端显示卡片功能暂不可用，不把旧文档数组解释为标准答案
