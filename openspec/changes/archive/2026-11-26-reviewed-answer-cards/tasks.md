# Tasks

本清单按实际实施及离线验证结果更新。范围以 proposal、六份增量规格和 design D1–D13 为准；设计中没有影响首期范围的未决问题。每组同时交付其离线业务测试和说明。

测试范围仅包括进程内单元/组件测试、Mock 或内存替身、模拟 DOM，以及编译、类型检查、静态构建和 OpenSpec 格式校验。所有下列行为用例均在此范围执行，不编写或执行需要前后端联调、启动业务服务/监听端口、真实浏览器联机或连接数据库、Redis、对象存储、模型等外部组件的测试，也不交付这些测试的运行入口。文档、迁移和 SQL 的说明通过人工审阅维护，不新增检查其文本、标题、关键字或文件是否存在的内容断言测试。离线替身结果不代表真实 SQL、数据库约束/锁/回滚或部署链路已经验证；这些事项不作为本变更任务完成或归档的前置条件。
