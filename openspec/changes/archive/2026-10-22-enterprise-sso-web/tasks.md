# Tasks

验证范围：仅执行被测单元及依赖替身组成的进程内单元测试，使用模拟 DOM、内存 storage、受控请求与导航替身。各任务按明确的测试文件名单运行，不执行全量自动发现、跨模块联合测试、集成测试或端到端测试；不启动应用、HTTP 服务、浏览器、数据库、Redis、MinIO、容器或供应商服务，也不连接这些外部组件。文档任务只交付说明，不增加文档内容断言、文案测试、示例执行或真实环境验收任务。
