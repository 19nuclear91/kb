# Spec Delta

## ADDED Requirements

### Requirement: 审核界面必须展示所审版本的适用期并说明冻结

审核界面 SHALL 在固定版本及轮次的上下文中，按当前访问资格读取并展示该版本的适用期标识与原始声明。活动审核期间明确提示“审核期间适用期已冻结，修改需先撤回”，不提供修改入口。适用期读取失败只显示“适用期暂不可确认”，不阻止查看、批准或驳回，也不显示为未声明。

#### Scenario: 审核人查看待审版本
- **WHEN** 合格审核人打开处于 IN_REVIEW 的候选版本
- **THEN** 页面显示该版本的生效日、截止日和状态，以及冻结说明

#### Scenario: 送审者想修改日期
- **WHEN** 送审者在审核期间查看本人版本
- **THEN** 页面只提示需先撤回才能修改适用期，不提交修改请求

#### Scenario: 适用期读取失败
- **WHEN** 审核界面读取适用期返回 503
- **THEN** 适用期区域显示暂不可确认，审核决定操作按原规则可用
