# Spec Delta

## ADDED Requirements

### Requirement: 空间详情必须提供 ID 级复审概况清单

空间详情 SHALL 在确认管理资格后提供复审概况区块，分为未指定、需重新指定、即将到期、已逾期四个标签，每个标签按服务端游标“加载更多”，不展示总数。每项只显示文档 ID、状态、到期日和责任人显示名，并链接到 `/admin/documents/:documentId`；页面 MUST NOT 为补充标题而额外读取文档详情。读取失败不显示为空清单。空间已归档时清单只读，并提示复审暂停。

#### Scenario: 切换标签
- **WHEN** 管理员从“未指定”切换到“已逾期”
- **THEN** 页面以新状态从首页读取，丢弃前一标签的在途结果和游标

#### Scenario: 读取失败
- **WHEN** 复审清单读取返回 503
- **THEN** 区块显示读取失败并提供重新读取，不显示“没有需要处理的文档”

#### Scenario: 失去管理资格
- **WHEN** 加载更多时返回 404
- **THEN** 区块清除已显示的清单并按空间详情既有规则重新核对管理资格
