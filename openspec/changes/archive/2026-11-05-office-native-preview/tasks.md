# Tasks

本清单按协议配置、后端会话、桥接、代理、页面、部署配置的依赖顺序推进，完成状态以各项勾选为准。

测试仅保留无需启动前端、应用服务或外部组件的隔离单元/组件测试。数据库、Redis、对象存储、ONLYOFFICE、HTTP 和 WebSocket 依赖使用进程内 mock/fake；前端使用 Vitest/jsdom 和模拟查看器消息。不使用真实或嵌入式中间件、Testcontainers、浏览器端到端测试及服务联调。只运行明确筛选的隔离测试类/文件，不执行可能带起外部依赖的全量测试命令。

文档编写和更新仍为交付项，不编写或运行检查说明文档/Markdown 是否包含指定关键词、段落或内容的测试。隔离测试结果不作为真实 ONLYOFFICE 或 Redis 已联调通过的证明。
