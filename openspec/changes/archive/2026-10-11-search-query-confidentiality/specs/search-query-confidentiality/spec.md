# Spec Delta

## Purpose

为知识库检索及 AI 问答中的检索词建立统一的传输和日志保密契约，使正常调用不把查询内容放入
URL，并使请求失败时的应用日志及受控访问日志仍不泄露查询内容、响应正文或凭据。

## ADDED Requirements

### Requirement: 检索仅通过 POST 请求体接收查询

系统 SHALL 仅通过 `POST /api/search` 的 JSON 请求体接收检索词 `query`、候选数 `candidates` 和结果数 `topK`。成功响应 SHALL
保持既有 JSON 字段、授权过滤和排序语义；缺省数量与现有接口一致。URL 查询参数 MUST NOT 成为检索输入。

#### Scenario: 合法检索请求

- **WHEN** 已登录且完成必需改密的用户以 POST JSON 提交非空 `query` 和合法数量
- **THEN** 系统按该用户当前服务端身份执行授权检索，并以既有响应结构返回结果
- **AND** 请求 URL 不含检索词或数量参数

#### Scenario: 缺省数量

- **WHEN** POST 请求体只包含合法的 `query`
- **THEN** 每路候选数默认为 50，`topK` 默认为候选数

#### Scenario: 无效请求体或 URL 参数

- **WHEN** POST 请求体缺少或提供空白 `query`、数量超出现有 1–200 范围，或 `/api/search` 的 URL 携带查询参数
- **THEN** 系统返回固定且不回显输入值的 HTTP 400 响应，不执行检索

#### Scenario: 调用方伪造身份或向量

- **WHEN** 请求体包含 `userId`、角色、密级、`queryVector` 或 profile 声明
- **THEN** 系统不将这些值作为身份、授权范围或查询向量，仍只使用服务端解析的主体与既有查询配置

### Requirement: 旧版 GET 检索停止服务

系统 MUST 停用 `GET /api/search`；通过既有认证与强制改密门禁的 GET 请求 SHALL 返回 HTTP 405，不执行检索，也不在错误响应中回显
URL 查询字符串。

#### Scenario: 已认证旧调用方使用 GET

- **WHEN** 已登录且完成必需改密的调用方请求 `GET /api/search?q=敏感词`
- **THEN** 系统返回 HTTP 405，不返回检索结果，响应不包含该检索词

#### Scenario: 旧调用方没有有效会话

- **WHEN** 未认证调用方请求旧版 GET 接口
- **THEN** 既有认证门禁仍可先返回 HTTP 401，旧接口不会因此提供匿名检索

### Requirement: AI 召回使用相同的保密检索入口

AI 服务 SHALL 通过 `POST /api/search` 的 JSON 请求体发送用户问题与召回数量，MUST NOT 把问题放入 URI；它 SHALL
透传调用者会话并继续使用同一授权检索响应与引用契约。召回失败时的既有对外空结果行为不因传输方法改变。

#### Scenario: 问答召回成功

- **WHEN** 用户提交 AI 问题并具有可见文档
- **THEN** AI 到业务应用的检索请求使用不含问题的固定路径及 JSON 请求体，携带原调用者会话
- **AND** 引用身份、来源字段及 SSE 事件语义与现有契约一致

#### Scenario: 召回被拒或上游不可用

- **WHEN** 业务应用拒绝召回或检索上游不可用
- **THEN** AI 服务维持既有空结果对外表现，不以服务账号或无权限条件重试

### Requirement: 查询相关日志不得记录原始敏感内容

系统控制的业务应用、AI 服务及网关日志 SHALL 不记录检索词、问答问题、原始查询字符串、请求或响应正文、会话令牌，以及可能包含这些内容的原始异常文本或堆栈。失败诊断
SHALL 使用固定处理阶段和安全的错误类别或状态。前置代理的访问日志规则 SHALL 在上线前核查，不得记录原始查询字符串或请求体。

#### Scenario: 异常内容回显检索词

- **WHEN** 召回、检索、模型或配额流程抛出消息、原因链或上游响应体含有检索词的异常
- **THEN** 应用异常日志只包含固定阶段与安全类别或状态，不包含该词或原始异常内容
- **AND** 对外错误仍遵循既有通用文案与授权边界

#### Scenario: 旧 GET 到达受控网关

- **WHEN** 旧客户端向受控网关发送带 `q` 的 GET 请求并被拒绝
- **THEN** 系统控制的访问日志不记录原始查询字符串或其值

#### Scenario: 发布前核查前置代理

- **WHEN** 将新检索入口部署到带前置代理的环境
- **THEN** 上线核查确认该代理的访问日志不会保存查询字符串或请求体；未完成核查时不得宣称端到端日志保密已验证
