# Tasks

任务依据本变更三份 delta spec 与 `design.md`。默认参数是方案初值；任务勾选表示对应代码、离线测试或说明已交付并按所述方法核验。

测试范围统一限定为进程内单元/组件测试，使用 Mock、内存仓储、SDK/传输/事务替身、受控时钟与模拟 DOM；不编写或执行需要前后端联调、启动应用/HTTP 监听服务/真实浏览器，或连接 Redis、数据库、MinIO/S3、解析器等外部组件的集成测试，也不交付此类测试入口。保留类型检查、构建、包体隔离和 OpenSpec 结构校验。说明文档的编写与人工审阅属于交付工作，不编写或执行检查 README、Markdown、注释、文档示例中文字、章节或文件是否存在的断言测试。离线证据只说明已覆盖的进程内行为，不作为真实数据库事务、网络取消或部署验收结论。
