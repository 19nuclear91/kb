## Purpose

在文档详情的固定已发布版本下提供安全的纯文本讨论界面，使用户能够读取评论、发表单层回复和删除本人正文，同时保持版本切换、当前授权、身份隔离及不确定提交结果的一致性，不把审核意见或讨论内容当作模型知识。

## ADDED Requirements

### Requirement: 评论面板必须绑定当前选中的固定版本

文档详情 SHALL 仅在所选版本的评论资格确认后加载其评论，明确显示对应版本，不默认跳至最新版本。新未发布版本或无发布证据的旧兼容版本 MUST 显示不可评论说明且不请求评论正文；审核意见使用独立私有区域，不复制为评论。

#### Scenario: 切换版本
- **WHEN** 用户从 V1 切换到 V2，而 V1 的评论请求尚未完成
- **THEN** 清理 V1 评论、草稿和游标，迟到结果不能显示在 V2，V2 只读取自己的讨论

#### Scenario: 打开固定版本回复通知
- **WHEN** 用户经通知进入 V1 的评论目标，而当前发布版本是 V2
- **THEN** 先核对 V1 和目标评论，不能用 V2 的讨论替代失效目标

### Requirement: 阅读与发表评论必须分别使用当前能力

面板 SHALL 按服务器当前版本资格及 comment 能力控制读取、发表和回复；只有 view 的用户可读但不可发表，comment 或管理资格不替代 view。资格未确认或读取故障时 MUST 不显示旧讨论或启用写入，不预取用户、角色或部门目录。

#### Scenario: 只读用户和权限变化
- **WHEN** 用户有 view 而无 comment，或发表前该能力被撤销
- **THEN** 前者保留阅读并说明不可发表，后者按新拒绝停止提交并重新核对，不能以旧按钮状态放行

### Requirement: 评论输入与显示必须保持纯文本边界

正文 SHALL 作为纯文本输入和展示，按服务端同一规则校验去首尾空白后的 1–4000 个 Unicode code point，保留换行，不静默截断；脚本、HTML、Markdown 图片和链接 MUST 不执行或自动加载。首期不提供编辑、附件、提及、富文本和深层回复入口。

#### Scenario: 多字节字符和标记文本
- **WHEN** 正文包含补充平面字符、换行或脚本标记
- **THEN** 长度按 code point 判断，内容安全显示，不以 UTF-16 单元误截断字符或请求外部资源

### Requirement: 根评论与回复必须独立有界加载

面板 SHALL 使用根评论倒序及回复正序的独立服务端游标，不为每条根评论预取全部回复。加载、空讨论、末页与故障 MUST 明确区分；删除根显示无正文占位、保留已有回复且禁用新回复，不展示隐藏总数。

#### Scenario: 回复很多或读取失败
- **WHEN** 根评论有多页回复，或某页读取为 503
- **THEN** 前者由用户有界续页，后者显示可重试故障，不把失败解释为无回复或全部加载完成

### Requirement: 创建评论必须显式提交并保留匹配重试意图

发表和回复 SHALL 绑定本人会话、文档版本、根节点、规范化正文和请求标识，发送期间防重复点击。结果不确定时只允许显式匹配重试或查询核对；匹配重试复用标识，改变正文、目标或版本后使用新标识。取消浏览器请求 MUST 不被解释为撤销服务端创建。

#### Scenario: 回复响应丢失
- **WHEN** 回复已经发送但无法确认结果
- **THEN** 保留当前内存中的绑定意图并显示待核对，不自动再次回复或重复发送通知

### Requirement: 删除交互必须只针对本人且不恢复正文

面板 SHALL 只为本人评论显示删除入口并要求明确确认；成功后移除正文、清理本地草稿及旧回执正文，根节点按墓碑显示。删除不要求当前 comment；资源撤权后仍可对当前页面已知的本人评论发起无正文删除，但不得为此重读受限讨论或提供管理员代删。

#### Scenario: 删除响应不确定或资源撤权
- **WHEN** 本人删除响应丢失，或页面新读取发现资源已不可访问
- **THEN** 前者可显式重试同一幂等删除，后者立即清理受保护内容，至多保留当前身份下已知本人评论的最小删除目标

### Requirement: 评论状态必须随身份和页面生命周期隔离

正文、作者投影、草稿、游标和写意图 SHALL 仅保留在当前页面内存；隐藏、离开、目标切换、退出、强制改密及身份变化时停止请求并清理相关内容。恢复先确认身份与当前版本资格，迟到结果 MUST 不填充新上下文；ID 保持精确，内容不得进入 URL、持久存储、日志或遥测。

#### Scenario: 旧用户结果迟到
- **WHEN** A 的评论、草稿或写回执在 B 登录后才返回
- **THEN** 不显示于 B 的页面，不恢复 A 的正文、删除目标或发表能力
