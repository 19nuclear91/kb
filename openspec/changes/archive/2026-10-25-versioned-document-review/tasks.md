# Tasks

实施进度以以下勾选条目为准，以本变更八份规格和 design.md 为验收依据。

验证仅限独立单元测试、无连接映射、架构检查、前端组件／状态单测、类型检查及静态构建。服务、控制器、网关和外部客户端的依赖均使用 Mock／stub 或内存替身，不启动完整应用，不安排集成测试、跨服务联调或浏览器端到端验收，不启动或连接数据库、Redis、对象存储、消息中间件或第三方 API，也不使用 Testcontainers／内嵌服务替代。迁移任务仅交付脚本，不实际执行迁移；文档任务仅交付说明，不增加 README／Markdown／说明文档或 SQL 文本断言。离线结果不能证明真实事务、锁互斥或生产可用性。
