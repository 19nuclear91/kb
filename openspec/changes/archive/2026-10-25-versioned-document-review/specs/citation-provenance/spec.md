## MODIFIED Requirements

### Requirement: 指定版本引用查询必须校验完整归属

系统 SHALL 提供 `GET /api/documents/{documentId}/versions/{versionId}/citations/{chunkId}`，要求路径 ID 为正整数，按文档和指定版本的当前 view 及发布／候选参与资格读取。仅当分块同时匹配该文档及该版本时，查询 SHALL 返回 AVAILABLE 和完整存储正文。查询 MUST 不要求该版本仍为当前版本，不按分块序号替代分块 ID；候选核对不使其进入检索或 RAG。

#### Scenario: 查询仍存在的原分块

- **WHEN** 用户可查看指定文档和版本，且三个 ID 与一个存储分块完全匹配
- **THEN** 响应为 HTTP `200`，使用既有成功响应封装，并在 `data.status` 中返回 `AVAILABLE`
- **AND** 数据包含 `docId`、`docTitle`、`versionId`、`versionNo`、请求的 `chunkId`、带完整正文和来源提示的 `chunk` 以及原版本文件入口

#### Scenario: 版本不属于请求文档

- **WHEN** 请求的 `versionId` 实际属于另一个文档
- **THEN** 返回与目标不存在或无权查看相同的 HTTP `404`，不返回版本、分块正文或文件入口

#### Scenario: 请求 ID 不合法

- **WHEN** 已通过身份检查的请求包含非正整数或超出支持范围的路径 ID
- **THEN** 返回 HTTP `400`，不尝试推断或替换为当前版本

#### Scenario: 普通读者猜测待审分块
- **WHEN** 用户只有父文档 view，没有新未发布版本的参与资格
- **THEN** 即使版本和分块 ID 匹配也统一 404，不返回 CHUNK_UNAVAILABLE、标题或原件入口

### Requirement: 引用读取必须使用当前授权并隐藏不可见目标

系统 SHALL 每次重新解析认证主体、当前密级、view、当前空间、例外、删除及版本访问资格。已发布历史与旧兼容版本按各自规则核对，新未发布版本另要求候选参与资格；管理资格不蕴含正文访问。空间归档、主体停用或无有效授权 MUST 阻止读取；不存在、已删除、归属不符或不可见统一 HTTP 404，不提供失效详情或入口。

#### Scenario: 已有引用不能保留被撤销的访问权

- **WHEN** 用户获取引用后其角色、部门、空间授权或文档例外发生变更，使其不再具有 `view` 权限，随后再次查询
- **THEN** 返回统一的 HTTP `404`，不因先前获得过该引用而返回正文、标题或降级入口

#### Scenario: 文档升密或搬迁后重新判定

- **WHEN** 文档升密超过用户当前密级，或搬迁到用户不可查看的空间后收到新的查询
- **THEN** 引用不可读取，不沿用引用生成时的密级、原空间或已清除的例外授权

#### Scenario: 空间归档优先于文档例外

- **WHEN** 文档所在空间已经归档，即使用户仍有文档例外或空间管理资格
- **THEN** 新的引用查询返回 HTTP `404`，不提供原文片段或文件入口

#### Scenario: 会话存在但主体已停用

- **WHEN** 仍持有会话的用户或其主部门已经停用
- **THEN** 新查询不能取得正文、来源信息或入口，按资源不可见返回 HTTP `404`

#### Scenario: 认证和强制改密门禁仍然生效

- **WHEN** 请求没有有效登录会话，或有效会话处于强制改密状态
- **THEN** 分别按既有门禁返回 HTTP `401` 或 `403`，新增查询不成为白名单例外

#### Scenario: 管理员没有内容查看授权

- **WHEN** 操作者只有管理权限或 `download`，而没有目标文档的 `view`
- **THEN** 引用查询不返回片段或降级详情，不能用管理或下载资格替代查看资格

#### Scenario: 审核人失去候选参与资格
- **WHEN** 审核人取得候选引用后失去 review，且不具有上传者或送审者身份
- **THEN** 新的候选引用读取返回 404，仍有父文档 view 也不保留候选读取资格
