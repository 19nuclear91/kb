# Tasks

本清单仅跟踪本变更的实现与离线验证；所有任务初始未完成。接口与场景以四份 delta spec 为准，技术选择见 `design.md`。

验证限定为明确名单的进程内单元、组件和架构测试，以及编译、类型检查、静态构建和 OpenSpec 结构校验。依赖使用内存 Mock/Stub、受控时钟、无真实连接的数据库对象替身、无端口监听的 HTTP 请求/响应替身和模拟 DOM。不编写或执行集成、端到端和进程烟测，不启动应用、真实浏览器、PostgreSQL/ParadeDB、Redis、MinIO、Docker 或模型服务，不执行数据库迁移或实际 SQL，也不保留可选外部测试入口。

文档任务仅交付说明和记录，不针对 README、Markdown、Javadoc、文档示例或 Java/XML/SQL 源文件文本编写测试。SQL 改动通过代码审查核对；内存替身的验证结论仅覆盖输入、编排和投影，不作为真实 SQL、索引或事务行为的证明。
