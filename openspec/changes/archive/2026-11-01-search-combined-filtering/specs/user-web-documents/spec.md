# Spec Delta

## MODIFIED Requirements

### Requirement: 搜索必须只消费现有授权检索能力

搜索页 SHALL 通过 POST JSON 提交 query、有界数量参数及 search-filtering 定义的可选组合条件，展示服务器返回的有序片段、标题和版本信息。不选条件时搜索全部当前可见已发布内容，选择条件时取其交集；失败不能伪装为空结果，空结果不得推断存在不可见文档。页面须按 8000 个 Unicode code point 的默认上限校验查询，不静默截断；服务端是最终判定。400、413、429 和 503 SHALL 按搜索上下文呈现，容量拒绝不得误报为部门 AI 额度不足，Retry-After 不触发自动重发。结果继续最多展示 20 条片段。

#### Scenario: 提交搜索
- **WHEN** 用户输入关键词并提交，可附带合法组合条件
- **THEN** 请求发往不含关键词或筛选参数的固定 POST 路径，页面按实际响应顺序展示结果
- **AND** 页面地址、持久存储和日志不保存该关键词或筛选草稿

#### Scenario: 未命中和依赖故障
- **WHEN** 检索成功返回空列表，或接口返回 503
- **THEN** 前者显示当前条件下未找到可用结果，后者显示检索暂不可用，两种状态可区分

#### Scenario: 查询超过字符上限
- **WHEN** 用户输入超过 8000 个 code point 的查询，或输入包含 NUL 或孤立代理项
- **THEN** 页面提示修正输入并阻止提交，不截断后发送；补充字符按一个 code point 计算

#### Scenario: 服务端拒绝输入
- **WHEN** 搜索返回 400 或 413
- **THEN** 页面分别显示查询输入不符合要求或搜索请求过大，不把搜索正文超限描述为上传文件过大
- **AND** 只在当前页面保留输入，不显示被拒请求的成功结果

#### Scenario: 搜索用户并发超限
- **WHEN** 搜索返回 429，可选带有 Retry-After
- **THEN** 页面提示搜索请求过于频繁、稍后重试，不提示部门 AI 额度不足
- **AND** 不自动再次搜索、不循环倒计时发请求；用户可以在条件允许时主动重新提交

#### Scenario: 合法的降级结果
- **WHEN** 搜索通过 BM25 或原候选排序回退返回合法成功结果，且带条件时通过筛选协议确认
- **THEN** 页面按响应原顺序显示片段，不自行重排、补取、移除条件或自动重复请求以追求非降级结果

#### Scenario: 新请求发出后旧请求才返回
- **WHEN** 用户重新提交搜索、离开页面或切换身份，旧请求随后才返回
- **THEN** 旧成功、错误及 Retry-After 信息不得覆盖新页面状态，取消本地等待不被解释为服务端工作已经退出

## ADDED Requirements

### Requirement: 搜索筛选必须采用明确且一致的表单语义

搜索页 SHALL 提供单空间、单分类及未分类、多个标签、当前发布文件类型和更新时间范围。分类与未分类互斥，父分类说明包含后代，标签说明全部匹配，文件类型不提供 UNPUBLISHED。时间由本地输入转换为带时区值，含起点不含终点；ID 必须保持长整型精度。空间使用既有可查看且未归档的候选，不因文档例外补查隐藏空间名称；不选空间仍保留全部合法例外文档。

#### Scenario: 切换空间
- **WHEN** 用户从 A 切换到 B 或全部空间
- **THEN** 清空已选分类与未分类标记，按新空间重新加载分类；已选全局标签保持其 ID，不自动提交搜索

#### Scenario: 空间外文档例外
- **WHEN** 某篇可检索文档仅由文档例外授权可见，其空间没有出现在既有空间下拉中
- **THEN** 全部可见范围仍可搜到该文档，不使用空间下拉作为本地结果过滤白名单

#### Scenario: 选择文件类型和时间
- **WHEN** 用户选 PDF 并给出合法更新起止时间
- **THEN** 提交 PDF 与带时区的时间端点；无效时间或反向范围阻止提交，不自动交换或删掉端点

### Requirement: 搜索条件草稿必须与已提交结果绑定分离

关键词和筛选 SHALL 仅在点击搜索并通过校验后作为一个完整条件快照提交；编辑草稿不发起正文搜索，不改变当前结果所对应的已提交条件。新提交清理旧结果与引用并取消旧等待；清除筛选只修改草稿，用户再次搜索才应用。页面 MUST 不以客户端过滤已取 topK、删除失败条件或自动重发代替服务端搜索。

#### Scenario: 修改草稿但没有提交
- **WHEN** 用户在已有结果时修改标签或更新时间
- **THEN** 不发出搜索，已展示结果继续标明原已提交条件，不被描述为新草稿的结果

#### Scenario: 仅凭筛选点击搜索
- **WHEN** 筛选已选但关键词为空
- **THEN** 提示填写关键词并阻止提交，不将页面改为无关键词文档浏览

#### Scenario: 新旧条件请求交错
- **WHEN** A 条件请求未完成，用户提交 B 条件，A 随后返回
- **THEN** A 的结果、错误及引用均不能填充 B，只有当前提交代次可以更新页面

### Requirement: 搜索候选目录必须独立稳定且使用搜索用途

分类和标签 SHALL 使用搜索专用已发布候选端点，独立于正文关键词及其他筛选的命中加载；分类按所选空间分层分页，标签按本人全局可检索范围进行名称搜索及分页，包含仍有关联的停用项。切换空间、分类层级或标签名称查询后 MUST 丢弃旧上下文的分页结果和迟到响应。目录为空、读取失败及末页须分别表达；不得回退管理目录、编辑候选或文档中心候选扩大范围。

#### Scenario: 分类目录来自已发布文档
- **WHEN** 用户打开空间分类选择器
- **THEN** 仅使用搜索候选响应展示分支及必要祖先，首版待审文档独有的分类不会出现

#### Scenario: 关键词变化及全局标签
- **WHEN** 用户更改正文关键词、空间、类型或时间
- **THEN** 不据此重新计算标签命中分面，标签仍使用自己的名称条件与全局候选分页

#### Scenario: 停用标签和合法空结果
- **WHEN** 用户选择仍有关联的停用标签，随后搜索得到合法空数组
- **THEN** 停用状态明确展示，页面显示当前条件下无结果，不移除标签后自动再搜

#### Scenario: 目录失败或树发生变化
- **WHEN** 候选端点失败或分类续页返回 409
- **THEN** 显示候选读取失败或目录已变化，停止拼接并提供主动重读；不自动清除已选限制并提交更宽搜索

### Requirement: 带筛选结果必须确认服务端协议支持

页面对含有效限制的搜索 SHALL 在消费成功数组前核对 `X-Search-Filter-Version: 1`；缺失、重复冲突或未知值时丢弃该次结果，提示筛选支持无法确认并保留输入供用户处理，不自动降级为无条件请求。候选端点 404 或故障不能被解释为空目录。合法无筛选搜索继续使用原成功契约，不要求旧后端提供该头。

#### Scenario: 新页面连接旧搜索后端
- **WHEN** 带筛选请求得到成功正文但没有合法版本头
- **THEN** 页面不展示任何该次命中或空结果成功提示，不声称筛选已生效

#### Scenario: 缺少候选接口
- **WHEN** 搜索分类或标签候选返回 404
- **THEN** 显示候选暂不可用，不回退到范围更宽的候选接口；已有条件不自动消失

#### Scenario: 旧后端执行合法无筛选请求
- **WHEN** 用户明确清除全部限制后搜索，响应没有版本头但满足原成功契约
- **THEN** 允许展示该次无筛选结果，不把缺少新头当成全局搜索不可用

### Requirement: 搜索筛选状态必须随页面与身份生命周期清理

草稿、已提交条件、候选名称和游标、命中及引用 SHALL 只保存在当前会话页面内存。离页、隐藏、退出、身份变化或强制改密时 MUST 清理这些状态、中止活动等待并使旧回调失效；恢复时按既有身份门禁重新加载目录，不自动恢复或重发搜索。名称按安全文本展示；失败不把旧身份候选用于新请求。

#### Scenario: 页面隐藏或切换用户
- **WHEN** 搜索和候选读取在途时页面隐藏或用户切换
- **THEN** 草稿、候选、结果与引用被清理，晚到响应不能恢复旧私有内容

#### Scenario: 恢复页面
- **WHEN** 页面重新可见且当前身份已经核对
- **THEN** 可以重新读取当前候选，关键词与搜索需用户重新输入和提交，不自动复用旧游标或旧限制
