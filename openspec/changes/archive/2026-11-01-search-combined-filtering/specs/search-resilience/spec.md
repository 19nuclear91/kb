# Spec Delta

## MODIFIED Requirements

### Requirement: 检索输入必须在执行前有界校验

检索 SHALL 接受非空白、合法 Unicode 且不含 NUL 的 query，默认上限为 8000 个 Unicode code point；超限或非法返回 400，不静默截断。请求体默认上限为 128 KiB，超限返回 413，实际读取字节必须受限，不仅信任 Content-Length。candidates 和 topK 各为 1–200，省略或 null 时默认 candidates=50、topK=candidates；topK 大于 candidates 时保持按实际候选截取的兼容行为。可选组合条件 MUST 遵守 search-filtering 的字段类型、数量和交叉校验规则，未知或重复字段及尾随 JSON 返回 400。被拒输入 MUST 不调用模型或执行召回。

#### Scenario: 查询达到边界
- **WHEN** 查询含 8000 个合法 code point，且请求体和数量参数均合法
- **THEN** 长度校验通过，补充字符不被按两个字符计算

#### Scenario: 超长或损坏字符
- **WHEN** 查询超过上限、包含 NUL 或孤立代理项
- **THEN** 返回 400，不调用 Embedding、rerank 或数据库召回，不回显查询内容

#### Scenario: 请求未声明长度
- **WHEN** 无 Content-Length 的请求实际正文超过 128 KiB
- **THEN** 在越过限界时返回 413，不先把无界正文全部载入内存

#### Scenario: 合法的独立数量参数
- **WHEN** candidates=20 且 topK=50
- **THEN** 请求合法，最终返回数量不超过实际取得的 20 个候选，不因新限制改成 400

#### Scenario: 无筛选且数量显式为空
- **WHEN** 请求有合法 query，candidates 或 topK 显式为 null
- **THEN** 沿用对应缺省值，不因新增筛选校验拒绝原本合法的无筛选请求

#### Scenario: 筛选输入无效
- **WHEN** 请求包含重复标签、冲突分类、反向时间、非法筛选类型、未知或重复字段
- **THEN** 返回 400，不通过忽略条件或强制类型转换执行部分搜索

### Requirement: 一次搜索必须共享绝对截止时间

合法请求通过已有会话与强制改密门禁、开始搜索处理时 SHALL 建立单调时钟截止时间，默认总预算 8 秒，覆盖权限解析、连接与锁等待、控制事实、Embedding、分类关系与全部筛选计算、召回、重排及结果准备。各阶段 MUST 使用剩余总预算，不重置计时；默认预留 500 毫秒用于结果准备和响应交付。截止后不得接受迟到成功或启动下一阶段，应向应用响应链路交付明确失败；网络向客户端实际送达时间不计入该执行预算。新增搜索候选请求独立取得同样的总预算，包含其授权、目录读取和响应准备。

#### Scenario: 前置阶段耗时
- **WHEN** 权限解析与控制读取已经消耗部分总预算
- **THEN** 后续阶段只使用剩余时间，不再获得新的 8 秒

#### Scenario: 总预算耗尽
- **WHEN** 截止时间到达且没有可交付的合法结果
- **THEN** 搜索以 503 结束等待，取消在途工作，不把迟到结果改写为成功

#### Scenario: 没有可见范围
- **WHEN** 当前权限已可靠解析为无可见范围
- **THEN** 正常返回空结果，不调用外部模型，不披露是否存在不可见文档

#### Scenario: 分类和标签筛选耗时
- **WHEN** 分类后代或标签关联计算消耗召回剩余预算
- **THEN** 后续召回及响应使用原截止，不另开无预算的文档 ID 预查询或重置阶段计时

#### Scenario: 候选目录读取超时
- **WHEN** 已通过准入的搜索候选请求在权限、目录读取或响应准备期间超时
- **THEN** 按既有 503 与实际工作退出规则收尾，不以空目录表示成功，也不因响应结束提前释放在途容量

### Requirement: 可选阶段降级必须保留授权和向量身份

合法配置下 Embedding 超时、限流、服务或响应错误，以及维护或实例缺少当前 profile 时 SHALL 降级为 BM25。实际向量比较前 MUST 复核当前 profile 与 epoch。rerank 超时、容量不足、服务或协议错误 SHALL 回退本次重排前授权候选的原顺序。降级不得更换主体、放宽 ACL/密级/发布/归档/版本约束或任何已提交组合筛选条件、使用旧答案或跨请求结果缓存；一次请求不自动重试远程模型或重新执行召回。

#### Scenario: Embedding 返回期间开始重建
- **WHEN** 查询向量生成后，实际检索前 profile、epoch 或维护状态已经变化
- **THEN** 当前请求执行受相同权限及组合筛选约束的 BM25，不用旧向量比较新 profile 数据

#### Scenario: 重排上游限流
- **WHEN** rerank 返回 429 而本次授权候选已经取得
- **THEN** 返回满足全部筛选的原候选 topK，记录降级，不把供应商限流冒充调用用户并发超限

#### Scenario: 控制或权限事实读取失败
- **WHEN** 当前权限、控制状态或数据库召回无法可靠完成
- **THEN** 明确失败，不凭旧事实或无权限条件再次检索

#### Scenario: 组合条件无命中
- **WHEN** 已提交空间、分类、标签、类型或时间的交集没有任何合法命中
- **THEN** 正常返回空结果，不减少条件或改用全局候选来填满 topK
