# admin-web-audits Specification

## Purpose

为持有当前审计读取资格的人员提供管理与登录事件查询页面，通过组合筛选、固定时间窗口、稳定续页和安全详情定位已记录的操作，同时保持身份隔离、精确数值和明确的数据覆盖边界。

## Requirements

### Requirement: 审计页面必须沿用既有只读审计范围

页面 SHALL 通过既有审计列表与事件详情接口展示已记录的管理、本地登录和企业 SSO 登录及绑定事件。页面 MUST 明示不包含 AI 调用审计和独立向量重建记录，且未查到记录不代表操作从未发生。首版 SHALL 仅提供查询，不提供导出、修改、删除或修补审计的操作。

#### Scenario: 查询企业登录事件
- **WHEN** 当前合格用户查询已记录的 SSO_LOGIN 或 SSO_BIND 事件
- **THEN** 页面展示服务端返回的安全元数据及可用摘要
- **AND** 不把平台登录成功自行解释为本平台会话建立成功

#### Scenario: 目标资料已经不存在
- **WHEN** 返回的审计事件关联的账号、角色、空间或文档已经不存在
- **THEN** 页面仍显示已有事件及存储的目标标识
- **AND** 不因额外关联资料不可读而隐藏事件

### Requirement: 筛选必须保持精确匹配和组合语义

页面 SHALL 提供 status、operationScope、operation、actorUserId、targetType、targetId、requestId、loginUsername 筛选并按 AND 组合。空表单字段 MUST 省略；非空字段 MUST 保持大小写和精确值，不静默修剪或截断。ID 须为 Long 正整数，targetId 必须同时有 targetType；status 仅接受 SUCCESS 或 FAILED，文本长度及控制字符限制 SHALL 与既有 API 一致。合法但未知的操作域、操作及目标类型 MUST 可以精确查询。

#### Scenario: 组合目标与结果
- **WHEN** 用户提供目标类型、目标 ID、FAILED 和请求标识并提交
- **THEN** 列表请求完整携带全部已提交条件，不忽略条件或改为模糊匹配

#### Scenario: 非法条件在发送前被拒绝
- **WHEN** 用户只填 targetId、填写非正整数或超 Long 范围 ID，或填写超长、含控制字符、首尾空白的非空文本
- **THEN** 页面显示字段校验错误，不提交新查询，不改变当前已确认结果

#### Scenario: 查询未知操作域
- **WHEN** 用户输入长度合法的未知 operationScope 或保留大小写的 targetType
- **THEN** 页面按原值提交，不强制转换大小写，也不因本地缺少显示标签而阻断查询

#### Scenario: 本地用户名筛选与 SSO 组合
- **WHEN** 用户同时提交 loginUsername 与 SSO_LOGIN 操作域
- **THEN** 两个条件都发送，页面提示用户名条件仅适用于本地登录事件
- **AND** 服务端返回空页时按本次组合查询的空结果展示，不放宽条件重查

### Requirement: 查询时间必须有界且显示实际窗口

页面 SHALL 默认查询最近 7 天，首请求省略 from/to 并展示服务端实际返回的窗口。自定义时间须同时提供起止值，按本地时区输入并转换为带时区的请求时间，满足 from 早于 to 且跨度不超过 31 天。页面 MUST 说明起点包含、终点不包含，并原样保留服务端窗口的时间精度用于续页核对。

#### Scenario: 默认窗口由服务端确定
- **WHEN** 用户首次进入页面且采用默认时间范围
- **THEN** 首次请求不按浏览器时钟补造窗口，成功后显示服务端返回的 from/to

#### Scenario: 自定义时间非法
- **WHEN** 自定义时间只填一端、日期不存在、起点不早于终点，或窗口超过 31 天
- **THEN** 页面显示校验错误，不发请求，也不自动缩短或替换时间

#### Scenario: 服务端返回微秒精度
- **WHEN** 首页返回带六位小数的 UTC 时间窗口
- **THEN** 后续请求与响应核对保持原时间值，不因显示格式转换损失精度
- **AND** 页面本地时区展示不改变固定查询窗口

### Requirement: 继续读取必须保持固定窗口和服务端顺序

页面 SHALL 提供每次 20、50、100 条及显式继续读取，按服务端顺序追加，展示已加载数量，不声称总记录数。续页 MUST 使用当前已提交条件和原游标，不重新计算时间。一次查询同时至多执行一个列表请求；仅 hasMore=true 且存在有效 nextCursor 时允许继续。新页的窗口或身份结构无法核对时 MUST 作为读取故障，不混入结果。

#### Scenario: 新事件在翻页期间产生
- **WHEN** 用户取得首页后产生了新事件，再点击继续读取
- **THEN** 续页仍使用首页确定的窗口和排序位置，不混入本次窗口之外的新事件

#### Scenario: 重复点击与续页响应丢失
- **WHEN** 用户连续点击继续读取，或续页失败后显式重试
- **THEN** 重复点击不会并行读取同一页；失败时保留已确认记录及待重试游标，重试成功后只追加一次

#### Scenario: 窗口或游标响应异常
- **WHEN** 续页窗口不同、出现重复事件身份、游标不能形成合法续页，或返回数据结构无法核对
- **THEN** 页面保留先前确认结果并显示读取故障，不追加异常页

### Requirement: 草稿筛选与已提交查询必须分离

页面 SHALL 在用户显式提交后应用筛选；编辑表单不影响正在继续读取的已提交条件。提交合法筛选、改变每次条数、重置或刷新 MUST 关闭详情、取消旧请求并开始新的查询代次。刷新沿用已提交条件，默认窗口重新由服务端确定，自定义窗口保留显式时间；重置恢复最近 7 天及每次 20 条。页面 MUST 不定时轮询。

#### Scenario: 修改草稿后继续读取
- **WHEN** 用户编辑筛选但尚未提交，随后点击继续读取
- **THEN** 续页仍按当前结果所属的已提交条件请求，草稿不会与旧游标混用

#### Scenario: 切换条件时旧请求晚到
- **WHEN** 原查询尚未完成，用户提交另一组合法条件或刷新列表
- **THEN** 旧代次结果不能恢复旧列表、窗口、游标或详情

### Requirement: 事件详情必须以 UUID 读取安全摘要

页面 SHALL 按所选列表项的 eventId 读取详情，并核对详情事件身份。详情展示安全元数据与字段前后值，不展示原始审计载荷或自由文本原因。summaryAvailable=false 时 SHALL 明示摘要不可用；summaryAvailable=true 且 changes 为空时 SHALL 表示无可展示变更，两种情况不得混淆。切换事件或关闭抽屉 MUST 清理旧详情并隔离迟到响应。

#### Scenario: 摘要不可用
- **WHEN** 详情返回合法元数据及 summaryAvailable=false
- **THEN** 抽屉继续展示安全元数据并说明摘要不可用，不用旧详情或原始 JSON 补全

#### Scenario: 没有可展示变更
- **WHEN** 详情返回 summaryAvailable=true 且 changes 为空
- **THEN** 页面显示无可展示变更，不显示摘要解析失败

#### Scenario: 事件切换与身份不匹配
- **WHEN** 用户从事件 A 切换到 B，或返回详情的 eventId 不等于所请求事件
- **THEN** A 的迟到详情不能显示在 B 下；身份不匹配的响应显示读取故障

### Requirement: 事件值必须精确且按安全文本展示

页面 MUST 精确保留并显示内部 ID、操作者和目标 ID、变更中的 Long 整数及计数。before/after 中 false、0、空字符串与 null MUST 各自可辨；null 主体显示未记录，不猜测为系统或某个用户。操作域、类型、字段、枚举和用户名 SHALL 按文本展示，未知合法代码保留原值。页面 MUST 不通过额外身份、角色、空间或文档请求补名称。

#### Scenario: 大整数与空主体
- **WHEN** 事件包含超过 JavaScript 安全整数范围的 ID 或变更值，且 actorUserId 或 targetId 为 null
- **THEN** 所有整数完整显示，空主体保持未记录，不将空值改为 0 或虚构主体

#### Scenario: 布尔值与空值共存
- **WHEN** 变更前值为 false、0 或空字符串，后值为 null
- **THEN** 两端分别展示，不因真假值判断把已有值替换为未记录

#### Scenario: 数据含 HTML 标记或未知代码
- **WHEN** 已批准展示的文本包含 HTML、图片或脚本标记，或操作代码没有本地标签
- **THEN** 页面只显示文本，不执行内容、不自动加载外部资源；未知代码仍可辨认

### Requirement: 审计内容必须服从当前会话和资格生命周期

页面 SHALL 仅在身份与 audit:read 已确认时读取。退出、身份切换、强制改密、资格撤销、进入后台和离开页面时 MUST 停止相关请求并清理已展示记录、查询窗口、游标、详情及筛选。后台恢复 SHALL 先重新核对身份与资格，再按默认条件重新读取；旧身份或旧查询的迟到响应不得恢复内容。可管理空间目录故障 MUST 不阻断已确认的审计读取资格。

#### Scenario: 查询途中退出或切换账号
- **WHEN** 列表或详情请求在途时用户退出、切换账号或进入强制改密
- **THEN** 清理当前审计资料与筛选，迟到结果不能进入后续身份页面

#### Scenario: 后台恢复
- **WHEN** 页面从后台重新变为活动且身份与资格重新确认
- **THEN** 使用默认最近 7 天重新读取，不恢复旧筛选、旧详情或旧游标

### Requirement: 读取拒绝与故障必须可辨且支持有界恢复

页面 SHALL 分别处理参数错误、登录失效、权限拒绝、事件不可访问和依赖故障。401 沿用登录恢复；403 立即清理所有审计结果、详情、游标及敏感筛选，针对同一拒绝上下文最多自动核对一次资格，不自动循环请求。详情 404 清理该详情并提示不可访问；400 游标错误要求重新查询。网络、503 或损坏成功响应 MUST 显示可重试故障，不伪装为成功空页。

#### Scenario: 翻页或详情返回禁止
- **WHEN** 已展示列表后，续页或详情请求返回 403
- **THEN** 立即清理整页审计资料并核对当前资格；核对仍声称有资格时保留拒绝提示，须显式重试
- **AND** 不因守卫重新挂载自动循环查询

#### Scenario: 单个事件不可访问
- **WHEN** 详情请求返回 404
- **THEN** 关闭旧详情正文与变更展示并提示该事件不可访问，不把整个列表解释为无事件

#### Scenario: 首次读取或续页暂时失败
- **WHEN** 列表请求因网络、503 或响应结构异常失败
- **THEN** 首次读取显示故障；续页失败保留已确认结果并提供重试当前页
- **AND** 均不显示为成功的零条结果

### Requirement: 审计查询状态必须限制在当前内存

筛选、记录、详情、游标和时间窗口 SHALL 只保留在当前有效页面内存。浏览器页面地址 MUST 保持 `/admin/audits`，不得携带查询值；审计资料 MUST 不写入浏览器持久存储、日志或遥测。发往既有 API 的查询参数 SHALL 使用既有认证与禁止缓存行为，错误提示不得展示服务端原始错误正文。

#### Scenario: 查询敏感用户名或请求标识
- **WHEN** 用户通过筛选输入用户名或请求标识并打开详情
- **THEN** 筛选只进入本次 API 查询，页面地址及浏览器存储不保存这些值
- **AND** 失败时仅显示安全错误分类，不回显原始错误载荷

### Requirement: 资料审计集合必须按字段白名单解码和展示

审计详情 SHALL 支持 tagIds 和 changedFields 的有界集合前后值：tagIds 至多 20 个精确正整数，changedFields 仅接受 title、summary、categoryId、tagIds 的不重复集合。其他字段继续采用既有标量规则，未知数组、嵌套对象、超限或非法元素作为读取故障。集合按安全文本逐项显示，不关联加载文档或词条名称，不把字段代码解释为实际正文。

#### Scenario: 标签集合包含大整数
- **WHEN** 合法资料审计含超过 JavaScript 安全整数范围的 tagId
- **THEN** 页面逐项完整显示原整数，不能经浮点转换导致截断或与其他 ID 合并

#### Scenario: 变更字段说明
- **WHEN** changedFields 为 title 和 summary
- **THEN** 页面只说明这两个字段被修改，不读取或推测修改前后正文

#### Scenario: 响应含任意嵌套对象
- **WHEN** 集合中出现对象、任意名称字符串，或未知字段返回数组
- **THEN** 详情作为读取故障处理，不直接 stringify 后展示原始载荷

### Requirement: 新分类空值必须与历史未知可区分

新版搬迁详情 SHALL 按服务器投影展示显式 null 分类与已知元数据版本；历史没有新字段时显示该信息未记录或省略，不补为未分类和零版本。合法空集合显示为空集合，不能与 null 或摘要不可用混为一谈。原审计身份、当前资格、分页窗口和迟到响应隔离继续执行。

#### Scenario: 明确迁入未分类
- **WHEN** 新版搬迁审计确认目标 categoryId 为 null
- **THEN** 页面可以显示明确未分类，与旧事件缺少分类信息的表现不同

#### Scenario: 旧事件缺少分类
- **WHEN** 旧搬迁事件没有分类和 metadataVersion 变更项
- **THEN** 页面保留已有安全详情，不推造未分类或 metadataVersion=0

#### Scenario: 标签全部移除
- **WHEN** tagIds 的后值是合法空数组
- **THEN** 页面显示标签集合已清空，不把它解释为未记录或摘要解析失败
