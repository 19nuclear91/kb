# search-query-confidentiality Specification

## Purpose

为知识库检索及 AI 问答中的检索词建立统一的传输和日志保密契约，使正常调用不把查询内容放入
URL，并使请求失败时的应用日志及受控访问日志仍不泄露查询内容、响应正文或凭据。

## Requirements

### Requirement: 检索仅通过 POST 请求体接收查询

系统 SHALL 仅通过 `POST /api/search` 或显式增强入口 `POST /api/search/assisted` 的 JSON 请求体接收检索词 query、候选数 candidates、结果数 topK 及 search-filtering 定义的可选组合条件；增强字段仅由增强入口接受。原接口保持既有数组字段与查询行为，增强入口按独立对象契约返回。URL 查询参数 MUST NOT 成为检索输入。未知字段、重复字段和尾随 JSON 必须返回 400，不静默忽略条件。请求须遵守 search-resilience 的字符、正文、数量、时间及容量限制；输入或容量被拒时不得以成功空列表替代错误。

#### Scenario: 合法检索请求

- **WHEN** 已登录且完成必需改密的用户以 POST JSON 提交非空 query、合法数量和可选筛选
- **THEN** 系统按该用户当前服务端身份和完整条件执行授权检索，并以所选接口的明确响应结构返回结果
- **AND** 请求 URL 不含检索词、数量或筛选参数

#### Scenario: 缺省数量

- **WHEN** POST 请求体只包含合法的 query
- **THEN** 每路候选数默认为 50，topK 默认为候选数

#### Scenario: 无效请求体或 URL 参数

- **WHEN** POST 请求体缺少或提供空白 query、数量超出现有 1–200 范围、筛选非法，或任一检索入口的 URL 携带查询参数
- **THEN** 系统返回固定且不回显输入值的 HTTP 400 响应，不执行检索

#### Scenario: 调用方伪造身份或向量

- **WHEN** 请求体包含 userId、角色、密级、queryVector 或 profile 声明
- **THEN** 系统将其作为未知字段返回 400，不执行检索，也不将这些值作为身份、授权范围或查询向量

#### Scenario: 请求触发新增限界
- **WHEN** 查询字符、实际请求体或搜索并发超过配置上限
- **THEN** 分别返回约定的 400、413、429 或 503，不回显输入，不执行被拒请求的召回

#### Scenario: 增强查询和采用上下文
- **WHEN** 用户采用纠错或歧义建议
- **THEN** 原始 query、完整筛选、selectionContext 及累计选择只经增强入口的 JSON 正文传输，不放在路径或 URL 参数中

#### Scenario: GET 增强搜索
- **WHEN** 已通过认证与强制改密门禁的调用方请求 GET `/api/search/assisted`
- **THEN** 返回 405，不执行检索，不回显 URL 查询字符串

### Requirement: 旧版 GET 检索停止服务

系统 MUST 停用 `GET /api/search`；通过既有认证与强制改密门禁的 GET 请求 SHALL 返回 HTTP 405，不执行检索，也不在错误响应中回显
URL 查询字符串。

#### Scenario: 已认证旧调用方使用 GET

- **WHEN** 已登录且完成必需改密的调用方请求 `GET /api/search?q=敏感词`
- **THEN** 系统返回 HTTP 405，不返回检索结果，响应不包含该检索词

#### Scenario: 旧调用方没有有效会话

- **WHEN** 未认证调用方请求旧版 GET 接口
- **THEN** 既有认证门禁仍可先返回 HTTP 401，旧接口不会因此提供匿名检索

### Requirement: AI 召回使用相同的保密检索入口

AI 服务 SHALL 通过 `POST /api/search` 的 JSON 请求体发送用户问题与召回数量，MUST NOT 把问题放入 URI；它 SHALL 透传调用者会话并继续使用同一授权检索响应与引用契约。仅 HTTP 200、code=200、data 为合法数组的成功响应可提供材料或真实空结果；检索拒绝、超时、依赖故障、空 HTTP 响应及损坏协议 MUST 显式失败，不转换为正常空集合，也不以服务账号、旧材料或放宽权限重试。

#### Scenario: 问答召回成功

- **WHEN** 用户提交 AI 问题并具有可见文档
- **THEN** AI 到业务应用的检索请求使用不含问题的固定路径及 JSON 请求体，携带原调用者会话
- **AND** 引用身份、来源字段及 SSE 事件语义与现有契约一致

#### Scenario: 召回被拒或上游不可用

- **WHEN** 业务应用拒绝召回或检索上游不可用
- **THEN** AI 明确结束为检索错误，不产生正常无结果回答，不以服务账号或无权限条件重试
- **AND** 对外信号不披露目标文档是否存在，原始 HTTP 状态和固定失败类别仅用于受控处理

#### Scenario: 合法的真实空结果
- **WHEN** 授权检索返回 HTTP 200 且响应为 code=200、data=[]
- **THEN** AI 使用既有固定无结果回答且不调用模型，不区分未命中与无可见范围

#### Scenario: 空响应或业务失败包装
- **WHEN** 上游返回 204、HTTP 200 空正文、null 根、缺少成功 code 或数组 data，或 HTTP 200 包装业务失败
- **THEN** AI 将其作为协议失败，触发安全错误收尾，不直接空完成或仅保留心跳

#### Scenario: 非空数组没有合法引用
- **WHEN** 非空成功数组中的记录经既有身份校验后全部无效
- **THEN** AI 将其作为协议失败，不把损坏材料误报为真实零命中
- **AND** 混合数组仍按已有引用规则保留合法项、丢弃损坏身份项，缺失的可选来源不伪造

#### Scenario: 检索取消或等待超时
- **WHEN** 独立检索预算到期或所属生成请求被取消
- **THEN** 停止上游读取，不自动重发；超时进入错误收尾，用户取消继续使用既有取消语义

### Requirement: 查询相关日志不得记录原始敏感内容

系统控制的业务应用、AI 服务及网关的日志与遥测输出（追踪跨度属性、指标标签与 exemplar）SHALL 不记录检索词、问答问题、筛选值、候选名称查询、原始查询字符串、请求或响应正文、会话令牌，以及可能包含这些内容的原始异常文本或堆栈。此规则 MUST 覆盖 `/api/search`、`/api/search/assisted`、`/api/search/categories` 和 `/api/search/tags` 的成功与失败，并包含有效表达、扩展词、纠错及歧义建议、selectionContext 和选择载荷。失败诊断 SHALL 使用固定处理阶段和安全错误类别或状态。前置代理的访问日志规则 SHALL 在上线前核查，不得记录原始查询字符串或请求体。

#### Scenario: 异常内容回显检索词

- **WHEN** 召回、检索、模型或配额流程抛出消息、原因链或上游响应体含有检索词的异常
- **THEN** 应用异常日志只包含固定阶段与安全类别或状态，不包含该词或原始异常内容
- **AND** 对外错误仍遵循既有通用文案与授权边界

#### Scenario: 旧 GET 到达受控网关

- **WHEN** 旧客户端向受控网关发送带 q 的 GET 请求并被拒绝
- **THEN** 系统控制的访问日志不记录原始查询字符串或其值

#### Scenario: 发布前核查前置代理

- **WHEN** 将新检索入口部署到带前置代理的环境
- **THEN** 上线核查确认该代理的访问日志不会保存查询字符串或请求体；未完成核查时不得宣称端到端日志保密已验证

#### Scenario: 搜索候选异常携带名称
- **WHEN** 分类或标签候选读取、分页解码或依赖调用抛出包含目录名称、筛选值或游标内容的异常
- **THEN** 日志不输出这些值及原始堆栈，响应使用固定安全错误，候选子路径不退回通用异常明细日志

#### Scenario: 追踪与指标输出
- **WHEN** 启用追踪或指标导出后处理搜索、候选或 AI 召回请求
- **THEN** 跨度属性、指标标签与 exemplar 只含固定阶段、路由模板与安全类别，不含检索词、筛选值、请求头值或查询字符串

#### Scenario: 建议过期或损坏
- **WHEN** selectionContext 校验失败，或词典查询异常携带纠错表达和原始问题
- **THEN** 仅输出固定失败类别，不记录上下文、原查询、目标词或原始异常链

### Requirement: 搜索候选查询必须使用受保护请求体并禁止缓存

搜索分类、标签候选 SHALL 通过各自固定 POST 路径接收 JSON 条件，拒绝 URL 查询参数；名称查询不进入 URL、浏览器持久存储或遥测。原搜索、增强搜索及候选端点的成功、参数拒绝、建议失效、认证拒绝、权限拒绝和服务故障响应 MUST 带 `Cache-Control: no-store`，网关不得丢失或覆写；公开路径不得转发到 AI 或改写为静态页面。

#### Scenario: 标签名称查询
- **WHEN** 用户输入名称并查询搜索标签候选
- **THEN** nameQuery 只通过 `/api/search/tags` 的 JSON 请求体发送，响应禁止缓存，地址栏不出现名称

#### Scenario: 网关提前拒绝候选请求
- **WHEN** 网关因登录状态失效在业务应用前拒绝 `/api/search/categories` 或 `/api/search/tags`
- **THEN** 拒绝响应仍带 no-store，不暴露查询体或返回可被缓存的候选数据

#### Scenario: 网关拒绝增强请求
- **WHEN** 增强请求在网关被认证门禁拒绝，或服务端返回 ASSISTANCE_STALE
- **THEN** 响应仍带 no-store，不缓存原始问题、词典采用说明或选择上下文

### Requirement: 搜索辅助不得建立隐式查询历史或扩大出站数据

词典匹配与建议生成 SHALL 仅使用本次输入及人工维护的公开词条，不持久记录用户搜索历史、采用记录或查询热度来学习词典。selectionContext 不得携带可直接解码的原始查询和筛选内容。外部 Embedding 与 rerank 仅接收本次执行必要的有效表达、实际扩展及已有授权材料，不外发完整词典、待确认候选释义、选择凭据或内部身份资料。

#### Scenario: 生成歧义候选
- **WHEN** 公开词典产生两个待确认含义
- **THEN** 在业务服务内形成候选，不调用外部模型猜测选择，也不把完整候选释义作为额外查询发送

#### Scenario: 用户可见的上下文
- **WHEN** 客户端取得 selectionContext
- **THEN** 即使观察其编码也不能直接还原原始问题或筛选；其存在不导致持久化一份用户查询历史

#### Scenario: 同义扩展需要外部向量
- **WHEN** 本次已采用的术语关系参与远程向量或重排请求
- **THEN** 仅发送执行所需表达，继续遵守既有用户令牌及追踪头隔离，未采用词条不随之外发
